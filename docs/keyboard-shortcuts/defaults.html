Default keyboard shortcuts

Letter and digit keys need Ctrl + Alt; only [, ], =, \, ', ,, . and Esc work alone. That keeps the extension's keys away from the keys a site's own player uses.

A "Yes" in the last column means the key works with a connected account, and Account and sync lists what connecting adds.

Speed​

The Speed Control section in Settings holds the speed keys and the widget keys.

]Increase speed by 0.1xNo
=Reset to default speedNo
\Show current speedNo
'Sync to dynamic speed: applies the Current Dynamic Speed set on the General tab in SettingsNo

Ctrl + Alt + HHide or show the widgetNo

Optional shortcuts with no key​

These start with no key. In Settings, open the Keyboard Shortcuts tab, find the group, press Set, then press the keys you want. If a key already belongs to another shortcut, Settings tells you which one and takes you to it.

Browser-level shortcuts​

The browser sets these four. It decides whether each one is assigned, and you change them on the browser's own extension shortcuts page. The extension cannot change them.

Suggested keyWhat it does
Alt + VOpen the popup
Ctrl + Shift + V (Command + Shift + V on a Mac)Show or hide the floating controls
Ctrl + Shift + P (Command + Shift + P on a Mac)Picture-in-Picture on or off
Ctrl + Shift + C (Command + Shift + C on a Mac)Take a screenshot

Netflix​

Netflix has its own set, which switches on only in one case, and the table is on the Netflix page.

To give one of these another key, see Change a shortcut.
