Letter and digit keys need `Ctrl + Alt`; only `[`, `]`, `=`, `\`, `'`, `,`, `.` and `Esc` work alone. That keeps the extension's keys away from the keys a site's own player uses.

A "Yes" in the last column means the key works with a connected account, and [Account and sync](/docs/account-and-sync) lists what connecting adds.

## Speed

The Speed Control section in Settings holds the speed keys and the widget keys.

| Key | What it does | Needs an account |
|---|---|---|
| `[` | Decrease speed by 0.1x | No |
| `]` | Increase speed by 0.1x | No |
| `=` | Reset to default speed | No |
| `\` | Show current speed | No |
| `'` | Sync to dynamic speed: applies the Current Dynamic Speed set on the General tab in Settings | No |
| `Esc` | Hide or show the widget | No |
| `Ctrl + Alt + H` | Hide or show the widget | No |

## Advanced controls

| Key | What it does | Needs an account |
|---|---|---|
| `Ctrl + Alt + P` | Picture-in-Picture on or off | Yes |
| `Ctrl + Alt + S` | Skip intro, on Netflix and Prime Video | Yes |

## Browser-level shortcuts

The browser sets these four. It decides whether each one is assigned, and you change them on the browser's own extension shortcuts page. The extension cannot change them.

| Suggested key | What it does |
|---|---|
| `Alt + V` | Open the popup |
| `Ctrl + Shift + V` (`Command + Shift + V` on a Mac) | Show or hide the floating controls |
| `Ctrl + Shift + P` (`Command + Shift + P` on a Mac) | Picture-in-Picture on or off |
| `Ctrl + Shift + C` (`Command + Shift + C` on a Mac) | Take a screenshot |

## Netflix

Netflix has its own set, which switches on only in one case, and the table is on the [Netflix page](/docs/platforms/netflix).

To give one of these another key, see [Change a shortcut](/docs/keyboard-shortcuts/rebinding).
