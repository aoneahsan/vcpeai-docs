Press `]` or `[` for 0.1x steps, or drag the slider in the widget up to 4x. The bracket keys work on their own, without `Ctrl + Alt`, and speed control works signed out.

## The speed keys

| Key | What it does |
|---|---|
| `]` | 0.1x faster |
| `[` | 0.1x slower |
| `=` | Back to your default speed |
| `\` | Show the current speed |
| `'` | Sync to dynamic speed |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## How fast it goes

The range is 0.1x to 16x. The slider and the bracket keys stop at 4x. Type a speed into the custom input on the widget's Speed tab, or into the **Custom Speed (0.1x - 16x)** boxes on the General tab in Settings, and the video plays at up to 16x.

The step is always 0.1x. Settings has no control for the minimum speed, the maximum speed or the step.

## Your default speed and the dynamic speed

Open Settings and go to the General tab.

| Setting | What it is | Key |
|---|---|---|
| Default Playback Speed | The speed used when you reset and when a new video loads | `=` |
| Current Dynamic Speed | A second speed you set here and apply with one key | `'` |

The `'` key applies the Current Dynamic Speed. It is not the speed saved for the video.

## Preset speeds

There are 8 presets on `Ctrl + Alt + 1` to `Ctrl + Alt + 8`. Each one can be edited, and you can remove the ones you don't use. You do that in Settings, on the Keyboard Shortcuts tab.

Add a ninth preset to use `Ctrl + Alt + 9`.

## Speed memory

The extension remembers the speed you set for a video, and it applies it the next time you open that video. That is on by default.

It can also remember one speed for a whole playlist or course; that switch is off by default, and you turn it on in Settings on the Advanced tab.

When a video has more than one saved speed, **Speed Priority** decides which one wins:

| Setting | Which speed wins |
|---|---|
| Playlist/Course first | The speed saved for the playlist or course |
| Video first | The speed saved for the video |
| Global only (ignore saved) | Your default speed, and saved speeds are ignored |
