---
title: Take notes and add bookmarks while you watch
sidebar_label: Notes and bookmarks
description: Save notes with the video timestamp from the widget's Tools tab, export them as Markdown, text or JSON, and add a bookmark at the current moment.
---

Connect your account before saving a note. Each note keeps the video timestamp and appears on the website's **Notes** page. The widget's **Tools** tab has the note editor, export buttons and a library chooser.

## Take a note

1. Open the widget and go to the **Tools** tab.
2. Under **Notes & Extraction**, click **Note**.
3. Type the note in the prompt and confirm.

The note is queued with the current timestamp for your account. You can also right-click the video and choose **Add Note**. If you aren't connected, the extension asks you to connect before opening the editor.

A note written at 12:40 in a lecture stays tied to 12:40, so you know which part of the video it belongs to. Notes are private: they are not posted to the site as comments.

To read and edit notes, choose **Notes** from **Your library** on the widget's Tools tab. It opens your account's Notes page on the website.

## Export your notes

In the same section, click the format you want. The export includes your account's notes and notes still waiting to sync from this browser.

| Button | What you get |
|---|---|
| Notes MD | A Markdown file |
| Notes TXT | A text file |
| Notes JSON | A JSON file |

The Markdown export puts each note on its own line with its timestamp, so the file sits beside the rest of your lecture notes as it is.

## Add a bookmark

Click **Bookmark** on the Tools tab, right-click the video and choose **Add Bookmark**, or press `Ctrl + Alt + O`. You can save a bookmark without an account; it stays in this browser.

When the extension is connected, a new bookmark saves at the current moment and syncs to your account. Choose **Bookmarks** from **Your library** on the widget's Tools tab, or open the **Bookmarks** tab on the website's [Notes page](https://vcpeai.aoneahsan.com/notes?tab=bookmarks), to search, edit, delete or export account bookmarks. Bookmarks made before you connected remain only in that browser; connecting later does not upload them automatically. The **Enable Cloud Sync** switch controls settings sync separately.

## Download the transcript

Click **Transcript** in the same section to download the transcript as text. You read it outside the player.

## Share a moment

Press `Ctrl + Alt + X` to copy a link to the video with the current timestamp, and it works on YouTube, Vimeo, Twitch and other sites. The link carries the time and nothing else.

## Related keys

| Key | What it does |
|---|---|
| `Ctrl + Alt + O` | Add a bookmark at the current moment |
| `Ctrl + Alt + X` | Copy a link with the timestamp |
| `Ctrl + Alt + C` | Capture the current frame |

Starting keys are in [Default shortcuts](/docs/keyboard-shortcuts/defaults), and [Change a shortcut](/docs/keyboard-shortcuts/rebinding) moves them.
