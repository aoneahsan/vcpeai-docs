---
title: Take notes and add bookmarks while you watch
sidebar_label: Notes and bookmarks
description: Save notes with the video timestamp from the widget's Tools tab, export them as Markdown, text or JSON, and add a bookmark at the current moment.
---

Each note you take while you watch is saved with the timestamp, and notes export as Markdown, text or JSON. Notes work without an account, and they are on the widget's **Tools** tab, under **Notes & Extraction**.

## Take a note

1. Open the widget and go to the **Tools** tab.
2. Under **Notes & Extraction**, click **Note**.
3. Type the note in the prompt and confirm.

The note is saved with the current timestamp. You can also right-click the video and choose **Add Note**.

A note written at 12:40 in a lecture stays tied to 12:40, so you know which part of the video it belongs to. Notes are private: they are not posted to the site as comments.

There is no notes list or viewer inside the extension today. To read your notes, export them.

## Export your notes

In the same section, click the format you want.

| Button | What you get |
|---|---|
| Notes MD | A Markdown file |
| Notes TXT | A text file |
| Notes JSON | A JSON file |

The Markdown export puts each note on its own line with its timestamp, so the file sits beside the rest of your lecture notes as it is.

## Add a bookmark

Click **Bookmark** on the Tools tab, or press `Ctrl + Alt + O`. The key needs [an account](/docs/account-and-sync).

The bookmark is added at the current moment. Bookmarks are add-only today.

## Download the transcript

Click **Transcript** in the same section to download the transcript as text. You read it outside the player.

## Share a moment

Press `Ctrl + Alt + X` to copy a link to the video with the current timestamp, and it works on YouTube, Vimeo, Twitch and other sites. The link carries the time and nothing else.

## Related keys

| Key | What it does |
|---|---|
| `Ctrl + Alt + O` | Add a bookmark at the current moment |
| `Ctrl + Alt + X` | Copy a link with the timestamp |
| `Ctrl + Alt + C` | Capture the current frame |

Starting keys are in [Default shortcuts](/docs/keyboard-shortcuts/defaults), and [Change a shortcut](/docs/keyboard-shortcuts/rebinding) moves them.
