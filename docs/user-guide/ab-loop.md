An A-B loop replays the stretch between two points you set. Looping needs a sign-in. Speed control does not. If the loop keys do nothing, [sign in first](/docs/account-and-sync).

## Set a loop

1. Play the video to where the hard part starts.
2. Press `Ctrl + Alt + A`. That is point A.
3. Let it play to where the part ends.
4. Press `Ctrl + Alt + B`. That is point B.

The video jumps back to A when it reaches B, and it plays that part until you clear it. You can also set A and B with one click each on the widget's Loop tab.

It helps with a guitar lesson that has one fast bar, a lecture where the proof goes by in 40 seconds, and a language video with one sentence you can't catch: set A and B around the part, slow the speed with `[`, and it plays until you have it.

## The loop keys

| Key | What it does |
|---|---|
| `Ctrl + Alt + A` | Set the start point (A) |
| `Ctrl + Alt + B` | Set the end point (B) |
| `Ctrl + Alt + L` | Turn the loop on or off |
| `Ctrl + Alt + Backspace` | Clear both points |

## Loop modes

You pick the mode on the widget's Loop tab, and the widget's labels are in English ([why](/docs/user-guide/display-and-widget)).

| Mode | What happens at B |
|---|---|
| Forever | The part repeats until you turn the loop off |
| Once | The part repeats one time |
| Times | The part repeats the number of times you set, from 1 to 20 |

With Times, a progress indicator shows how far through the repeats you are, and the count stops at 20, so for more, use Forever and turn it off yourself with `Ctrl + Alt + L`.

## Related keys

`,` and `.` step back and forward one frame, which helps you put A and B on the exact spot. Every key is in [Default shortcuts](/docs/keyboard-shortcuts/defaults), and you can change them in [Change a shortcut](/docs/keyboard-shortcuts/rebinding).
