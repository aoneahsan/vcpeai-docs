HTML5 Video Speed Control is keys for speed and seeking, so moving means setting your keys again.

**Last checked 2026-11-07.** A keyboard speed controller for HTML5 video: speed up, slow down, advance and rewind. <a href="https://microsoftedge.microsoft.com/addons/detail/html5-video-speed-control/dpidphhdlkjaipgecjejekdeheeokfkf" target="_blank" rel="noopener noreferrer nofollow">Check HTML5 Video Speed Control yourself</a>.

## Move across

1. Install Video Controls Plus for your browser: [Install Video Controls Plus](../getting-started/install.md).
2. Read the keys we start with: [Default keyboard shortcuts](../keyboard-shortcuts/defaults.md).
3. Give speed and seeking the keys your hands know: [Change a keyboard shortcut](../keyboard-shortcuts/rebinding.md).
4. Turn HTML5 Video Speed Control off on your browser's Extensions page, so two extensions don't answer the same keys. Remove it once your own sites work.

Each browser keeps an extension's settings to itself, so nothing carries over. You set them once here.

## Who is better off with which

- Choose HTML5 Video Speed Control if you want keys for speed and seeking and no other feature.
- Choose Video Controls Plus if you want those keys plus per-video memory, presets, loops, filters and notes in one account.
