Video Speed Control is a popup you press Play in each time. Here the speed is on a key, so the move is learning two keys.

**Last checked 2026-11-07.** A popup speed changer for HTML5 video, 0.07x to 16x, applied with a Play button each time. <a href="https://microsoftedge.microsoft.com/addons/detail/video-speed-control/fgggaiedigajhlidjmmmengcpoipjeko" target="_blank" rel="noopener noreferrer nofollow">Check Video Speed Control yourself</a>.

## Move across

1. Install Video Controls Plus for your browser: [Install Video Controls Plus](../getting-started/install.md).
2. Change speed with the bracket keys and type a custom speed up to 16x: [Control the playback speed](../user-guide/speed-control.md).
3. To stop setting it every time, keep a speed for each site under [Automation](../user-guide/playback-automation.md).
4. Turn Video Speed Control off on your browser's Extensions page, so two extensions don't answer the same keys. Remove it once your own sites work.

Each browser keeps an extension's settings to itself, so nothing carries over. You set them once here.

## Who is better off with which

- Choose Video Speed Control if you change speed now and then from a popup and want a small extension with a dark mode.
- Choose Video Controls Plus if you want the speed to stay set per video and per playlist, keys you can rebind, and loops, filters and notes beside it.
