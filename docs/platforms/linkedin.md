On LinkedIn it does a lot more than control a video: it scores your profile, tracks your job applications and exports your posts, and each tool runs the moment you pick it from the widget or the right-click menu. The core video controls work as on any site. The tools that are on by default run without an account. To switch one on or off you need the LinkedIn Features tab in Settings, and that tab needs an account ([what connecting adds](/docs/account-and-sync)).

## The tools

A tool opens its panel, or it exports or downloads, at once.

| Tool | What it does | Default |
|---|---|---|
| Profile Scorer | Analyzes how complete your profile is | On |
| Headline Generator | Generates headlines built around keywords | On |
| Job Tracker | Tracks your job applications | On |
| Post Exporter | Exports posts to CSV or JSON | On |
| Profile Backup | Backs up your profile | On |
| Message Exporter | Exports messages to CSV or JSON | On |
| Feed Filter | Filters feed content | Off |
| Focus Mode | Blocks distractions on LinkedIn | Off |

## What is on and what is off

A tool that waits until you pick it is on by default. A tool that puts something on the LinkedIn page when it loads, or that changes LinkedIn's feed, is off until you turn it on. Feed Filter and Focus Mode are in that second group.

## Where the switches are

1. Open Settings.
2. Go to the **LinkedIn Features** tab.
3. Connect an account if the tab asks you to.

The tools are grouped: Profile, Content Creation, Post & Feed, Connections, Messaging, Jobs, Analytics, Export, Privacy and Productivity.

Each tool has an enable switch and a "show in right-click menu" switch. The tools run only on linkedin.com.

On/off switches apply after you reload the LinkedIn page. Menu actions need no reload.

## The info button

Every panel a LinkedIn tool opens carries an info button, and when you click it the panel explains what it is and how to use it.
