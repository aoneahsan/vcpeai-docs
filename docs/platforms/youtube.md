On YouTube you get the same controls as everywhere and a set of extras made for YouTube: Comment Search, a Dislike Counter, a Channel Blocker and subtitle and thumbnail downloads are on from the start, and each one has its own switch in Settings. The extras that are on by default run signed out. Only the YouTube Features tab in Settings, where you switch them, is behind a sign-in, and [Account and sync](/docs/account-and-sync) covers that.

## The core controls

Speed, the widget and the shortcuts work on YouTube as they do everywhere. Press `]` to go 0.1x faster, and the speed memory keeps a speed for each video.

## What is on by default

Most YouTube extras are on from the start. A few are off until you turn them on.

| Extra | What it does | Default |
|---|---|---|
| Dislike Counter | Shows dislike counts, using the Return YouTube Dislike API | On, and in the right-click menu |
| Comment Search | Searches within a video's comments | On, and in the right-click menu |
| Channel Blocker | Keeps a channel out of your recommendations | On, and in the right-click menu |
| Thumbnail Downloader | Downloads the video thumbnail | On |
| Subtitle Downloader | Downloads the subtitles | On |
| Shorts Blocker | Hides Shorts from the YouTube feed | Off |
| Auto Wide | Always plays in YouTube's wide theater layout | Off |
| Ad Skip | Clicks YouTube's own Skip Ad button when YouTube shows it | Off |

Ad Skip clicks the button YouTube shows. It does not remove ads, and it does nothing until the button is there.

## Where the switches are

1. Open Settings.
2. Go to the **YouTube Features** tab.
3. Sign in if the tab asks you to.

The extras are grouped: Comments, Discovery & Blocking, Navigation, Viewing Experience, Player, Productivity, Learning, Analytics, Advanced and Downloads.

Each extra has two switches.

| Switch | What it does |
|---|---|
| Enable | Turns the extra on or off |
| Show in right-click menu | Adds the extra to the right-click menu on YouTube |

The extras run only on youtube.com.

## How you run an extra

You run an extra from the YouTube tab in the widget or from the right-click menu, and the labels there are in English today ([why](/docs/user-guide/display-and-widget)).

Only the extras you ticked for the right-click menu appear there. That keeps the menu short.

## Related keys

`Ctrl + Alt + X` copies a link to the video with the current timestamp. The rest of the starting keys are in [Default shortcuts](/docs/keyboard-shortcuts/defaults), and [Change a shortcut](/docs/keyboard-shortcuts/rebinding) moves them.
