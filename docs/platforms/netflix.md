Speed and the core controls work on Netflix; the Netflix extras are off until you switch them on. You switch them on the Netflix Features tab in Settings, which needs an account, and [Account and sync](/docs/account-and-sync) covers that.

## The core controls

Press `]` to go 0.1x faster and `[` to go 0.1x slower, with or without an account.

## Netflix extras are opt-in

1. Open Settings.
2. Go to the **Netflix Features** tab.
3. Connect an account if the tab asks you to.
4. Turn on an extra with its enable switch.
5. Reload the Netflix page.

On/off switches apply after that reload. Menu actions do not wait for one: opening a panel, starting a timer, exporting or downloading from the widget or the right-click menu happens at once.

Each extra also has a "show in right-click menu" switch. The extras run only on netflix.com.

| Extra | What it does | Default |
|---|---|---|
| Skip Recap | Skips "Previously on…" recaps | Off |
| Dual Subtitles | Shows two subtitle languages at once | Off |
| Subtitle Downloader | Downloads subtitles as SRT or VTT | Off |
| Sleep Timer | Pauses after the number of minutes you set | Off |
| Episode Navigator | Moves between episodes | Off |
| Watch Limits | Sets a daily viewing limit | Off |
| Dialogue Boost | Raises voices relative to music and effects | Off |

Watch Limits counts only while a video is playing in a visible tab. A background tab does not use up the daily limit.

## Netflix recovery controls

Netflix sometimes shows a "device isn't part of the Netflix Household" screen. When the extension clears that screen, Netflix keeps its own player controls hidden. Only then do the keyboard controls switch on.

A small notice on the player tells you they are on and links to the full list.

| Key | What it does |
|---|---|
| `Space` | Play or pause |
| `←` / `→` | Back or forward 10 seconds |
| `Shift + ←` / `Shift + →` | Back or forward 1 minute |
| `Ctrl + ←` / `Ctrl + →` | Back or forward 5 minutes |
| `Ctrl + 0` | Jump to the start |
| `Ctrl + 1` to `Ctrl + 9` | Jump to 10% through 90% |
| `Ctrl + -` | Jump to 1 minute before the end |
| `↑` / `↓` | Volume up or down |
| `M` | Mute or unmute |
| `F` | Fullscreen on or off |
| `V` | Next subtitle track, including off |
| `B` | Next audio track |

Each of these keys can be changed in Settings, on the Keyboard Shortcuts tab, under **Netflix Recovery Controls**. A key can belong to only one shortcut, so a recovery key cannot also be one of your general shortcuts.

## Limits

At any other time these keys are Netflix's own.

The extension does not fix every Netflix error. It clears the Household screen and gives you keyboard controls.
