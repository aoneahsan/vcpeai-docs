Add Video Controls Plus from the Chrome Web Store, Microsoft Edge Add-ons or Firefox Add-ons, and speed control works as soon as it is installed.

| Browser | Store page |
|---|---|
| Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/ihafdbecgnhendhckoknblmcminoikdb) |
| Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/video-controls-plus/ghjcpobkbbhefdlgffopfhlepkgcknlb) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/video-controls-plus) |

The same links are on the website's [install page](https://vcpeai.aoneahsan.com/install).

## Add it to your browser

1. Open the store page for your browser from the table above.
2. Add the extension, and confirm when the browser shows the permissions.
3. Pin it to the toolbar from the browser's Extensions button, so the popup is one click away.

A welcome page opens inside the extension. Walk through it or skip it.

## On Firefox

The add-on needs Firefox 140 or newer, and Firefox shows the data the add-on collects when you add it.

There is no Google sign-in in the Firefox add-on today, so the signed-out controls ([list](/docs/account-and-sync)) work on Firefox and the controls that need a sign-in are not available there. [Account and sync](/docs/account-and-sync) lists them.

## What the browser asks for

The extension asks for access to all sites, because it has to find the video on any page you open. Each permission and the reason for it is listed in [Privacy and permissions](/docs/privacy-and-permissions).
