ویڈیو والا کوئی بھی صفحہ کھولیں اور `]` دبائیں۔ رفتار 0.1x بڑھ جائے گی؛ ایکسٹینشن چل رہی ہے۔

## ابتدائی کنٹرولز آزمائیں

1. YouTube، Udemy، Vimeo یا معیاری ویڈیو والی کوئی بھی سائٹ کھولیں۔
2. رفتار 0.1x بڑھانے کے لیے `]` دبائیں۔ بار بار دبانے سے 4x تک جا سکتے ہیں۔
3. رفتار 0.1x گھٹانے کے لیے `[` دبائیں۔
4. پہلے سے مقرر رفتار پر واپس آنے کے لیے `=` دبائیں۔
5. فوراً 2x رفتار پر جانے کے لیے `Ctrl + Alt + 4` دبائیں۔

رفتار کے کنٹرول کے لیے اکاؤنٹ ضروری نہیں۔ اسی کی بورڈ سے `,` اور `.` کے ذریعے ویڈیو کو ایک ایک فریم چلا سکتے ہیں۔ تصویر در تصویر اکاؤنٹ جوڑنے کے بعد کھلتی ہے۔

## تیرتا کنٹرول پینل تلاش کریں

یہ ویڈیو کے صفحے پر نظر آنے والا تیرتا کنٹرول پینل ہے۔ اسے کھولنے کے لیے کلک کریں اور اپنی پسند کی جگہ کھینچ کر رکھیں۔

اسے چھپانے کے لیے `Esc` یا `Ctrl + Alt + H` دبائیں؛ دوبارہ دبانے پر واپس آ جائے گا۔

## ٹول بار پینل اور ترتیبات کھولیں

ٹول بار میں Video Controls Plus کا آئیکن دبائیں۔ کھلنے والا پینل موجودہ سائٹ اور اس پر ایکسٹینشن کی حالت دکھاتا ہے۔ یہیں سے آپ [ایک سائٹ پر ایکسٹینشن روک](/docs/getting-started/pause-per-site) سکتے ہیں۔

ترتیبات الگ ٹیب میں کھلتی ہیں۔

## کن کنٹرولز کے لیے اکاؤنٹ چاہیے

رفتار، محفوظ شدہ رفتاریں، فریم بہ فریم چلانا، وقت کا لنک شیئر کرنا، تھیٹر کی وضع، براؤزر میں محفوظ نشان اور تیرتا پینل اکاؤنٹ کے بغیر چلتے ہیں۔ اکاؤنٹ جوڑنے پر یہ کنٹرولز کھلتے ہیں:

| کنٹرول | اکاؤنٹ جوڑنے کے بعد آزمانے والی کنجی |
|---|---|
| A-B دہرائی | `Ctrl + Alt + A`، پھر `Ctrl + Alt + B` |
| تصویر در تصویر | `Ctrl + Alt + P` |
| آواز میں اضافہ | `Ctrl + Alt + U` |
| ویڈیو فلٹرز | `Ctrl + Alt + F` |
| اسکرین شاٹس | `Ctrl + Alt + C` |
| وقت کے نشان والے نوٹس | تیرتے پینل کے ٹولز ٹیب میں **نوٹ** |
| خودکار چھوڑنا | ترتیبات میں چالو کریں |

ایکسٹینشن کے اندر سائن اِن نہیں ہوتا۔ آپ کا اکاؤنٹ vcpeai.aoneahsan.com پر ہے۔ اسے جوڑنے کے لیے ٹول بار پینل میں **اپنا اکاؤنٹ جوڑیں** دبائیں یا ترتیبات کے اکاؤنٹ اور ہم آہنگی ٹیب میں یہی بٹن دبائیں۔ یہ Chrome، Edge اور Firefox پر کام کرتا ہے۔ مراحل، اکاؤنٹ سے ملنے والی سہولتیں اور محفوظ ہونے والا ڈیٹا [اکاؤنٹ اور ہم آہنگی](/docs/account-and-sync) میں ہیں۔

## کنجی دبانے پر کچھ نہیں ہوتا

حروف اور اعداد والی کنجیوں کے ساتھ `Ctrl + Alt` دبانا ہوتا ہے۔ صرف `[`, `]`, `=`, `\`, `'`, `,`, `.` اور `Esc` اکیلے چلتے ہیں۔ پوری فہرست [پہلے سے مقرر شارٹ کٹس](/docs/keyboard-shortcuts/defaults) میں ہے۔ کنجی بدلنے کا طریقہ [شارٹ کٹ بدلیں](/docs/keyboard-shortcuts/rebinding) میں دیکھیں۔

اگلا صفحہ: [رفتار کا کنٹرول](/docs/user-guide/speed-control)۔
