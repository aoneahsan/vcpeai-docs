Video Controls Plus کو Chrome Web Store، Microsoft Edge Add-ons یا Firefox Add-ons سے شامل کریں۔ انسٹال ہوتے ہی رفتار کا کنٹرول چلنے لگتا ہے۔

| براؤزر | اسٹور کا صفحہ |
|---|---|
| Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/video-controls-plus/ihafdbecgnhendhckoknblmcminoikdb) |
| Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/video-controls-plus/ghjcpobkbbhefdlgffopfhlepkgcknlb) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/video-controls-plus) |

یہی لنک ویب سائٹ کے [انسٹال صفحے](https://vcpeai.aoneahsan.com/install) پر بھی ہیں۔

## براؤزر میں شامل کریں

1. اوپر دی گئی جدول سے اپنے براؤزر کا اسٹور صفحہ کھولیں۔
2. ایکسٹینشن شامل کریں اور براؤزر کے اجازتیں دکھانے پر تصدیق کریں۔
3. براؤزر کے ایکسٹینشنز بٹن سے اسے ٹول بار پر پن کریں تاکہ اس کا پینل ایک کلک پر کھلے۔

ابتدائی صفحہ ایکسٹینشن کے اندر کھلتا ہے۔ اس کے مراحل مکمل کریں یا چھوڑ دیں۔ ایک مرحلے میں **اپنا اکاؤنٹ جوڑیں** کی پیشکش ہوتی ہے؛ اسے چھوڑ کر بعد میں بھی اکاؤنٹ جوڑ سکتے ہیں۔

## Firefox پر

اس ایڈ آن کے لیے Firefox 140 یا نیا ورژن چاہیے۔ اسے شامل کرتے وقت Firefox دکھاتا ہے کہ ایڈ آن کون سا ڈیٹا جمع کرتا ہے۔

Firefox دو اختیاری ڈیٹا اجازتیں بھی مانگتا ہے: استعمال کے واقعات صرف اس وقت بھیجے جاتے ہیں جب آپ ”تکنیکی اور استعمال کا ڈیٹا“ کی اجازت دیں۔ صفحے کا مواد صرف اس وقت بھیجا جاتا ہے جب آپ ”ویب سائٹ کا مواد“ کی اجازت دیں؛ ایڈ آن پہلی ضرورت پر یہ اجازت مانگتا ہے۔ [رازداری اور اجازتیں](/docs/privacy-and-permissions) میں دونوں کی تفصیل ہے۔

Firefox پر اکاؤنٹ اسی طرح جڑتا ہے جیسے Chrome اور Edge پر۔ [اکاؤنٹ اور ہم آہنگی](/docs/account-and-sync) میں اکاؤنٹ جوڑنے کے مراحل اور اس کی ضرورت والے کنٹرولز درج ہیں۔

## براؤزر کیا اجازتیں مانگتا ہے

ایکسٹینشن تمام سائٹس تک رسائی مانگتی ہے تاکہ آپ کے کھولے ہوئے کسی بھی صفحے پر ویڈیو تلاش کر سکے۔ ہر اجازت کی وجہ [رازداری اور اجازتیں](/docs/privacy-and-permissions) میں درج ہے۔

اگلا صفحہ: [پہلی بار استعمال](/docs/getting-started/first-run)۔
