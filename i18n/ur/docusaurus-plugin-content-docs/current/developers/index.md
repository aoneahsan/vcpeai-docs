# ڈیولپرز کے لیے Video Controls Plus

**آپ اپنی Video Controls Plus لائبریری تک ایکسٹینشن سے باہر بھی پہنچ سکتے ہیں، اپنے جوڑے ہوئے ٹولز کے ذریعے:** رسائی کلید والا اسکرپٹ، Claude یا ChatGPT جیسا اسسٹنٹ، یا ویب ہُک سے ہر تبدیلی کی اطلاع لینے والا اپنا سرور۔ یہ تینوں ویب سائٹ پر **Account → [Other apps](https://vcpeai.aoneahsan.com/account/apps)** میں مرتب ہوتے ہیں۔ Free سمیت ہر پلان پر دستیاب ہیں۔

ہر کلید، اسسٹنٹ یا ویب ہُک صرف انہی حصوں تک پہنچتا ہے جنہیں آپ اس کے لیے منتخب کرتے ہیں، اور آپ ہی کی حیثیت سے کام کرتا ہے۔ اسے وہ کچھ نظر نہیں آتا جو آپ خود ویب سائٹ پر نہیں دیکھ سکتے۔

## رسائی کے تین طریقے {#three-ways-in}

| آپ کا مقصد | طریقہ | صفحہ |
|---|---|---|
| اسکرپٹ، اسپریڈشیٹ سنک یا فون کے شارٹ کٹ سے اپنی لائبریری پڑھنا یا بدلنا | رسائی کلید اور REST API | [رسائی کلیدیں](./access-keys.md)، [API](./api.md) |
| Claude، ChatGPT، Claude Code یا Cursor سے اپنے نوٹس اور فلیش کارڈز کے بارے میں پوچھنا | اسسٹنٹ کا پتہ (MCP) | [اسسٹنٹس](./assistants.md) |
| نوٹ یا بک مارک محفوظ ہوتے ہی اپنے سرور کو اطلاع دینا | ویب ہُک کا پتہ | [ویب ہُکس](./webhooks.md) |

## بیرونی ایپ کس چیز تک پہنچ سکتی ہے {#what-an-outside-app-can-reach}

صرف آپ کی منتخب کردہ چیزوں تک، اور صرف آپ کے اپنے ڈیٹا تک:

- اپنے بک مارکس، نوٹس، مجموعے اور ان کی ویڈیوز، فلیش کارڈز، سیکھنے کے راستے اور ان کی ویڈیوز، بعد میں دیکھنے کی فہرست، ٹرانسکرپٹس، ترتیبات اور ایکسٹینشن سے جڑے براؤزر **پڑھ اور بدل** سکتی ہے۔
- دیکھنے کی تاریخ **پڑھ اور اس سے اندراج ہٹا** سکتی ہے۔ تاریخ میں اضافہ صرف ایکسٹینشن کرتی ہے، جب Watch History آن ہو۔
- آپ کے اسکرین شاٹس **پڑھ** سکتی ہے۔ انہیں ہٹانے کے لیے ایکسٹینشن استعمال کریں۔
- کسی حصے کے لیے Delete منتخب ہو تو اسے **حذف** کر سکتی ہے۔ کلید فوراً حذف کرتی ہے؛ اسسٹنٹ کی حذف کی درخواست ویب سائٹ پر آپ کی منظوری کا انتظار کرتی ہے۔
- واچ پارٹیز جن کی آپ میزبانی کرتے ہیں یا جن میں شامل ہوئے ہیں، کمیونٹی کی سائٹ اصلاحات، اور آپ کے ووٹوں سمیت فیچر درخواستیں صرف **پڑھ** سکتی ہے۔
- آپ کا پلان، اس کی حدود اور آج کا استعمال **ہمیشہ پڑھ** سکتی ہے۔

### کن چیزوں تک رسائی کبھی نہیں ملتی {#what-it-never-reaches}

آپ جو بھی منتخب کریں، کوئی کلید، اسسٹنٹ یا ویب ہُک یہ کام نہیں کر سکتا:

- کسی اور کی لائبریری تک پہنچنا، یا بتانا کہ آپ کی واچ پارٹی میں اور کون ہے؛
- واچ پارٹی کی میزبانی یا اس میں شمولیت، ووٹ دینا، سائٹ اصلاح شائع کرنا یا فیچر درخواست بدلنا؛
- آپ کا سائن اِن، دو مرحلہ جاتی کوڈز، ریکوری کوڈز، کلیدیں یا دستخطی راز دیکھنا؛
- آپ کا پلان، ادائیگیاں یا ای میل بدلنا، یا ایکسٹینشن جوڑنا؛
- آپ کے وائس نوٹس، AI کی تاریخ، ادائیگیاں، ریفرلز یا استعمال کے تجزیات پڑھنا؛
- عملے کا صفحہ کھولنا۔

## ہر پلان کی حدود {#limits-on-each-plan}

| | Free | Pro | Team (ہر رکن کے لیے) |
|---|---|---|---|
| رسائی کلیدیں | 5 | 25 | 50 |
| API اور اسسٹنٹ کی روزانہ درخواستیں | 5,000 | 50,000 | 100,000 |
| ویب ہُک پتے | 3 | 20 | 40 |
| اسسٹنٹ کنکشنز | 3 | 10 | 25 |

روزانہ درخواستوں میں آپ کی تمام کلیدوں اور اسسٹنٹس کی درخواستیں مل کر شمار ہوتی ہیں، اور گنتی ہر روز نصف شب UTC پر دوبارہ شروع ہوتی ہے۔ ہر کلید یا اسسٹنٹ کی اپنی حد بھی ہے: ایک منٹ میں 120 درخواستیں، تاکہ قابو سے باہر اسکرپٹ خود رک جائے۔ **Other apps** میں پلان کے مقابلے میں اپنا استعمال دیکھیں۔ پلان اور قیمتیں [Plans](https://vcpeai.aoneahsan.com/plans) پر ہیں۔

## دوبارہ سائن اِن تک کلیدیں اور راز پوشیدہ رہتے ہیں {#keys-and-secrets-stay-hidden}

کلید یا ویب ہُک کا دستخطی راز بناتے وقت پورا صرف ایک بار دکھایا جاتا ہے۔ بعد میں اسے دوبارہ دیکھنے کے لیے پچھلے دس منٹ میں سائن اِن کیا ہونا ضروری ہے؛ اور اگر [دو مرحلہ جاتی سائن اِن](./two-step-sign-in.md) آن ہے تو آتھنٹیکیٹر کا کوڈ بھی چاہیے۔ کھلا چھوڑا ہوا براؤزر کلید نہیں دکھا سکتا۔ نئی کلید بننے، اسسٹنٹ جڑنے یا ویب ہُک پتہ شامل ہونے پر ہم آپ کو ای میل کرتے ہیں۔ ای میل میں کلید یا راز نہیں ہوتا۔
