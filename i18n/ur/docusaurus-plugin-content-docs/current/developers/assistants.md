# اسسٹنٹس

**اسسٹنٹ جوڑ کر آپ اپنی لائبریری کے بارے میں اس سے پوچھ سکتے ہیں:** "پچھلے ہفتے کے لیکچرز کے کون سے فلیش کارڈز کی باری ہے؟"، "اس ویڈیو کے میرے نوٹس کا خلاصہ بناؤ"، "یہ گفتگو بعد میں دیکھنے کی فہرست میں شامل کرو"۔ Claude، ChatGPT، Claude Code اور Cursor سب ایک ہی پتے سے جڑتے ہیں:

```text
https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp
```

اسسٹنٹ آپ کو Video Controls Plus کی ویب سائٹ پر لے جاتا ہے، جہاں آپ سائن اِن کر کے اس کی رسائی منتخب اور منظور کرتے ہیں۔ آپ اسے اپنا پاس ورڈ یا کلید نہیں دیتے۔ یہ پتہ نقل کرنے کے بٹن کے ساتھ **Account → [Other apps](https://vcpeai.aoneahsan.com/account/apps)** میں بھی ہے۔

## جوڑنا {#connecting}

### Claude {#claude}

1. Claude میں **Settings → Connectors** کھولیں اور **Add custom connector** منتخب کریں۔
2. اس کا نام Video Controls Plus رکھیں اور اوپر والا پتہ چسپاں کریں۔
3. Claude ہماری ویب سائٹ کھولتا ہے۔ قابلِ رسائی حصے منتخب کریں اور منظوری دیں۔

### ChatGPT {#chatgpt}

1. ChatGPT میں **Settings → Apps and connectors**، پھر **Advanced** کھولیں اور developer mode آن کریں۔
2. **Create** منتخب کریں، نام Video Controls Plus رکھیں اور اوپر والا پتہ چسپاں کریں۔
3. ChatGPT ہماری ویب سائٹ کھولتا ہے۔ قابلِ رسائی حصے منتخب کریں اور منظوری دیں۔

### Claude Code {#claude-code}

1. ٹرمینل میں یہ چلائیں:

   ```bash
   claude mcp add --transport http video-controls-plus https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp
   ```

2. Claude Code کے اندر `/mcp` چلائیں اور سائن اِن کے لیے Video Controls Plus منتخب کریں۔
3. براؤزر ہماری ویب سائٹ کھولتا ہے۔ قابلِ رسائی حصے منتخب کریں اور منظوری دیں۔

### Cursor {#cursor}

1. Cursor میں **Settings → Tools & MCP** کھولیں اور **New MCP server** منتخب کریں۔
2. کھلنے والی فائل میں یہ سطریں شامل کر کے محفوظ کریں:

   ```json
   { "mcpServers": { "video-controls-plus": { "url": "https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp" } } }
   ```

3. Cursor میں **Needs login** نظر آئے گا۔ اسے دبائیں، ویب سائٹ پر قابلِ رسائی حصے منتخب کریں اور منظوری دیں۔

## آپ کس چیز کی منظوری دیتے ہیں {#what-you-approve}

منظوری کا صفحہ اسسٹنٹ کا نام اور واپسی کی جگہ دکھاتا ہے، پھر [رسائی کلید](./access-keys.md#what-each-tick-reaches) جیسے Read، Change اور Delete کے خانے۔ Delete ابتدا میں بند ہوتا ہے۔ کم از کم ایک قابلِ مطالعہ چیز منتخب کریں یا **Deny** دبائیں؛ مسترد شدہ اسسٹنٹ کو "منظور نہیں" کا جواب ملتا ہے اور وہ کسی چیز تک نہیں پہنچتا۔

[دو مرحلہ جاتی سائن اِن](./two-step-sign-in.md) آن ہو تو منظوری کے لیے کوڈ درج کریں۔ یاد رکھا ہوا براؤزر کوڈ صرف اس وقت چھوڑتا ہے جب کنکشن محض پڑھ سکتا ہو۔ اسسٹنٹ کو بدلنے یا حذف کرنے کی اجازت دینے کے لیے پچھلے دس منٹ کا سائن اِن بھی چاہیے۔ اسسٹنٹ جڑنے کی ای میل آپ کو ملتی ہے۔

وہ جو بھی پڑھے، آپ کی حیثیت سے پڑھے گا۔ اسے آپ کے سائن اِن، کلیدوں یا کسی اور کی لائبریری تک رسائی نہیں۔

## حذف کرنے کے لیے آپ کی منظوری ضروری ہے {#deleting-waits-for-your-yes}

Delete منتخب ہو تب بھی اسسٹنٹ خود کچھ حذف نہیں کرتا۔ آپ نوٹ ہٹانے کو کہیں تو اسے ایک لنک ملتا ہے اور درخواست ویب سائٹ پر آپ کے فیصلے کی منتظر رہتی ہے:

1. اسسٹنٹ لنک دیتا ہے، اور **Other apps** میں یہ **Asked to delete, waiting for you** کے تحت دکھائی دیتا ہے۔
2. لنک کھولیں۔ صفحہ بتاتا ہے کیا حذف ہوگا، وہ کس ویڈیو پر ہے، درخواست کب ہوئی اور جواب دینے کی آخری مہلت کیا ہے۔
3. **Delete the note** (یا بک مارک، کارڈ وغیرہ) دبائیں، یا **Keep it**۔

درخواست دس منٹ رہتی ہے۔ اس کے بعد کچھ حذف نہیں ہوتا؛ ضرورت برقرار ہو تو اسسٹنٹ سے دوبارہ کہیں۔ اگلی بار جانچنے پر اسسٹنٹ کو "حذف ہو گیا" کا جواب ملتا ہے۔

## نام بدلنا اور منقطع کرنا {#renaming-and-disconnecting}

ہر جڑے ہوئے اسسٹنٹ کی **Other apps** میں ایک سطر ہوتی ہے، جس میں جڑنے اور آخری استعمال کا وقت ہے۔ پہچاننے میں آسان نام دیں، یا **Disconnect** اور پھر تصدیق کے لیے اسے دوبارہ دبائیں۔ اس کی اگلی درخواست رد ہو جائے گی۔

## کتنے اسسٹنٹس جوڑ سکتے ہیں {#how-many-you-can-connect}

Free میں 3، Pro میں 10 اور Team میں ہر رکن کے لیے 25 اسسٹنٹ کنکشنز ہیں۔ اسی اسسٹنٹ کو دوبارہ جوڑنے سے پرانی منظوری بدل جاتی ہے؛ اضافی جگہ نہیں لگتی۔ اس کی درخواستیں کلیدوں کے ساتھ روزانہ حد ([حدود](./index.md#limits-on-each-plan)) میں شمار ہوتی ہیں۔

## اسسٹنٹ آپ کی اپنی تحریر پڑھتا ہے {#your-own-writing}

آپ کے نوٹس، لیبل اور کارڈ کا متن اسی شکل میں اسسٹنٹ کو ڈیٹا کے طور پر جاتا ہے جس میں آپ نے لکھا ہے۔ نوٹ میں چسپاں کردہ ہدایات بھی اسے آپ کی لائبریری کا متن نظر آتی ہیں۔ گفتگو کے لیے صرف ضروری حصے منتخب کریں۔

## MCP کلائنٹ بنانے والوں کے لیے {#for-mcp-client-developers}

| | |
|---|---|
| ٹرانسپورٹ | Streamable HTTP، stateless، ایک endpoint |
| سائن اِن | OAuth 2.1 مع PKCE، ہمارے Supabase authorization server `https://gjajgvsjhdbtrpvfiuwl.supabase.co/auth/v1` کے ذریعے |
| دریافت | Protected-resource metadata: `https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp/.well-known/oauth-protected-resource` |
| ٹوکن نہ ہو | `401` اور metadata کی طرف اشارہ کرنے والا `WWW-Authenticate` ہیڈر |
| رسائی کلیدیں | اپنے چلائے ہوئے کلائنٹ میں `vcp_pat_` کلید bearer token کے طور پر بھی استعمال ہو سکتی ہے |
| حدود | ہر کنکشن پر ایک منٹ میں 120 درخواستیں، اور پلان کی روزانہ حد |

ٹولز [API](./api.md#your-library) والے انہی حصوں سے بنتے ہیں: `list_<part>`، `get_<part>`، `create_<part>`، `update_<part>` اور `prepare_delete_<part>`، جہاں حصہ اجازت دے۔ `tools/list` صرف اسی کنکشن کی منتخب اجازتوں کے مطابق ٹولز دکھاتا ہے۔ مشترکہ حصوں اور آپ کے پلان کے لیے صرف list اور get ٹولز ہیں؛ وائس نوٹس اور AI کی تاریخ کسی ٹول میں نہیں۔
