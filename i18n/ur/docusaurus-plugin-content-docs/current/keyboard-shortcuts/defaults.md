حروف اور اعداد کی کنجیوں کے ساتھ `Ctrl + Alt` دبانا ہوتا ہے۔ صرف `[`, `]`, `=`, `\`, `'`, `,`, `.` اور `Esc` اکیلے چلتے ہیں، تاکہ ایکسٹینشن کی کنجیاں سائٹ کے اپنے پلیئر کی کنجیوں سے نہ ٹکرائیں۔

آخری ستون میں ”ہاں“ کا مطلب ہے کہ جوڑا ہوا اکاؤنٹ ضروری ہے۔ [اکاؤنٹ اور ہم آہنگی](/docs/account-and-sync) میں اس کی سہولتیں ہیں۔

## رفتار

ترتیبات کے رفتار کے حصے میں رفتار اور تیرتے پینل کی کنجیاں ہیں۔

| کنجی | کام | اکاؤنٹ چاہیے؟ |
|---|---|---|
| `[` | رفتار 0.1x گھٹائیں | نہیں |
| `]` | رفتار 0.1x بڑھائیں | نہیں |
| `=` | پہلے سے مقرر رفتار پر واپس | نہیں |
| `\` | موجودہ رفتار دکھائیں | نہیں |
| `'` | عمومی ٹیب میں مقرر موجودہ بدلتی رفتار لگائیں | نہیں |
| `Esc` | تیرتا پینل چھپائیں یا دکھائیں | نہیں |
| `Ctrl + Alt + H` | تیرتا پینل چھپائیں یا دکھائیں | نہیں |

## اعلیٰ کنٹرولز

| کنجی | کام | اکاؤنٹ چاہیے؟ |
|---|---|---|
| `Ctrl + Alt + P` | تصویر در تصویر چالو یا بند | ہاں |
| `Ctrl + Alt + S` | Netflix اور Prime Video کا تعارف چھوڑیں | ہاں |

## اختیاری شارٹ کٹس

ان کی کنجی پہلے سے مقرر نہیں۔ ترتیبات کے کی بورڈ شارٹ کٹس ٹیب میں متعلقہ گروہ کھولیں، **کنجی مقرر کریں** دبائیں اور مطلوبہ کنجیاں دبائیں۔ کنجی کسی دوسرے شارٹ کٹ کی ہو تو ترتیبات اس کا نام اور اس تک جانے کا لنک دیتی ہیں۔

| ترتیبات کا گروہ | شارٹ کٹ | اکاؤنٹ چاہیے؟ |
|---|---|---|
| آرام | آنکھوں کا آرام بدلیں | نہیں |
| آرام | رنگ دیکھنے میں مدد بدلیں | نہیں |
| نشانات | توجہ کی وضع بدلیں | نہیں |
| آرام | سب ٹائٹلز کی شکل بدلیں | نہیں |
| آرام | پڑھنے کی رہنما لکیر بدلیں | نہیں |
| مطالعہ | ٹائمر شروع یا روکیں | نہیں |
| مطالعہ | ویڈیو کا متن دکھائیں یا چھپائیں | نہیں |
| اثرات | اثرات چالو یا بند کریں | ہاں |
| اثرات | ویڈیو کا حصہ دھندلا کریں | ہاں |
| آواز کے ٹولز | آواز کے ٹولز چالو یا بند کریں | ہاں |
| آواز کے ٹولز | بائیں دائیں بدلیں | ہاں |
| تصویر اور ویڈیو | کلپ ریکارڈ یا بند کریں | ہاں |
| تصویر اور ویڈیو | GIF بنائیں | ہاں |
| تصویر اور ویڈیو | اسکرین شاٹ پر نشان لگائیں | ہاں |
| خودکار کنٹرول | اس سائٹ پر خود چلنا روکیں | نہیں |
| خودکار کنٹرول | رفتار بتدریج بڑھانا شروع یا بند کریں | نہیں |

ہر گروہ کی تفصیل [آرام اور رسائی](/docs/user-guide/comfort-and-accessibility)، [مطالعے کے ٹولز](/docs/user-guide/study-tools)، [منظر کے اثرات اور زوم](/docs/user-guide/visual-effects)، [آواز کے ٹولز](/docs/user-guide/audio-tools)، [تصویر اور ویڈیو محفوظ کرنا](/docs/user-guide/capture-and-export) اور [خودکار پلے بیک](/docs/user-guide/playback-automation) میں ہے۔

## براؤزر کی کنجیاں

یہ چار شارٹ کٹس براؤزر مقرر کرتا ہے۔ براؤزر طے کرتا ہے کہ کون سی کنجی دی گئی ہے؛ اس کے ایکسٹینشن شارٹ کٹس صفحے پر بدلیں۔ ایکسٹینشن کے اندر نہیں بدل سکتے۔

| مجوزہ کنجی | کام |
|---|---|
| `Alt + V` | ٹول بار پینل کھولیں |
| `Ctrl + Shift + V` (Mac پر `Command + Shift + V`) | تیرتے کنٹرولز دکھائیں یا چھپائیں |
| `Ctrl + Shift + P` (Mac پر `Command + Shift + P`) | تصویر در تصویر چالو یا بند |
| `Ctrl + Shift + C` (Mac پر `Command + Shift + C`) | اسکرین شاٹ لیں |

## Netflix

Netflix کی اپنی کنجیاں صرف ایک خاص حالت میں چلتی ہیں۔ ان کی فہرست [Netflix صفحے](/docs/platforms/netflix) پر ہے۔

کنجی بدلنے کے لیے [شارٹ کٹ بدلیں](/docs/keyboard-shortcuts/rebinding) دیکھیں۔
