ادائیگی کے بعد لائسنس کی ای میل میں کلید اور یہ مراحل ملتے ہیں۔ ہر اسٹور اپنا جائزہ خود لیتا ہے، اس لیے وقت اس کے مطابق بدلتا ہے۔

1. **قیمتوں کے صفحے پر ادائیگی کریں۔** نام، ای میل اور ویب سائٹ کا ڈومین دیں، پھر **ادائیگی کی طرف جائیں** دبائیں۔ ادائیگی کا صفحہ اسی ٹیب میں کھلتا ہے۔ Wise بینک ٹرانسفر سے ادائیگی کر کے حوالہ نمبر ہمیں بھیجیں۔ ٹرانسفر کی تصدیق کے بعد لائسنس جاری ہوتا ہے۔
2. **لائسنس کی ای میل کا جواب دیں** اور پروڈکٹ کا نام، SVG یا بڑے PNG میں لوگو، رنگ اور ڈومین بھیجیں۔
3. **ہم آپ کی کاپی بناتے ہیں۔** ایکسٹینشن اور ویب سائٹ پر آپ کا نام اور رنگ ہوتے ہیں۔ اسٹور فہرست کا متن اور تصاویر منظوری کے لیے بھیجتے ہیں۔
4. **ہم ایکسٹینشن شائع کرتے ہیں** آپ کے Chrome Web Store، Firefox Add-ons اور Microsoft Edge Add-ons ڈیولپر اکاؤنٹس کے تحت۔ آپ ہمیں ہر اکاؤنٹ میں شامل کرتے ہیں یا اسٹور کے طریقے سے رسائی دیتے ہیں۔
5. **ہم آپ کا ڈومین جوڑتے ہیں** اور ویب سائٹ شائع کرتے ہیں۔ آپ ہماری بتائی DNS اندراجات شامل کرتے ہیں۔
6. **ویب سائٹ جاری ہونے پر لائسنس چلتا ہے۔** سائٹ لائسنس فائل پیش کرتی ہے اور [کوئی بھی اسے جانچ سکتا ہے](./verify.md)۔

## پہلے سے کیا تیار رکھیں

- ہر اسٹور کا ڈیولپر اکاؤنٹ: Chrome Web Store، Firefox Add-ons (مفت) اور Edge کے لیے Microsoft Partner Center۔
- ڈومین کی DNS ترتیبات تک رسائی۔
- لوگو اور رنگ۔

نام، لوگو اور رنگ سے آگے آپ کی کاپی کے کام میں تبدیلی [مخصوص کام](https://vcpeai.aoneahsan.com/white-label/custom-work) ہے، جس کی الگ قیمت دی جاتی ہے۔
