Netflix پر رفتار اور بنیادی کنٹرولز چلتے ہیں۔ Netflix کے اضافی ٹولز آپ کے چالو کرنے تک بند رہتے ہیں۔ انہیں ترتیبات کے Netflix خصوصیات ٹیب میں چالو کریں؛ اس ٹیب کے لیے اکاؤنٹ چاہیے۔ [اکاؤنٹ اور ہم آہنگی](/docs/account-and-sync) میں طریقہ ہے۔

## بنیادی کنٹرولز

اکاؤنٹ کے ساتھ یا بغیر `]` سے رفتار 0.1x بڑھائیں اور `[` سے 0.1x گھٹائیں۔

## اضافی ٹولز خود چالو کریں

1. ترتیبات کھولیں۔
2. **Netflix خصوصیات** ٹیب پر جائیں۔
3. ٹیب کہے تو اکاؤنٹ جوڑیں۔
4. مطلوبہ ٹول کا سوئچ چالو کریں۔
5. Netflix کا صفحہ دوبارہ لوڈ کریں۔

چالو/بند سوئچ دوبارہ لوڈ کرنے کے بعد لگتے ہیں۔ مینو کے اعمال فوراً چلتے ہیں: پینل کھولنا، ٹائمر شروع کرنا، برآمد یا ڈاؤن لوڈ کرنا۔

ہر ٹول کا ”دائیں کلک کے مینو میں دکھائیں“ سوئچ بھی ہے۔ یہ صرف netflix.com پر چلتے ہیں۔ تمام 50 ٹولز اور Netflix کی اپنی حفاظتی حدیں [ہر Netflix ٹول کی رہنمائی](https://vcpeai.aoneahsan.com/blog/netflix-extras-guide) میں ہیں۔

| ٹول | کام | ابتدائی حالت |
|---|---|---|
| گزشتہ خلاصہ چھوڑیں | ”اس سے پہلے…“ والا خلاصہ چھوڑتا ہے | بند |
| دو زبانوں کے سب ٹائٹلز | ایک ساتھ دو زبانیں دکھاتا ہے | بند |
| سب ٹائٹلز ڈاؤن لوڈ | SRT یا VTT میں محفوظ کرتا ہے | بند |
| نیند کا ٹائمر | مقررہ منٹ بعد ویڈیو روکتا ہے | بند |
| قسطوں میں جانا | قسطیں بدلتا ہے | بند |
| دیکھنے کی حدیں | روزانہ دیکھنے کا وقت محدود کرتا ہے | بند |
| مکالمے بلند کریں | موسیقی اور اثرات کے مقابل آواز بلند کرتا ہے | بند |

دیکھنے کی حد صرف نظر آنے والے ٹیب میں ویڈیو چلنے کے دوران شمار ہوتی ہے؛ پس منظر کا ٹیب روزانہ حد نہیں کھاتا۔

## Netflix کے پوشیدہ کنٹرولز کی جگہ کی بورڈ

Netflix کبھی ”یہ آلہ Netflix Household کا حصہ نہیں“ والا صفحہ دکھاتا ہے۔ ایکسٹینشن اسے ہٹائے تو Netflix اپنے پلیئر کے کنٹرول چھپائے رکھتا ہے۔ صرف اسی حالت میں نیچے کی کنجیاں چلتی ہیں۔

پلیئر پر مختصر اطلاع ان کے چلنے اور پوری فہرست کا لنک بتاتی ہے۔

| کنجی | کام |
|---|---|
| `Space` | ویڈیو چلائیں یا روکیں |
| `←` / `→` | 10 سیکنڈ پیچھے یا آگے |
| `Shift + ←` / `Shift + →` | 1 منٹ پیچھے یا آگے |
| `Ctrl + ←` / `Ctrl + →` | 5 منٹ پیچھے یا آگے |
| `Ctrl + 0` | آغاز پر جائیں |
| `Ctrl + 1` سے `Ctrl + 9` | ویڈیو کے 10٪ سے 90٪ مقام تک جائیں |
| `Ctrl + -` | اختتام سے 1 منٹ پہلے جائیں |
| `↑` / `↓` | آواز بڑھائیں یا گھٹائیں |
| `M` | خاموش کریں یا آواز بحال کریں |
| `F` | پوری اسکرین چالو یا بند |
| `V` | اگلا سب ٹائٹل ٹریک، بند حالت سمیت |
| `B` | اگلا آڈیو ٹریک |

ہر کنجی ترتیبات کے کی بورڈ شارٹ کٹس ٹیب میں **Netflix کے متبادل کنٹرولز** کے تحت بدل سکتے ہیں۔ ایک کنجی صرف ایک شارٹ کٹ کی ہو سکتی ہے، اس لیے ان میں سے کوئی کنجی عمومی شارٹ کٹ کی بھی نہیں ہو سکتی۔

## حدود

دوسری حالتوں میں یہ Netflix کی اپنی کنجیاں رہتی ہیں۔

ایکسٹینشن Netflix کی ہر خرابی درست نہیں کرتی۔ یہ Household والا صفحہ ہٹاتی اور کی بورڈ کنٹرول دیتی ہے۔

## متعلقہ کنجیاں

عمومی کنجیاں [پہلے سے مقرر شارٹ کٹس](/docs/keyboard-shortcuts/defaults) میں ہیں۔ کوئی بھی کنجی، متبادل ہو یا عمومی، [شارٹ کٹ بدلیں](/docs/keyboard-shortcuts/rebinding) سے بدلیں۔
