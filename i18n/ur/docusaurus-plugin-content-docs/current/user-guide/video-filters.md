فلٹرز میں 0٪ سے 200٪ تک چمک، تضاد اور رنگوں کی شدت، نیز سیاہ و سفید، الٹے رنگ اور رات کی وضع شامل ہیں۔ [اکاؤنٹ جوڑنے](/docs/account-and-sync) کے بعد `Ctrl + Alt + F` سے تیرتے پینل کا فلٹرز ٹیب کھولیں۔

## کنٹرولز

| کنٹرول | حد یا اثر | کنجی |
|---|---|---|
| فلٹرز ٹیب | ٹیب کھولتا یا بند کرتا ہے | `Ctrl + Alt + F` |
| چمک | 0٪ سے 200٪ | سلائیڈر |
| تضاد | 0٪ سے 200٪ | سلائیڈر |
| رنگوں کی شدت | 0٪ سے 200٪ | سلائیڈر |
| سیاہ و سفید | چالو یا بند | `Ctrl + Alt + G` |
| الٹے رنگ | چالو یا بند | `Ctrl + Alt + I` |
| رات کی وضع | چالو یا بند | `Ctrl + Alt + T` |

100٪ پر تصویر ویسی ہی ہے جیسی سائٹ بھیجتی ہے۔ اس سے کم پر اثر گھٹتا ہے، زیادہ پر بڑھتا ہے؛ ہر سلائیڈر 200٪ پر رکتا ہے۔ اسی ٹیب کا **تمام فلٹرز پہلے جیسے کریں** سب واپس کرتا ہے۔

## کون سا فلٹر کب استعمال کریں

سفید پس منظر پر ہلکا سرمئی متن پڑھنا مشکل ہو تو تضاد بڑھائیں۔

روشن دوپہر میں تاریک ویڈیو واضح نہ ہو تو چمک بڑھائیں۔

رات کو سفید بورڈ کا لیکچر تاریک کمرے میں بہت روشن لگے تو `Ctrl + Alt + I` سے رنگ الٹیں، یا `Ctrl + Alt + T` سے رات کی وضع لگائیں۔

## محفوظ فلٹرز

تینوں سلائیڈر اپنی پسند کے مطابق رکھ کر فلٹرز ٹیب میں ترتیب محفوظ کریں۔ زیادہ سے زیادہ 20 فلٹر محفوظ ہو سکتے ہیں۔ یہ ترتیبات کا حصہ ہیں، اس لیے [ترتیبات برآمد کرنے](/docs/account-and-sync) پر شامل ہو سکتے ہیں۔

## تصویر کے مزید کنٹرولز

تیرتے پینل کے دو اور ٹیب تصویر بدلتے ہیں؛ یہ فلٹرز ٹیب سے الگ ہیں۔

| جگہ | کنٹرول | کام |
|---|---|---|
| منظر ٹیب، **شکل بدلیں** | گھمائیں، آئینہ بنائیں، پلٹیں | تصویر 90 درجے گھمائیں یا افقی و عمودی طور پر پلٹیں |
| ٹولز ٹیب، **منظر کی وضعیں** | اردگرد روشنی | پلیئر کے گرد روشنی |
| ٹولز ٹیب، **منظر کی وضعیں** | سنیما | سنیما جیسی رنگوں کی ترتیب |
| ٹولز ٹیب، **منظر کی وضعیں** | سیاہ پٹیاں | تصویر کے اوپر اور نیچے سنیما جیسی پٹیاں |

فلٹرز براؤزر میں ویڈیو دکھانے کا طریقہ بدلتے ہیں۔ اسکرین شاٹ اور ڈاؤن لوڈ الگ کنٹرولز ہیں۔

## متعلقہ کنجیاں

فلٹرز کی کنجیاں [پہلے سے مقرر شارٹ کٹس](/docs/keyboard-shortcuts/defaults) میں ہیں۔ [شارٹ کٹ بدلیں](/docs/keyboard-shortcuts/rebinding) میں انہیں بدلنے کے مراحل ہیں۔
