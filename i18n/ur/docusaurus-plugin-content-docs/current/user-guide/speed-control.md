رفتار 0.1x کے وقفوں سے بدلنے کے لیے `]` یا `[` دبائیں، یا تیرتے پینل کا سلائیڈر 4x تک کھینچیں۔ بریکٹ کنجیاں `Ctrl + Alt` کے بغیر چلتی ہیں اور رفتار کے کنٹرول کے لیے اکاؤنٹ نہیں چاہیے۔

## رفتار کی کنجیاں

| کنجی | کام |
|---|---|
| `]` | رفتار 0.1x بڑھائیں |
| `[` | رفتار 0.1x گھٹائیں |
| `=` | پہلے سے مقرر رفتار پر واپس جائیں |
| `\` | موجودہ رفتار دکھائیں |
| `'` | بدلتی رفتار کے ساتھ ہم آہنگ کریں |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## رفتار کی حد

رفتار 0.1x سے 16x تک ہے۔ سلائیڈر اور بریکٹ کنجیاں 4x پر رکتی ہیں۔ تیرتے پینل کے رفتار ٹیب میں اپنی رفتار کا خانہ، یا ترتیبات کے عمومی ٹیب میں **اپنی رفتار (0.1x - 16x)** کے خانے استعمال کریں؛ ویڈیو 16x تک چل سکتی ہے۔

ہر قدم 0.1x کا ہے۔ ترتیبات میں کم ترین، زیادہ ترین یا قدم کی رفتار بدلنے کا کنٹرول نہیں۔

## پہلے سے مقرر اور بدلتی رفتار

ترتیبات کا عمومی ٹیب کھولیں۔

| ترتیب | مطلب | کنجی |
|---|---|---|
| پہلے سے مقرر پلے بیک رفتار | ری سیٹ کرنے یا نئی ویڈیو کھلنے پر لگنے والی رفتار | `=` |
| موجودہ بدلتی رفتار | یہاں مقرر کی گئی دوسری رفتار جو ایک کنجی سے لگتی ہے | `'` |

`'` موجودہ بدلتی رفتار لگاتی ہے؛ یہ ویڈیو کے لیے محفوظ رفتار نہیں۔

## محفوظ رفتاریں

`Ctrl + Alt + 1` سے `Ctrl + Alt + 8` پر آٹھ رفتاریں ہیں۔ ہر ایک بدل سکتے ہیں اور غیر ضروری رفتاریں ہٹا سکتے ہیں۔ یہ ترتیبات کے کی بورڈ شارٹ کٹس ٹیب میں ہوتا ہے۔

نویں رفتار شامل کریں تو `Ctrl + Alt + 9` استعمال کریں۔

## رفتار یاد رکھیں

ایکسٹینشن ویڈیو کے لیے آپ کی مقررہ رفتار یاد رکھتی ہے اور دوبارہ کھولنے پر لگا دیتی ہے۔ یہ پہلے سے چالو ہے۔

یہ پوری پلے لسٹ یا کورس کی ایک رفتار بھی یاد رکھ سکتی ہے؛ یہ سوئچ پہلے سے بند ہے اور ترتیبات کے اعلیٰ ٹیب میں چالو ہوتا ہے۔

ایک ویڈیو کی ایک سے زیادہ رفتاریں محفوظ ہوں تو **رفتار کی ترجیح** طے کرتی ہے کہ کون سی لگے:

| ترتیب | لگنے والی رفتار |
|---|---|
| پلے لسٹ / کورس پہلے | پلے لسٹ یا کورس کی محفوظ رفتار |
| ویڈیو پہلے | ویڈیو کی محفوظ رفتار |
| صرف عمومی رفتار؛ محفوظ شدہ نظر انداز | پہلے سے مقرر رفتار، محفوظ رفتاریں نظر انداز |

## متعلقہ کنجیاں

`,` اور `.` سے ایک فریم پیچھے یا آگے جائیں۔

پوری فہرست [پہلے سے مقرر شارٹ کٹس](/docs/keyboard-shortcuts/defaults) میں ہے؛ [شارٹ کٹ بدلیں](/docs/keyboard-shortcuts/rebinding) تبدیلی کا طریقہ بتاتا ہے۔

اگلا کنٹرول [A-B دہرائی](/docs/user-guide/ab-loop) ہے۔
