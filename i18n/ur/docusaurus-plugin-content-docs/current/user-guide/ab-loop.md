A-B دہرائی آپ کے مقرر کردہ دو نقطوں کے درمیان ویڈیو بار بار چلاتی ہے۔ اس کے لیے [اکاؤنٹ](/docs/account-and-sync) ضروری ہے، رفتار کے کنٹرول کے لیے نہیں۔ اگر دہرائی کی کنجیاں کام نہ کریں تو پہلے اکاؤنٹ جوڑیں۔

## حصہ مقرر کریں

1. ویڈیو اس جگہ تک چلائیں جہاں مشکل حصہ شروع ہوتا ہے۔
2. `Ctrl + Alt + A` دبائیں؛ یہ نقطہ A ہے۔
3. ویڈیو اس حصے کے اختتام تک چلنے دیں۔
4. `Ctrl + Alt + B` دبائیں؛ یہ نقطہ B ہے۔

B پر پہنچتے ہی ویڈیو A پر واپس آتی ہے اور آپ کے ختم کرنے تک وہ حصہ دہراتی ہے۔ تیرتے پینل کے دہرائی والے ٹیب میں بھی A اور B ایک ایک کلک سے مقرر کر سکتے ہیں۔

گٹار کے سبق کی ایک تیز دھن، لیکچر میں 40 سیکنڈ میں گزر جانے والا ثبوت، یا زبان سیکھنے والی ویڈیو کا مشکل جملہ: مطلوبہ حصے کے گرد A اور B رکھیں، `[` سے رفتار گھٹائیں، اور ضرورت تک سنتے رہیں۔

## دہرائی کی کنجیاں

| کنجی | کام |
|---|---|
| `Ctrl + Alt + A` | آغاز (A) مقرر کریں |
| `Ctrl + Alt + B` | اختتام (B) مقرر کریں |
| `Ctrl + Alt + L` | دہرائی چالو یا بند کریں |
| `Ctrl + Alt + Backspace` | دونوں نقطے ہٹائیں |

## دہرائی کے طریقے

تیرتے پینل کے دہرائی والے ٹیب میں طریقہ منتخب کریں۔ براؤزر کی زبان انگریزی، ہسپانوی، فرانسیسی یا جرمن ہو تو اس کے نام اسی زبان میں ہوتے ہیں ([زبان بدلیں](/docs/user-guide/display-and-widget))۔

| طریقہ | B پر کیا ہوتا ہے |
|---|---|
| مسلسل | بند کرنے تک حصہ دہرایا جاتا ہے |
| ایک بار | حصہ ایک بار دہرایا جاتا ہے |
| مقررہ تعداد | آپ کی مقررہ 1 سے 20 بار دہرایا جاتا ہے |

مقررہ تعداد پر پیش رفت دکھتی ہے اور گنتی 20 پر رکتی ہے۔ زیادہ بار سننا ہو تو مسلسل طریقہ استعمال کریں اور خود `Ctrl + Alt + L` سے بند کریں۔

## متعلقہ کنجیاں

`,` اور `.` سے ایک فریم پیچھے یا آگے جائیں؛ اس طرح A اور B درست لمحے پر لگتے ہیں۔ تمام کنجیاں [پہلے سے مقرر شارٹ کٹس](/docs/keyboard-shortcuts/defaults) میں ہیں اور [شارٹ کٹ بدلیں](/docs/keyboard-shortcuts/rebinding) سے بدلی جا سکتی ہیں۔

اگلا صفحہ: [آواز میں اضافہ](/docs/user-guide/audio-boost)۔
