اکاؤنٹ جوڑنے کے بعد `Ctrl + Alt + P` دبائیں۔ ویڈیو تصویر در تصویر والی چھوٹی ونڈو میں آ جائے گی۔ واپس لانے کے لیے یہی کنجیاں دوبارہ دبائیں۔

## استعمال کریں

1. ویڈیو چلائیں۔
2. `Ctrl + Alt + P` دبائیں۔
3. دوسرے ٹیب پر جائیں۔ ویڈیو اپنی چھوٹی ونڈو میں چلتی رہے گی۔
4. تصویر در تصویر بند کرنے کے لیے `Ctrl + Alt + P` دوبارہ دبائیں۔

کنجیاں اس ونڈو پر بھی چلتی ہیں: `]` اور `[` سے وہاں بھی رفتار بدلتی ہے، اور رفتار کے باقی کنٹرولز بھی کام کرتے ہیں۔

## صفحہ نیچے کرنے پر خود کھولیں

طویل صفحے پر نیچے متن پڑھتے وقت ویڈیو نظروں سے اوجھل ہو سکتی ہے۔ ایکسٹینشن اس وقت اسے خود چھوٹی ونڈو میں لے جا سکتی ہے۔

1. ترتیبات کا اعلیٰ ٹیب کھولیں۔
2. **پلے بیک کی خصوصیات** تلاش کریں۔
3. **تصویر در تصویر** چالو رکھیں۔
4. **صفحہ نیچے کرنے پر خود تصویر در تصویر کھولیں** چالو کریں۔

## متعلقہ کنجیاں

| کنجی | کام |
|---|---|
| `Ctrl + Alt + P` | تصویر در تصویر چالو یا بند |
| `Ctrl + Alt + Z` | تھیٹر کی وضع چالو یا بند |
| `]` / `[` | چھوٹی ونڈو میں بھی رفتار 0.1x بڑھائیں یا گھٹائیں |
