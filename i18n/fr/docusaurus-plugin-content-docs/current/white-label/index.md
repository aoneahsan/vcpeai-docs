Avec une licence en marque blanche, l’équipe Video Controls Plus exploite l’extension pour votre entreprise sous votre nom. Vos utilisateurs installent votre extension depuis le Chrome Web Store, Firefox Add-ons ou Microsoft Edge Add-ons, tandis que son site compagnon fonctionne sur votre domaine. Nous la construisons, la publions, hébergeons le site et livrons les mises à jour. Vous n’avez pas à gérer le code.

Deux formules sont proposées. La [page Marque blanche](https://vcpeai.aoneahsan.com/white-label) les compare :

| | Licence en marque blanche | Rachat du code source |
|---|---|---|
| Qui l’exploite | Notre équipe, sous votre marque | Vous |
| Code source | Reste chez nous | Tous les dépôts nécessaires à la construction de l’extension vous sont remis |
| Pouvons-nous la vendre à d’autres ? | Oui, jusqu’à un rachat intégral | Non, les ventes cessent après le rachat |
| Mises à jour | Six mois inclus, puis renouvellement possible | Six mois inclus, puis renouvellement possible |
| Paiements après l’achat initial | Renouvellements, si vous souhaitez d’autres mises à jour | Renouvellements facultatifs et redevance de 7 % du chiffre d’affaires brut généré, payée chaque trimestre tant que le produit génère des revenus |

Video Controls Plus est vendu comme un seul groupe de plateformes : l’extension pour Chrome, Firefox et Edge ensemble. Puisqu’il n’y a qu’un groupe, aucune remise pour combinaison de groupes ne s’applique.

Les tarifs et le paiement figurent sur la [page des tarifs](https://vcpeai.aoneahsan.com/white-label/pricing), alimentée directement par notre service de licences. Le rachat possède sa [propre page](https://vcpeai.aoneahsan.com/white-label/buyout).
