Dans l’onglet **Outils** du widget, **Partager et regarder ensemble** permet d’envoyer un lien vers le passage actuel, de créer un extrait pour les réseaux sociaux ou d’organiser une séance à plusieurs. Le partage d’un passage ne demande pas de compte. Les extraits et les séances demandent [un compte connecté](/fr/docs/account-and-sync) ; chaque participant à une séance doit également être connecté.

## Partager ce passage {#share-this-moment}

Appuyez sur **Partager ce passage**. Le panneau affiche un lien au minutage actuel, identique à celui copié avec `Ctrl + Alt + X`.

- **Copier le lien** le place dans le presse-papiers.
- Le **QR code** est créé sur votre appareil. **Enregistrer le QR code** télécharge un PNG.
- Les boutons du bas permettent de partager sur X, Facebook, LinkedIn, WhatsApp, Telegram, Reddit ou par courriel.

## Extrait pour les réseaux sociaux {#clip-for-social}

Choisissez un **format d’extrait** : original, carré 1:1 ou vertical 9:16. Appuyez ensuite sur **Extrait pour les réseaux sociaux**. L’[enregistreur d’extraits](/fr/docs/user-guide/capture-and-export) recadre l’image au centre. **■ Arrêter l’extrait** termine l’enregistrement. Les vidéos protégées ne peuvent pas être enregistrées ainsi.

## Démarrer une séance à plusieurs {#start-a-watch-party}

1. Ouvrez la vidéo à regarder ensemble.
2. Appuyez sur **Démarrer une séance à plusieurs**.
3. Appuyez sur **Copier le lien d’invitation**, ou transmettez le code de séance à 10 caractères.
4. La personne qui reçoit le lien voit la page « Vous êtes invité à regarder ensemble » et appuie sur **Ouvrir la vidéo et rejoindre**. Avec le code, elle ouvre la même vidéo, le saisit sous **Code de séance**, puis appuie sur **Rejoindre**.

Pendant la séance, le widget affiche les participants et le code. Lecture, pause, déplacements dans la vidéo et vitesse restent synchronisés pour un maximum de 20 personnes.

**Quitter** vous retire de la séance. L’hôte peut choisir **Terminer la séance** ; elle se termine aussi automatiquement après 6 heures. Une personne peut organiser jusqu’à 3 séances simultanément.

Il n’y a pas de messagerie intégrée : continuez à échanger par votre moyen habituel.

## Données transmises et conservées {#what-a-party-sends-and-keeps}

La synchronisation en direct passe par Supabase Realtime et seuls les membres de la séance la reçoivent. Les messages de lecture, pause, déplacement et vitesse ne sont pas conservés.

La séance conserve l’adresse et le titre de la vidéo, son code, ainsi que l’identité des participants et leur heure d’arrivée. La [page Confidentialité](/fr/docs/privacy-and-permissions) donne les détails.

## Messages possibles {#messages-you-may-see}

| Message | Que faire |
|---|---|
| « Cette séance est terminée ou le code est incorrect. » | Vérifiez le code ou demandez-en un nouveau à l’hôte |
| « Cette séance est complète (20 personnes). » | Le maximum de 20 participants est atteint |
| « Vous avez déjà 3 séances en cours. Terminez-en une d’abord. » | Terminez une séance avant d’en créer une autre |
| « Connectez votre compte pour utiliser les séances à plusieurs. » | Connectez-vous et réessayez |
| « Un code de séance comporte 10 lettres et chiffres. » | Vérifiez la longueur et les caractères du code |
