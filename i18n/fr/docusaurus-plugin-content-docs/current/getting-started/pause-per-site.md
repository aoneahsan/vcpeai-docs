Ouvrez le popup sur le site et cliquez **Pause sur ce site**. Cela interrompt toute l'extension sur ce site, sans widget ni raccourci, et rien ne change sur vos autres sites.

## Pause un site {#pause-a-site}

1. Ouvrez le site que vous voulez mettre en pause.
2. Cliquez sur l'icône Video Controls Plus dans la barre d'outils.
3. Cliquez sur **Pause sur ce site**.
4. Choisissez combien de temps.

| Option                     | Ce qui se passe                                         |
| -------------------------- | ------------------------------------------------------- |
| Jusqu'à ce que je l'allume | Le site reste en pause jusqu'à ce que vous le repreniez |
| Pour 1 heure               | La pause se termine seule après 1 heure                 |
| Pendant 4 heures           | La pause se termine seule après 4 heures                |
| Pour 1 jour                | La pause se termine seule après 1 jour                  |
| Pour 1 semaine             | La pause se termine seule après 1 semaine               |

La page se recharge. Pendant que le site est interrompu, il n'y a pas de widget dessus et aucun raccourci n'est exécuté.

## Reprendre un site {#resume-a-site}

1. Ouvrez le site en pause.
2. Ouvre le popup. Il montre **Paus** et combien de temps il reste.
3. Cliquez sur **Reprendre**.

## Limites {#limits}

La liste des sites en pause reste sur cet appareil et ne se synchronise pas avec votre compte, donc un site que vous arrêtez sur votre ordinateur portable n'est pas en pause sur un autre ordinateur.

Le bouton de pause n'apparaît que sur un site où l'extension est en cours d'exécution. Si le popup dit **Non activé**, il n'y a rien à faire.

## Clés connexes {#related-keys}

Pauser n'a pas de raccourci. Pour cacher seulement le widget, appuyez sur `Esc` ou `Ctrl + Alt + H`Les deux sont en [Raccourcis par défaut](/docs/keyboard-shortcuts/defaults)et [Modifier un raccourci](/docs/keyboard-shortcuts/rebinding) les déplace.
