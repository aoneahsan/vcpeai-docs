Les autres applications de l'équipe obtiennent une maison permanente dans Paramètres, et le panneau promotionnel sort du haut de chaque page Paramètres, de sorte qu'une seule bannière peut s'asseoir au-dessus de vos paramètres.

- **Nouveau : onglet "Plus du développeur".** Paramètres a un nouvel onglet qui recueille les autres applications de l'équipe à un endroit, avec un logo, une courte description et un lien pour chaque. Jusqu'à présent, la liste n'était qu'une étape de la page de bienvenue, donc sauter la configuration signifiait la perdre. La liste est groupée avec l'extension, et rien n'est récupéré pour la montrer. Ouvrir un produit n'est pas suivi.
- **Nouveau : "Plus d'applications" dans le popup.** Un lien au bas du popup ouvre directement cet onglet.
- **Amélioration : une page de paramètres plus calme.** Le panneau promotionnel qui était assis au-dessus de chaque page Paramètres a déplacé dans le nouvel onglet, donc Paramètres s'ouvre à vos paramètres. Une bannière qui apparaît là s'élève alors que le rappel "finissez votre configuration" est affiché, donc deux ne sont jamais empilés.
- **Amélioration : des listes de magasins plus claires.** Les listes Chrome, Edge et Firefox décrivent maintenant les parties du lien d'extension vers les autres applications de l'équipe, et la question Chrome "contient des annonces" est répondue: auto-promotion seulement, sans réseau publicitaire, ad SDK ou suivi impliqués.
