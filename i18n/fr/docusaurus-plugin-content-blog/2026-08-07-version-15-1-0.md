Les autres applications de l’équipe ont désormais leur propre place dans les paramètres. Le panneau promotionnel quitte le haut de chaque page de réglages, où une seule bannière au maximum peut apparaître.

- **Nouveau : onglet « More from the developer ».** Cet onglet regroupe les autres applications de l’équipe, chacune avec son logo, une courte description et un lien. Auparavant, la liste n’apparaissait qu’à une étape de la page de bienvenue : on la perdait en sautant la configuration. La liste est incluse dans l’extension, sans récupération réseau. Ouvrir un produit n’est pas suivi.
- **Nouveau : « More apps » dans le panneau.** Un lien en bas du panneau ouvre directement cet onglet.
- **Amélioration : des paramètres plus calmes.** Le panneau promotionnel placé au-dessus de chaque page a été déplacé dans le nouvel onglet. Une bannière éventuelle s’efface tant que le rappel de fin de configuration est affiché, afin de ne jamais empiler les deux.
- **Amélioration : fiches en boutique plus claires.** Les fiches Chrome, Edge et Firefox décrivent maintenant les liens vers les autres applications de l’équipe. La question « Contains ads » de Chrome reçoit une réponse précise : il s’agit seulement d’autopromotion, sans réseau publicitaire, SDK publicitaire ni suivi lié à ces liens.
