Votre compte sur le site dispose de deux nouvelles pages : **Autres applications**, pour les outils que vous reliez à votre bibliothèque, et **Sécurité**, pour ajouter une étape après Google.

- **Nouveau : clés d’accès.** Créez une clé dans **Autres applications** pour un script ou la synchronisation d’un tableur, choisissez ce qu’elle peut consulter, puis utilisez-la avec l’API. [Clés d’accès](/fr/docs/developers/access-keys/).
- **Nouveau : assistants.** Connectez Claude, ChatGPT, Claude Code ou Cursor et interrogez vos notes, signets et fiches de révision. Une demande de suppression attend votre confirmation sur le site. [Assistants](/fr/docs/developers/assistants/).
- **Nouveau : webhooks.** Votre serveur reçoit un court message signé dès que vous enregistrez une note ou un signet. Le contenu de votre note n’y figure que si vous cochez **Inclure le contenu saisi**. [Webhooks](/fr/docs/developers/webhooks/).
- **Nouveau : connexion en deux étapes.** Après Google, saisissez un code à six chiffres depuis votre téléphone. Vous recevez dix codes de récupération et pouvez cocher **Se souvenir de ce navigateur pendant 7 jours**. Dans ce cas, l’extension reste connectée 7 jours à la fois, puis demande une nouvelle connexion. [Connexion en deux étapes](/fr/docs/developers/two-step-sign-in/).

Les clés, assistants et webhooks sont disponibles avec tous les forfaits, y compris Free. Retrouvez-les dans [Video Controls Plus pour les développeurs](/fr/docs/developers/).
