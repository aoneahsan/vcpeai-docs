Abra uma página com vídeo e pressione `]`. A velocidade aumenta 0,1x. Você já usou a extensão.

## Experimente os primeiros controles

1. Abra um vídeo no YouTube, Udemy, Vimeo ou em outro site com vídeo padrão.
2. Pressione `]` para aumentar a velocidade em 0,1x. Continue até chegar a 4x.
3. Pressione `[` para diminuir em 0,1x.
4. Pressione `=` para voltar à velocidade padrão.
5. Pressione `Ctrl + Alt + 4` para ir diretamente a 2x.

Esse é o controle de velocidade, disponível sem conta. O teclado também faz mais: `,` e `.` avançam um quadro por vez. O modo Picture-in-Picture fica disponível depois que você conecta uma conta.

## Encontre o widget

O widget é o painel flutuante de controles na página. Clique para abri-lo e arraste-o para onde preferir.

Pressione `Esc` ou `Ctrl + Alt + H` para ocultá-lo; pressione novamente para mostrá-lo.

## Encontre o popup e as Configurações

Clique no ícone do Video Controls Plus na barra de ferramentas para abrir o popup. Ele mostra o site atual e se a extensão está ativa ali. É nele que você pode [pausar a extensão em um site](/docs/getting-started/pause-per-site).

As Configurações abrem em uma aba própria.

## O que exige uma conta conectada

Velocidade, predefinições, avanço quadro a quadro, compartilhamento de horário, modo cinema, favoritos locais do navegador e o widget funcionam sem conta. Estes controles ficam disponíveis depois da conexão:

| Controle | Atalho para testar após conectar |
|---|---|
| Repetição A-B | `Ctrl + Alt + A`, depois `Ctrl + Alt + B` |
| Picture-in-Picture | `Ctrl + Alt + P` |
| Amplificação de áudio | `Ctrl + Alt + U` |
| Filtros de vídeo | `Ctrl + Alt + F` |
| Capturas de tela | `Ctrl + Alt + C` |
| Notas com horário do vídeo | **Nota** na aba Ferramentas do widget |
| Avanço automático | Ative nas Configurações |

Você não entra na conta dentro da extensão. Sua conta fica em vcpeai.aoneahsan.com. Pressione **Conectar à sua conta** no popup ou na aba Conta e sincronização das Configurações. A conexão funciona no Chrome, Edge e Firefox. [Conta e sincronização](/docs/account-and-sync) traz as etapas, o que a conexão oferece e os dados registrados.

## Uma tecla não responde

Letras e números exigem `Ctrl + Alt`. Apenas `[`, `]`, `=`, `\\`, `'`, `,`, `.` e `Esc` funcionam sozinhos. A tabela completa está em [Atalhos padrão](/docs/keyboard-shortcuts/defaults). Você pode mudar uma tecla em [Alterar um atalho](/docs/keyboard-shortcuts/rebinding).
