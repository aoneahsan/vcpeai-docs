A repetição A-B reproduz de novo o trecho entre dois pontos que você marca. Para usá-la, [conecte uma conta](/docs/account-and-sync). O controle de velocidade funciona sem conta. Se as teclas da repetição não responderem, faça a conexão primeiro.

## Marcar um trecho

1. Reproduza o vídeo até o início do trecho difícil.
2. Pressione `Ctrl + Alt + A` para marcar o ponto A.
3. Deixe o vídeo seguir até o fim do trecho.
4. Pressione `Ctrl + Alt + B` para marcar o ponto B.

Ao chegar a B, o vídeo volta a A e repete o trecho até você desativar a repetição. Também é possível marcar A e B com um clique cada na aba Repetição do widget.

Em uma aula de violão com um compasso rápido, uma explicação que passa em 40 segundos ou uma frase em outro idioma difícil de entender, marque o trecho, diminua a velocidade com `[` e ouça quantas vezes precisar.

## Teclas da repetição

| Tecla | O que faz |
|---|---|
| `Ctrl + Alt + A` | Marca o início (A) |
| `Ctrl + Alt + B` | Marca o fim (B) |
| `Ctrl + Alt + L` | Ativa ou desativa a repetição |
| `Ctrl + Alt + Backspace` | Apaga os dois pontos |

## Modos de repetição

Escolha o modo na aba Repetição do widget. Os nomes seguem o idioma selecionado na extensão ([alterar o idioma](/docs/user-guide/display-and-widget)).

| Modo | O que acontece em B |
|---|---|
| Para sempre | O trecho se repete até você desligar |
| Uma vez | O trecho se repete uma vez |
| Número de vezes | O trecho se repete de 1 a 20 vezes, conforme o número escolhido |

No modo Número de vezes, um indicador mostra o progresso. O limite é 20 repetições; para mais, escolha Para sempre e desligue com `Ctrl + Alt + L`.

## Teclas relacionadas

`,` e `.` recuam e avançam um quadro, úteis para marcar A e B no ponto exato. Veja [Atalhos padrão](/docs/keyboard-shortcuts/defaults) e [Alterar um atalho](/docs/keyboard-shortcuts/rebinding).
