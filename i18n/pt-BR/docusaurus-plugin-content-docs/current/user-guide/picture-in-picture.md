Conecte uma conta e pressione `Ctrl + Alt + P` para abrir o vídeo em uma janela Picture-in-Picture. Pressione novamente para devolvê-lo à página.

## Usar o modo

1. Inicie o vídeo.
2. Pressione `Ctrl + Alt + P`.
3. Mude para outra aba. O vídeo continua em uma janela pequena.
4. Pressione `Ctrl + Alt + P` novamente para sair.

Os atalhos continuam funcionando: `]` e `[` também mudam a velocidade na janela pequena.

## Entrar automaticamente ao rolar

Em uma página longa, o vídeo pode sair da tela enquanto você lê o texto. A extensão pode movê-lo automaticamente para Picture-in-Picture.

1. Abra a aba Avançado das Configurações.
2. Encontre **Recursos de reprodução**.
3. Confira se **Picture-in-Picture** está ativado.
4. Ative **Entrar em PiP automaticamente ao rolar**.

## Teclas relacionadas

| Tecla | O que faz |
|---|---|
| `Ctrl + Alt + P` | Ativa ou desativa Picture-in-Picture |
| `Ctrl + Alt + Z` | Ativa ou desativa o modo cinema |
| `]` / `[` | Aumenta ou diminui 0,1x, inclusive na janela pequena |

Para mudar um atalho, consulte [Atalhos padrão](/docs/keyboard-shortcuts/defaults) e [Alterar um atalho](/docs/keyboard-shortcuts/rebinding).
