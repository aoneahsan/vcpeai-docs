Os filtros incluem brilho, contraste e saturação de 0% a 200%, além de escala de cinza, inversão e modo noturno. Com uma [conta conectada](/docs/account-and-sync), pressione `Ctrl + Alt + F` para abrir a aba Filtros do widget.

## Controles

| Controle | Intervalo ou efeito | Tecla |
|---|---|---|
| Aba Filtros | Abre e fecha a aba | `Ctrl + Alt + F` |
| Brilho | 0% a 200% | Controle deslizante |
| Contraste | 0% a 200% | Controle deslizante |
| Saturação | 0% a 200% | Controle deslizante |
| Escala de cinza | Liga ou desliga | `Ctrl + Alt + G` |
| Inversão | Liga ou desliga | `Ctrl + Alt + I` |
| Modo noturno | Liga ou desliga | `Ctrl + Alt + T` |

100% é a imagem original enviada pelo site. Abaixo de 100% reduz o efeito; acima, aumenta. Cada controle para em 200%. **Redefinir todos os filtros** restaura a imagem.

## Quando cada filtro ajuda

Em uma gravação de tela com texto cinza-claro sobre branco, aumente o contraste para ler melhor.

Numa tarde ensolarada, aumente o brilho de um vídeo escuro.

À noite, um quadro branco pode iluminar a sala inteira. Pressione `Ctrl + Alt + I` para inverter as cores ou `Ctrl + Alt + T` para ativar o modo noturno.

## Predefinições

Ajuste os três controles e salve o resultado como predefinição na aba Filtros. Você pode salvar até 20. Como fazem parte das configurações, elas podem entrar no [arquivo exportado](/docs/account-and-sync).

## Outros controles de imagem

Duas outras abas do widget alteram a imagem:

| Onde | Controle | O que faz |
|---|---|---|
| Aba Visualização, **Transformar** | Girar, espelhar, inverter | Gira 90 graus, espelha horizontalmente ou inverte verticalmente |
| Aba Ferramentas, **Modos visuais** | Ambiente | Luz ambiente ao redor do player |
| Aba Ferramentas, **Modos visuais** | Cinema | Predefinição de cores de cinema |
| Aba Ferramentas, **Modos visuais** | Letterbox | Faixas de cinema acima e abaixo da imagem |

Os filtros alteram a exibição do vídeo no navegador. Capturar uma imagem ou baixar um arquivo é uma ação separada.
