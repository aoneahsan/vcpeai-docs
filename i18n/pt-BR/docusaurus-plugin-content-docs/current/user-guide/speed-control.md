Pressione `]` ou `[` para mudar a velocidade em 0,1x, ou arraste o controle do widget até 4x. As teclas de colchete funcionam sozinhas, sem `Ctrl + Alt`, e você não precisa de conta.

## Teclas de velocidade

| Tecla | O que faz |
|---|---|
| `]` | Aumenta 0,1x |
| `[` | Diminui 0,1x |
| `=` | Volta à velocidade padrão |
| `\\` | Mostra a velocidade atual |
| `'` | Aplica a velocidade dinâmica |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## Até que velocidade vai

O intervalo é de 0.1x a 16x. O controle deslizante e as teclas de colchete param em 4x. Para chegar a 16x, digite um valor no campo personalizado da aba Velocidade do widget ou nos campos **Velocidade personalizada (0.1x - 16x)** da aba Geral nas Configurações.

O passo é sempre 0,1x. Não há configuração para alterar o mínimo, o máximo ou o passo.

## Velocidade padrão e velocidade dinâmica

Abra a aba Geral nas Configurações.

| Configuração | O que é | Tecla |
|---|---|---|
| Velocidade de reprodução padrão | Usada ao redefinir ou carregar um novo vídeo | `=` |
| Velocidade dinâmica atual | Segunda velocidade que você define aqui e aplica com uma tecla | `'` |

A tecla `'` aplica a velocidade dinâmica atual; ela não corresponde à velocidade salva para o vídeo.

## Velocidades predefinidas

Há oito predefinições, de `Ctrl + Alt + 1` a `Ctrl + Alt + 8`. Você pode editar cada uma e remover as que não usa na aba Atalhos de teclado das Configurações.

Adicione uma nona predefinição para usar `Ctrl + Alt + 9`.

## Memória de velocidade

A extensão lembra a velocidade escolhida para um vídeo e a aplica na próxima vez que você o abrir. Isso vem ativado.

Ela também pode lembrar uma velocidade para toda uma playlist ou curso. Essa opção vem desativada e pode ser ligada na aba Avançado das Configurações.

Quando há mais de uma velocidade salva, **Prioridade de velocidade** determina qual vale:

| Configuração | Velocidade aplicada |
|---|---|
| Playlist/Curso primeiro | A velocidade salva para a playlist ou o curso |
| Vídeo primeiro | A velocidade salva para o vídeo |
| Apenas global (ignorar salvas) | A velocidade padrão; as salvas são ignoradas |
