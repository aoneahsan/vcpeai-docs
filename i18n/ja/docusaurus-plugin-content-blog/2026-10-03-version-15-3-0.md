Netflix と LinkedIn のメニュー操作をすぐ実行できるようにしました。「設定」には、実際に動作するスイッチとショートカットだけを表示します。ウェブサイトとストアの説明も、現在使える機能に合わせて修正しました。

- **改善：Netflix と LinkedIn の操作を即時実行。** ウィジェットや右クリックメニューからパネルを開く、タイマーを始める、エクスポートやダウンロードを行う操作が、すぐ実行されます。以前は多くの操作で機能を有効にするだけで、ページの再読み込みが必要でした。オン・オフの切り替えは引き続き再読み込み後に反映されます。
- **修正：動作しなかった四つの LinkedIn ツール。** Profile Backup、Message Export、Job Tracker、Job Alerts にはスイッチとメニュー項目がありましたが、実行できませんでした。メニューから各操作を実行できるようにしました。動作する部分がなかった Response Tracker と Message Scheduler は削除しました。
- **改善：使える設定だけを表示。** 「新機能」ページにあった 127 個のスイッチのうち、効果があったのは五つだけでした。ジェスチャー操作、VR / 360 モード、SponsorBlock、広告アクセラレーター、スクロールホイールによる音量調整と、その関連オプションだけを表示します。Netflix の設定は従来どおり Netflix セクションにあります。
- **改善：使えるショートカットだけを表示。** 効果のなかった 64 件を「設定」から削除し、割り当てられていたキーを解放しました。機能しなかったミニモードのキーと Player Overlay の表示オプションも削除しました。「v10 Features」というグループ名は「ブックマーク」に変更しました。`Ctrl + Alt + F` でフィルタータブの開閉、`Ctrl + Alt + O` で現在位置のブックマーク追加ができます。
- **追加：LinkedIn の二つのパネルに説明ボタン。** 投稿パフォーマンスのオーバーレイとクイックプレビューカードに、ほかのパネルと同じ説明ボタンを付けました。パネルの目的と使い方を確認できます。
- **改善：実際の機能に合う説明。** ウェブサイト、ライセンスの一覧、ストア掲載文から、まだ拡張機能にないツールの記述を除きました。今使える機能、正しいショートカット、ログインが必要な機能を記載しています。
