英字キーと数字キーには `Ctrl + Alt` が必要です。`[`、`]`、`=`、`\\`、`'`、`,`、`.`、`Esc` だけは単独で使えます。サイトの動画プレーヤーが使うキーと重ならないための初期設定です。

表の「要」が付いたキーにはアカウントの接続が必要です。[アカウントと同期](/docs/account-and-sync)に、接続で使えるようになる機能をまとめています。

## 速度

設定の「速度調整」に速度キーとウィジェットのキーがあります。

| キー | 動作 | 接続 |
|---|---|---|
| `[` | 0.1x 遅くする | 不要 |
| `]` | 0.1x 速くする | 不要 |
| `=` | 既定の速度に戻す | 不要 |
| `\\` | 現在の速度を表示 | 不要 |
| `'` | 設定の「一般」タブで指定した動的速度を適用 | 不要 |
| `Esc` | ウィジェットの表示・非表示 | 不要 |
| `Ctrl + Alt + H` | ウィジェットの表示・非表示 | 不要 |

## 詳細な操作

| キー | 動作 | 接続 |
|---|---|---|
| `Ctrl + Alt + P` | ピクチャーインピクチャーのオン・オフ | 要 |
| `Ctrl + Alt + S` | Netflix、Prime Video でオープニングをスキップ | 要 |

| `Ctrl + Alt + 1` | 0.5x | 不要 |

## キー未割り当ての操作

次の操作には最初からキーがありません。設定の「キーボードショートカット」タブで分類を探し、「設定」を押してキーを入力します。別の操作と重なる場合は、その操作の名前と移動先が表示されます。

| 設定の分類 | 操作 | 接続 |
|---|---|---|
| Comfort | 目に優しい表示を切り替え | 不要 |
| Comfort | 色の見え方を切り替え | 不要 |
| ブックマーク | Focus Mode を切り替え | 不要 |
| Comfort | 字幕スタイルを切り替え | 不要 |
| Comfort | 読書ガイドを切り替え | 不要 |
| 学習 | 学習タイマーの開始・一時停止 | 不要 |
| 学習 | 文字起こしの表示・非表示 | 不要 |
| 効果 | 効果のオン・オフ | 要 |
| 効果 | 動画の一部をぼかす | 要 |
| 音声ツール | 音声ツールのオン・オフ | 要 |
| 音声ツール | 左右の音を入れ替え | 要 |
| 撮影 | クリップの録画・停止 | 要 |
| 撮影 | GIF を作る | 要 |
| 撮影 | スクリーンショットに注釈 | 要 |
| 自動化 | このサイトの自動再生を止める | 不要 |
| 自動化 | 速度ランプの開始・停止 | 不要 |

操作の説明は[Comfort](/docs/user-guide/comfort-and-accessibility)、[学習ツール](/docs/user-guide/study-tools)、[映像効果](/docs/user-guide/visual-effects)、[音声ツール](/docs/user-guide/audio-tools)、[キャプチャ](/docs/user-guide/capture-and-export)、[再生の自動化](/docs/user-guide/playback-automation)にあります。

## ブラウザー側のショートカット

次の 4 つはブラウザーが管理します。割り当ての有無もブラウザーが決め、拡張機能内では変更できません。ブラウザーの拡張機能ショートカット画面で変更してください。

| 推奨キー | 動作 |
|---|---|
| `Alt + V` | ポップアップを開く |
| `Ctrl + Shift + V`（Mac は `Command + Shift + V`） | 浮かぶ操作パネルの表示・非表示 |
| `Ctrl + Shift + P`（Mac は `Command + Shift + P`） | ピクチャーインピクチャーのオン・オフ |
| `Ctrl + Shift + C`（Mac は `Command + Shift + C`） | スクリーンショット |

## Netflix 専用キー

Netflix では特定の場合だけ有効になる専用キーがあります。[Netflix のページ](/docs/platforms/netflix)に一覧があります。

どのキーも[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)から変更できます。
