誰でも[確認ページ](https://vcpeai.aoneahsan.com/verify-license)でライセンスを調べられます。照会は私たちのライセンスサービスが処理します。

## ライセンスキーで確認

**ライセンスキー**を選び、キーを貼り付けて**確認**を押します。有効かどうかに加え、ライセンス先、対象ドメイン、状態、更新期間の終了日が表示されます。メールアドレス、電話番号、価格は表示されません。

## ドメインで確認

**ドメイン**を選び、`videos.example.com` のようなホスト名を入力して**確認**を押します。ライセンスサービスは、そのドメインが提供するライセンスファイルを読み、記載されたキーを確認します。

| 表示される結果 | 意味 |
|---|---|
| このドメインには有効なライセンスがあります。 | ファイルがあり、キーの対象にこのドメインが含まれます。 |
| このドメインには別のドメイン向けのライセンスがあります。 | キーは有効ですが、このドメインは対象外です。 |
| このドメインにはライセンスファイルがありません。 | 以下の場所にファイルがありません。 |
| このドメインに接続できませんでした。 | HTTPS で応答がありませんでした。 |

## ライセンスファイル

すべてのホワイトラベル製品は、次の場所にファイルを公開します。

```text
/.well-known/vcpeai-white-label-license.json
```

製品名、顧客名、ドメイン、ライセンスキー、確認ページへのリンクが記載されます。同じ場所に拡張子が `.pdf` の証明書もあります。公開時に私たちが両方を配置するので、お客様が作成する必要はありません。

取り消されたキーを使う製品や、ライセンス対象外のドメインで動く製品には、アプリの代わりに「このライセンスは有効ではありません」というページが表示されます。データは削除されません。
