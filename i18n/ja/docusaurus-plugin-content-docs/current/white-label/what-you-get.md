ホワイトラベルライセンスでは、お客様のブランドで動作する拡張機能とウェブサイトを提供し、私たちが更新を続けます。買い取りではソースコードをお渡しします。

## ホワイトラベルライセンスで提供するもの

- **お客様の名前の拡張機能。** Chrome、Firefox、Edge 向けに、ポップアップ、ページ上のウィジェット、「設定」に名前、ロゴ、色を適用します。
- **お客様のストア掲載。** お客様自身の開発者アカウントを使い、Chrome Web Store、Firefox Add-ons、Microsoft Edge Add-ons に公開します。アカウントと、ストアが請求する費用はお客様のものです。
- **お客様のドメイン上の連携ウェブサイト。** 拡張機能の接続先となるアカウントページを、私たちがデプロイしホスティングします。
- **現在の Video Controls Plus の操作機能。** 0.1～16 倍速、A-B ループ、最大 400% の音量ブースト、フィルター、スクリーンショット、時刻付きメモ、変更可能なキーボードショートカット、YouTube、Netflix、LinkedIn の追加ツールが含まれます。
- **購入日から 6 か月間の更新。** 詳しくは[更新と更新契約](./updates.md)をご覧ください。
- **ライセンスキーと公開されるライセンスファイル。** 誰でも[有効性を確認](./verify.md)できます。

ライセンスにソースコードは含まれず、独占権もありません。買い取りが成立するまでは、同じ製品をほかの企業にもライセンスできます。

## Video Controls Plus の構成

ライセンスでは以下の構成をお客様向けに運営し、買い取りでは引き渡します。製品固有の構成を確認できます。

| 構成 | 現在の内容 |
|---|---|
| 拡張機能 | WXT、React、TypeScript を使う一つのコードベース。Chrome と Edge は Manifest V3、Firefox は Manifest V2。外部から読み込むコードはなく、すべてのライブラリーをパッケージに同梱します。Chrome Web Store が求める構成です。 |
| サイト別ツール | YouTube の追加機能 62 件、Netflix の追加機能 52 件（うち 50 件はスイッチ付きで、インストール時はすべてオフ）、LinkedIn のツール 48 件の三つの機能一覧です。各項目が「設定」のスイッチ、ウィジェットのタブ、右クリックメニューにつながります。 |
| ログイン | 拡張機能にパスワードはありません。連携ウェブサイトで Google ログインし、両画面に表示される短いコードで接続します。Chrome、Edge、Firefox で同じ手順です。 |
| 連携ウェブサイト | Vite と React で構築。拡張機能が接続するアカウントページ、メモ、ブックマーク、あとで見る項目、プラン、開発者向けページがあります。 |
| バックエンド | 行レベルセキュリティ付きの Postgres、Drizzle で定義したスキーマ、AI の実行、ファイルアップロード、メール、支払い、API、アシスタント用 MCP 接続先、Webhook を処理するサーバー関数があります。 |

Android アプリはブラウザー拡張機能のプラットフォーム群に含まれません。

## ソースコード買い取りで提供するもの

- **拡張機能の構築に必要なすべてのリポジトリのソースコード。** 拡張機能、連携ウェブサイト、両者が使うバックエンドと、設定手順をお渡しします。
- **購入日から 6 か月間の更新。** コードとしてお届けします。以後の更新契約は任意です。
- **販売の終了。** Video Controls Plus のライセンスと買い取りの販売を終了します。買い取り前にライセンスを購入した企業の契約条件は維持されます。

買い取り後の運営方法はお客様が決めます。ホスティング、ストアアカウント、選択した有料サービスの費用はお客様の負担です。

買い取りにはロイヤルティも伴います。Video Controls Plus が生む総収益から、お客様が徴収する売上税や VAT を除いた額の 7% を支払います。収益がある限り四半期ごとに収益報告書とともに支払い、製品を再販売した場合も義務は続きます。[ライセンス条件](https://vcpeai.aoneahsan.com/white-label/license-terms)にも同じ内容を記載しています。

詳しい条件は[ライセンス条件](https://vcpeai.aoneahsan.com/white-label/license-terms)と[利用規約](https://vcpeai.aoneahsan.com/terms#policy-section-14)の第 14 節をご覧ください。
