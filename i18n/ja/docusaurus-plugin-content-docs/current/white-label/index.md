ホワイトラベルライセンスでは、Video Controls Plus チームが、お客様の名前で拡張機能を運営します。利用者は Chrome Web Store、Firefox Add-ons、Microsoft Edge Add-ons からお客様の拡張機能をインストールし、連携するウェブサイトはお客様のドメインで動作します。構築、公開、ウェブサイトのホスティング、更新は私たちが担当します。お客様がコードを扱う必要はありません。

購入方法は二つあり、[ホワイトラベルのページ](https://vcpeai.aoneahsan.com/white-label)で比較できます。

| | ホワイトラベルライセンス | ソースコード買い取り |
|---|---|---|
| 運営 | 私たちがお客様のブランドで運営 | お客様が運営 |
| ソースコード | 私たちが保有 | 拡張機能の構築に必要なすべてのリポジトリを引き渡し |
| ほかの企業への販売 | 誰かが買い取るまで継続 | 買い取り後は販売終了 |
| 更新 | 6 か月分を含み、以後は更新契約が可能 | 6 か月分を含み、以後は更新契約が可能 |
| 初回支払い後の費用 | 更新を希望する場合の更新料 | 希望する場合の更新料と、収益が発生する限り四半期ごとに支払う総収益の 7% のロイヤルティ |

Video Controls Plus は、Chrome、Firefox、Edge 向けのブラウザー拡張機能をまとめて一つのプラットフォーム群として販売します。一つの群だけなので、複数群をまとめる割引はありません。

価格と購入手続きは、ライセンスサービスから最新情報を読み込む[価格ページ](https://vcpeai.aoneahsan.com/white-label/pricing)で確認できます。買い取りには[専用ページ](https://vcpeai.aoneahsan.com/white-label/buyout)もあります。
