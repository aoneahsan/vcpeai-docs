お支払い後、ライセンスキーと以下の手順を記載したメールが届きます。審査期間は各ストアが決めるため、公開日も審査によって変わります。

1. **価格ページで申し込む。** 名前、メールアドレス、ウェブサイトのドメインを入力し、**支払いへ進む**を押します。同じタブで支払いページが開きます。Wise の銀行振込で支払い、送金照会番号をお知らせください。送金確認後にライセンスを発行します。
2. **ライセンスメールに返信する。** 製品名、SVG または大きい PNG のロゴ、ブランドカラー、ドメインを送ってください。
3. **私たちがお客様向けの製品を構築する。** 拡張機能とウェブサイトにお客様の名前と色を適用します。ストア掲載文とスクリーンショットを送り、確認していただきます。
4. **拡張機能を公開する。** お客様の Chrome Web Store、Firefox Add-ons、Microsoft Edge Add-ons の開発者アカウントを使います。各アカウントに私たちを追加するか、ストアが認める方法でアクセスを提供してください。
5. **ドメインを接続する。** ウェブサイトをデプロイし、お送りする DNS レコードをお客様に追加していただきます。
6. **公開とともにライセンスが有効になる。** ウェブサイトからライセンスファイルが提供され、[誰でも有効性を確認](./verify.md)できます。

## 事前に用意するもの

- Chrome Web Store、Firefox Add-ons（無料）、Edge 向け Microsoft Partner Center の各開発者アカウント。
- ドメインの DNS 設定にアクセスできること。
- ロゴとブランドカラー。

名前、ロゴ、色以外で製品の動作を変更する場合は、別途見積もる[個別開発](https://vcpeai.aoneahsan.com/white-label/custom-work)になります。
