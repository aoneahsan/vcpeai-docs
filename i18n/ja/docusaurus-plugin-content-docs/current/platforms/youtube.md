YouTube では共通の動画操作に加え、コメント検索、低評価数の表示、チャンネルのブロック、字幕やサムネイルの保存などを使えます。これらは初期状態でオンで、設定にそれぞれのスイッチがあります。初期状態でオンの機能自体はアカウントなしで動きます。スイッチがある設定の「YouTube 機能」タブにはアカウントが必要です。[アカウントと同期](/docs/account-and-sync)をご覧ください。

## 共通の操作

速度、ウィジェット、ショートカットはほかのサイトと同じです。`]` を押すと 0.1x 速くなり、動画ごとの速度も記憶されます。

## 初期状態で有効な機能

多くの YouTube 専用機能は初期状態でオンです。一部は自分でオンにするまで動きません。

| 機能 | 動作 | 初期値 |
|---|---|---|
| 低評価数 | Return YouTube Dislike API を使って表示 | オン。右クリックメニューにも表示 |
| コメント検索 | 動画のコメント内を検索 | オン。右クリックメニューにも表示 |
| チャンネルのブロック | おすすめから対象チャンネルを除外 | オン。右クリックメニューにも表示 |
| サムネイルの保存 | 動画のサムネイルをダウンロード | オン |
| 字幕の保存 | 字幕をダウンロード | オン |
| Shorts の非表示 | YouTube のフィードから Shorts を隠す | オフ |
| 自動ワイド表示 | YouTube の広いシアター表示にする | オフ |
| 広告のスキップ | YouTube 自身の「広告をスキップ」ボタンを押す | オフ |

広告のスキップは、YouTube が表示したボタンを押すだけです。広告を取り除く機能ではなく、ボタンが出るまでは何もしません。

## スイッチの場所

1. 設定を開きます。
2. 「YouTube 機能」タブへ進みます。
3. 接続を求められたらアカウントを接続します。

機能は、コメント、発見とブロック、移動、視聴体験、プレーヤー、生産性、学習、分析、詳細、ダウンロードに分かれています。62 件それぞれの動作と制限は、製品サイトの[YouTube 専用機能ガイド](https://vcpeai.aoneahsan.com/blog/youtube-extras-guide)にあります。

各機能には 2 つのスイッチがあります。

| スイッチ | 動作 |
|---|---|
| 有効 | 機能のオン・オフ |
| 右クリックメニューに表示 | YouTube 上の動画メニューへ追加 |

専用機能が動くのは youtube.com だけです。

## 機能を使う

ウィジェットの「YouTube」タブか右クリックメニューから起動します。ウィジェットの表示言語は拡張機能で選んだ言語に従います。[言語の変更](/docs/user-guide/display-and-widget)もご覧ください。

右クリックメニューには、表示を選んだ機能だけが並びます。

## 関連するキー

`Ctrl + Alt + X` で現在の時刻を含む動画リンクをコピーできます。ほかのキーは[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)にあり、[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)で変えられます。
