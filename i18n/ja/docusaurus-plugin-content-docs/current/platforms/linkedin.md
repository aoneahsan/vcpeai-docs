LinkedIn では動画操作に加え、プロフィールの採点、応募状況の記録、投稿の書き出しなどを使えます。ウィジェットや右クリックメニューから選ぶと、その場で実行されます。共通の動画操作はほかのサイトと同じです。初期状態でオンの機能はアカウントなしで動きます。オン・オフを変える「LinkedIn 機能」タブにはアカウントが必要です。[アカウント接続で増えること](/docs/account-and-sync)もご覧ください。

## 主な機能

機能は選ぶとパネルを開くか、書き出し・ダウンロードを始めます。48 件それぞれに手順、例、よくある質問が製品サイトの LinkedIn ページにあり、[プロフィール機能](https://vcpeai.aoneahsan.com/features/linkedin-profile)からたどれます。

| 機能 | 動作 | 初期値 |
|---|---|---|
| プロフィール採点 | プロフィールの完成度を分析 | オン |
| 見出し文の作成 | キーワードをもとに見出しを作成 | オン |
| 応募の記録 | 求人応募を記録 | オン |
| 投稿の書き出し | CSV または JSON で保存 | オン |
| プロフィールのバックアップ | プロフィールを保存 | オン |
| メッセージの書き出し | CSV または JSON で保存 | オン |
| フィードの絞り込み | フィードの内容を選別 | オフ |
| Focus Mode | LinkedIn 上の気が散る部分を隠す | オフ |

## 初期状態の違い

自分で選ぶまで待機する機能は、初期状態でオンです。LinkedIn のページ読込時に表示を加えたり、フィードを変えたりする機能は、自分でオンにするまで動きません。フィードの絞り込みと Focus Mode は後者です。

## スイッチの場所

1. 設定を開きます。
2. 「LinkedIn 機能」タブへ進みます。
3. 求められたらアカウントを接続します。

プロフィール、コンテンツ作成、投稿とフィード、つながり、メッセージ、求人、分析、書き出し、プライバシー、生産性に分かれています。

各機能には「有効」と「右クリックメニューに表示」の 2 つのスイッチがあります。専用機能は linkedin.com だけで動作します。オン・オフの切り替えは LinkedIn のページを再読み込みすると反映されます。メニューからの操作に再読み込みは不要です。

## 情報ボタン

LinkedIn 機能が開く各パネルには情報ボタンがあり、押すと機能の説明と使い方が表示されます。

## 文章作成の支援

LinkedIn 向け文章作成は AI 機能の 1 つで、3 通りの実行方法があります。送信される内容と送信先は[AI 機能](/docs/ai-features)に記載しています。

## 関連するキー

LinkedIn 専用機能に初期設定のキーはありません。共通の動画操作は[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)にあり、[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)で変えられます。

そのほかは[対応サイト](/docs/platforms/other-sites)をご覧ください。
