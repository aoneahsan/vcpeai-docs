Video Controls Plus は、標準的な HTML5 動画を再生するサイトで動作します。YouTube、Netflix、LinkedIn には専用機能があります。Udemy、Vimeo、Twitch、Coursera、Khan Academy、Prime Video なども対象です。

## どのサイトでも使える操作

`]` と `[` による速度調整、ウィジェット、ショートカットは共通です。サイト専用の追加機能は次の 3 つにあります。

| サイト | 専用機能 | 説明 |
|---|---|---|
| YouTube | 各機能に個別のスイッチ | [YouTube](/docs/platforms/youtube) |
| Netflix | 自分でオンにして使う機能 | [Netflix](/docs/platforms/netflix) |
| LinkedIn | メニューから起動する機能 | [LinkedIn](/docs/platforms/linkedin) |

## 埋め込み動画

記事や講座ページ内の YouTube、Vimeo プレーヤーでも、浮かぶ操作パネル、ショートカット、右クリックメニューを使えます。埋め込みフレーム内に動画がある場合だけ、拡張機能が読み込まれます。

## ポップアップでサイトを確かめる

そのサイトでポップアップを開くと、サイト名と次の状態のいずれかが表示されます。

| 表示 | 意味 |
|---|---|
| 対応 | 組み込みの対応サイト一覧にある |
| 有効 | このサイトで拡張機能を有効にした |
| 有効ではありません | このサイトでは拡張機能が動作していない |

「有効ではありません」と表示されたら「このサイトで有効にする」を押します。組み込みの一覧は設定の「サイト設定」タブにある「対応サイト」で確認できます。

## 操作パネルが出ない場合

- サイトが一時停止中なら、ポップアップから「再開」を押します。[サイトごとの一時停止](/docs/getting-started/pause-per-site)もご覧ください。
- ポップアップが「有効ではありません」と示すなら、「このサイトで有効にする」を押します。
- 標準的な HTML5 動画がないページには、操作対象がありません。
- ウィジェットが隠れているなら、`Esc` または `Ctrl + Alt + H` を押します。

## 関連するキー

| キー | 動作 |
|---|---|
| `]` / `[` | 0.1x 速く／遅くする |
| `Esc` | ウィジェットの表示・非表示 |
| `Ctrl + Alt + H` | ウィジェットの表示・非表示 |

どのサイトでも同じキーです。ほかの操作は[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)と[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)で確認できます。

まだ表示されない場合は[問題が起きたとき](/docs/troubleshooting)をご覧ください。
