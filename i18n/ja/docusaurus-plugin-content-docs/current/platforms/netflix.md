Netflix でも速度などの共通操作が使えます。Netflix 専用機能は自分でオンにするまで動きません。切り替えは、アカウント接続が必要な設定の「Netflix 機能」タブで行います。[アカウントと同期](/docs/account-and-sync)をご覧ください。

## 共通の操作

アカウントの有無にかかわらず、`]` で 0.1x 速く、`[` で 0.1x 遅くできます。

## 専用機能をオンにする

1. 設定を開きます。
2. 「Netflix 機能」タブへ進みます。
3. 求められたらアカウントを接続します。
4. 使いたい機能のスイッチをオンにします。
5. Netflix のページを再読み込みします。

オン・オフの切り替えは再読み込み後に反映されます。メニューからパネルを開く、タイマーを始める、書き出す、ダウンロードするといった操作はすぐに実行されます。

各機能には右クリックメニューへの表示スイッチもあります。専用機能が動くのは netflix.com だけです。50 件それぞれの説明と、Netflix 側の保護による制限は[Netflix 専用機能ガイド](https://vcpeai.aoneahsan.com/blog/netflix-extras-guide)をご覧ください。

| 機能 | 動作 | 初期値 |
|---|---|---|
| あらすじのスキップ | 「前回まで」の部分を飛ばす | オフ |
| 2 言語の字幕 | 2 言語の字幕を同時表示 | オフ |
| 字幕の保存 | SRT または VTT でダウンロード | オフ |
| スリープタイマー | 指定した分数後に一時停止 | オフ |
| エピソード移動 | エピソード間を移動 | オフ |
| 視聴制限 | 1 日の上限を設定 | オフ |
| セリフの増幅 | 音楽や効果音より声を大きくする | オフ |

視聴制限は動画が見えているタブで再生している間だけ数えます。背景タブの時間は加算されません。

## Netflix の復旧用キー

Netflix が「このデバイスは Netflix ご利用世帯に含まれていません」と示すことがあります。拡張機能がその画面を取り除いた後、Netflix 自身の再生操作が隠れたままになる場合に限り、次のキーが有効になります。

プレーヤー上の小さな通知から全キー一覧へ進めます。

| キー | 動作 |
|---|---|
| `Space` | 再生・一時停止 |
| `←` / `→` | 10 秒戻る／進む |
| `Shift + ←` / `Shift + →` | 1 分戻る／進む |
| `Ctrl + ←` / `Ctrl + →` | 5 分戻る／進む |
| `Ctrl + 0` | 先頭へ移動 |
| `Ctrl + 1`～`Ctrl + 9` | 動画の 10%～90% の位置へ移動 |
| `Ctrl + -` | 終わりの 1 分前へ移動 |
| `↑` / `↓` | 音量を上げる／下げる |
| `M` | ミュートのオン・オフ |
| `F` | 全画面のオン・オフ |
| `V` | 字幕トラックを次へ。オフも含む |
| `B` | 音声トラックを次へ |

設定の「キーボードショートカット」タブ、「Netflix の復旧操作」で変更できます。1 つのキーに割り当てられる操作は 1 つなので、一般の操作と重複できません。

## 動作範囲

上記以外の場面では、これらは Netflix 自身のキーです。拡張機能がすべての Netflix エラーを解消するわけではありません。世帯画面を取り除き、必要なときにキーボード操作を提供します。

一般のキーは[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)にあり、復旧用も含め[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)から割り当てを変えられます。
