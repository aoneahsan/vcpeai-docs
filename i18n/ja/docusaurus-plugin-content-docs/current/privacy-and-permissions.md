Video Controls Plus は設定をブラウザー内に保存します。初期状態でオンの**利用状況の分析**スイッチが有効な間は、アカウント接続の有無にかかわらず利用イベントがチームのバックエンドに送られ、一日一回まで、位置を調べるため IP アドレスが ipapi.co に送られます。アカウントを接続すると、アカウントのデータと、同期をオンにした場合の設定も保存されます。

スイッチをオフにすると、こうした利用状況の記録は行われません。

視聴履歴は初期状態でオフです。有効にしない限り、視聴した動画、そのタイトル、アドレスは記録しません。自分で保存した項目は例外です。接続済みアカウントでは、メモ、ブックマーク、日記、あとで見る項目、アップロードしたスクリーンショット、抽出した動画情報、文字起こし、動画から保存したフラッシュカード、学習経路の動画、コレクションの項目、共同視聴のように、保存または開始した項目とともに動画のタイトルとアドレスを保持します。

このページは[プライバシーポリシー](https://vcpeai.aoneahsan.com/privacy)を平易に説明したものです。法的な文書はポリシーです。内容が異なる場合はポリシーが優先します。

## ブラウザー内に残るもの

設定、キーボードショートカット、動画ごとに記憶した速度、再生位置、フィルターのプリセット、音声設定はブラウザー内に保存されます。拡張機能をアカウントに接続し、同期をオンにした場合だけアカウントに送られます。

音声のダウンロードは端末上で処理されます。スクリーンショットも、画像をアップロードするクラウド操作を選ばない限り端末に残ります。

視聴制限の分数はこの端末だけで数えます。PIN はハッシュ化され、同期されません。学習タイマーの回数と、動画の字幕から作成したチャプターはこのブラウザーに残ります。GIF、クリップ、タイムラプス、コンタクトシートは端末上で作られ、ダウンロードとして保存されます。

## 記録される内容

| データ | 記録される条件 | 内容 |
|---|---|---|
| 利用イベント | 利用状況の分析がオンの間。アカウントは不要 | イベント名、サイトのホスト名、ブラウザー、OS、拡張機能のバージョン、セッション ID。接続中はアカウント情報も含みます。 |
| 位置の照会 | 利用状況の分析がオンの間、一日一回まで | IP アドレスを ipapi.co に送ります。返された国、都市、タイムゾーンはアカウント接続中にプロフィールへ保存し、地域情報はブラウザー内に残します。IP アドレスは保存しません。 |
| サイト、機能、速度 | 利用状況の分析がオンで、アカウントに接続中 | 使用したサイト、機能、速度 |
| アカウント | アカウントに接続中 | メールアドレス、表示名、プロフィール写真、Google アカウント ID |
| このブラウザー | アカウントに接続中 | 端末名、ブラウザー、OS、拡張機能のバージョン、最後に確認した時刻 |
| 設定 | アカウントに接続し、同期がオン | アカウントに同期する設定 |
| アカウントに保存したもの | アカウント接続中、各項目を保存したときだけ | メモ、ブックマーク、あとで見る項目、アップロードしたスクリーンショット、右クリックで抽出した動画情報、アカウントに保存した文字起こしと、それぞれの動画タイトル・アドレス。ブックマークには時刻も含みます。日記は気分と文章を含むブックマークです。動画から保存したフラッシュカード、学習経路の動画、コレクションの項目も同様です。 |
| 視聴履歴 | 「設定」→「プライバシーとデータ」で**視聴履歴**をオンにし、接続中に動画を再生した場合。接続済みアカウントの各ブラウザーで初期状態はオフです。 | 15 秒以上の視聴ごとに、動画のタイトルとアドレス、視聴時間、最後の位置、再生した部分、日付、再生速度、使った機能。オフにすると新しい記録は止まります。既存の履歴はウェブサイトで削除するか、アカウントを削除するまで残ります。 |
| 共同視聴 | 共同視聴を開始または参加したとき | 動画のアドレスとタイトル、参加コード、参加者と参加時刻。進行中の再生、一時停止、シーク、速度は Supabase Realtime を通じて参加者に伝えられ、保存されません。 |
| エラーレポート | 外部のエラー追跡がオンの間 | Sentry に送るクラッシュレポート |
| AI に渡す文章 | AI 機能を開始した場合だけ | 動画の字幕または下書き中の文章。共有利用枠の実行記録は、文章を含めず 13 か月保持します。[AI 機能](/docs/ai-features)をご覧ください。 |
| 音声入力の録音 | 音声入力で録音した場合だけ | 最大 2 分間の音声、文字起こし、提案されたメモ。三つとも 24 時間以内、または**破棄**を押した時点で削除します（[プライバシーポリシー](https://vcpeai.aoneahsan.com/privacy) 1.8 節）。 |

利用イベントに含まれるサイト情報は、youtube.com のようなホスト名だけです。完全な URL、ページ内のパス、ページタイトルは含みません。

## 利用状況の分析スイッチ

「設定」→**プライバシーとデータ**→**利用状況の分析**を開きます。アカウントの有無にかかわらず設定できます。

オフにすると、次の三つが止まります。

1. チームのバックエンドへの利用イベント送信。
2. 接続済みアカウントでの、使用したサイト、機能、速度の記録。
3. ipapi.co への IP アドレス送信。

接続時にブラウザー側かアカウント側のいずれかでオフなら、両方ともオフになります。

## ほかのスイッチ

同じタブにあります。

| スイッチ | 初期状態 | 制御する内容 |
|---|---|---|
| 外部のエラー追跡 | オン | Sentry へのクラッシュレポート |
| マーケティングのお知らせ | オフ | 新機能やチームのほかの製品について、ときどき届くブラウザー通知。メールは別です。アカウント保有者には製品ニュースのメールが届き、各メールからワンクリックで配信を停止できます。 |
| 設定の同期 | オン | アカウントへの設定保存 |

外部のエラー追跡と利用状況の分析は別々です。一方をオフにしても、もう一方は変わりません。同じタブの**自分のデータ**から書き出しや削除を行えます。手順は[アカウントと同期](/docs/account-and-sync)にあります。

## データの保存先

| サービス | 扱う内容 |
|---|---|
| Supabase | アカウントのデータベースとログイン、共同視聴のリアルタイム同期 |
| FilesHub | 保存したスクリーンショット、最大 24 時間の音声入力の録音、チームからのメール |
| Sentry | 外部のエラー追跡がオンの間のクラッシュレポート |
| ipapi.co | 利用状況の分析がオンの間、位置の照会用に IP アドレスを受信 |
| Anthropic、OpenAI、Groq | 自分が開始した AI 実行の文章、音声入力の音声や文字起こし。どのデータをどこへ送るかは[AI 機能](/docs/ai-features)をご覧ください。 |

五つの機能は、使用中に限りそれぞれの外部サービスに接続します。SponsorBlock（`sponsor.ajay.app`）、Netflix の字幕翻訳・二言語字幕（`api.mymemory.translated.net`）、自分のキーで使う Netflix の評価（`www.omdbapi.com`）、字幕取得が必要な AI 要約（`video.google.com/timedtext`）、ウィジェットの「単語を保存」にある**調べる**（`en.wiktionary.org`。入力した一語だけ送信）です。ポリシーの 5.9 節には、このドキュメントでまだ説明していない機能向けのサービスがもう一つあります。

## 収集しないもの

ポリシーでは、次を収集対象外としています。視聴した動画（視聴履歴をオンにした場合を除く）、アップロードを選んだスクリーンショット以外の動画内容やメディアファイル、拡張機能が動作しないページでの閲覧、パスワード、支払い情報、訪問先ページの内容（自分で AI 機能へ送った文章と、上記五つの機能がそれぞれのサービスへ送る内容を除く）。

データを販売することはありません。

## マイク

音声をアップロードする機能は音声入力だけです。初回利用時にマイクの許可を求めます。

| 場所 | 表示されるもの |
|---|---|
| 拡張機能 | **音声でメモ**に「マイクを一度許可」と表示されます。**マイクのページを開く**を押すと、許可用タブが開きます。そこで**マイクを許可**を押し、ブラウザーの確認画面で許可してください。一度だけ必要です。 |
| Android アプリ | 音声入力で初めて録音を押したとき、マイクの許可を求めます。 |
| Firefox アドオン | 録音や送信の前に、任意の「Personal communications」データ権限も求めます。 |

マイクを使うのは録音中だけです。拒否した場合、再度有効にする場所をページで案内します。「設定」の**AI 機能**タブで音声入力をオフにすると、拡張機能からの提案が止まります。

## 各権限の用途

拡張機能は七つの権限とサイトへのアクセスを求め、Chrome と Edge では八つ目の `offscreen` も求めます。拡張機能内でログインしないため、`identity` 権限は求めません。マイクの許可はインストール時には求めません。

| 権限 | 用途 |
|---|---|
| `storage` | 設定、ショートカット、速度の記憶、フィルターのプリセット、テーマをブラウザーに保存 |
| `activeTab` | ポップアップを開いた際に、現在のタブの動画を読み取り・操作 |
| `contextMenus` | 右クリックメニューの項目を追加 |
| `alarms` | スリープタイマー、同期待ち・利用イベントの送信、保留中のアカウント接続確認、遠隔設定の更新、サイトごとの一時停止終了、一日一回のお知らせ通知確認のためのタイマー |
| `notifications` | ウィジェットが隠れているか「通知のみ」の場合に、速度変更、ループ状態、スリープタイマーの通知を表示 |
| `clipboardWrite` | 右クリックメニューの「ページ URL をコピー」「時刻付き URL をコピー」でクリップボードへ書き込み。読み取りはしません。 |
| `scripting` | 別のページに埋め込まれた動画へ操作を届けます。動画のあるフレームだけで動作します。 |
| `offscreen`（Chrome、Edge） | 拡張機能の隠れたページで音声入力を録音・送信し、アップロード中も録音を続けられるようにします。Firefox はバックグラウンドページを使うため不要です。 |
| 全サイトへのアクセス | 開いたサイトにある動画を見つけて操作 |

全サイトへのアクセスは範囲の広い権限です。動画がどのサイトにもあり得るため必要です。[一時停止中](/docs/getting-started/pause-per-site)のサイトでは、拡張機能は動作しません。

## Firefox での権限

Firefox は三つの任意のデータ権限を求め、許可ごとに送信内容を制御します。

| Firefox の権限 | 許可が必要なもの |
|---|---|
| Technical and interaction data | 利用イベント。利用状況の分析スイッチを使うと、この権限を求めます。 |
| Website content | アップロードするスクリーンショット、アカウントに保存する文字起こし、AI 実行に使う字幕、画面上の字幕行を例文として付けた単語などのページ内容。初回利用時に求めます。 |
| Personal communications | 音声入力の録音と文字起こし。音声入力の初回利用時に求めます。 |

## 接続するキー、アシスタント、Webhook

ウェブサイトの**アカウント → ほかのアプリ**で自分で設定しない限り、外部からライブラリーへアクセスできません。アクセスキー、Claude や ChatGPT などのアシスタント、Webhook は選んだ範囲だけを扱い、ログイン、支払い、音声メモ、AI 履歴、利用状況の分析にはアクセスできません。Webhook のメッセージには項目 ID、動画、時刻が含まれます。**記入した内容を含める**をその接続先で選んだ場合だけ本文も含みます。文字起こしの本文は送られません。範囲と解除方法は[開発者向け Video Controls Plus](/docs/developers)をご覧ください。

## 同じチームのほかのアプリ

「設定」に、同じチームのほかのアプリを紹介するタブがあります。一覧は拡張機能に同梱され、表示時の取得処理はありません。横に出るお知らせはチームのバックエンドから読みます。広告ネットワークや広告 SDK は含まれません。
