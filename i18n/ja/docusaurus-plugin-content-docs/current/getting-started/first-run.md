動画のあるページで `]` を押してください。再生速度が 0.1x 上がれば、最初の操作は完了です。

## まず速度を変える

1. YouTube、Udemy、Vimeo など、標準的な動画のあるページを開きます。
2. `]` を押すと 0.1x 速くなります。押し続けると最大 4x まで上げられます。
3. `[` を押すと 0.1x 遅くなります。
4. `=` を押すと既定の速度に戻ります。
5. `Ctrl + Alt + 4` を押すと 2x に切り替わります。

速度調整にはアカウントは不要です。`,` と `.` を押せば、動画を 1 フレームずつ動かせます。ピクチャーインピクチャーは、アカウントを接続すると使えるようになります。

## ウィジェットを見つける

ウィジェットは動画のそばに浮かぶ操作パネルです。クリックして開き、ドラッグして好きな位置へ移せます。

`Esc` または `Ctrl + Alt + H` を押すと非表示になり、もう一度押すと戻ります。

## ポップアップと設定を開く

ツールバーの Video Controls Plus アイコンをクリックするとポップアップが開きます。現在のサイトと拡張機能の動作状態を確認でき、[そのサイトだけで一時停止](/docs/getting-started/pause-per-site)もできます。

設定は別のタブで開きます。

## アカウントの接続が必要な操作

速度、プリセット、フレーム送り、時刻付きリンクの共有、シアターモード、ブラウザー内のブックマーク、ウィジェットはアカウントなしで使えます。次の操作は接続後に有効になります。

| 操作 | 接続後に試すキー |
|---|---|
| A-B ループ | `Ctrl + Alt + A`、次に `Ctrl + Alt + B` |
| ピクチャーインピクチャー | `Ctrl + Alt + P` |
| 音量増幅 | `Ctrl + Alt + U` |
| 映像フィルター | `Ctrl + Alt + F` |
| スクリーンショット | `Ctrl + Alt + C` |
| 時刻付きメモ | ウィジェットの「ツール」タブにある「メモ」 |
| 自動スキップ | 設定で有効にする |

拡張機能内でサインインする方式ではありません。アカウントは vcpeai.aoneahsan.com 上にあり、ポップアップまたは設定の「アカウントと同期」で「アカウントに接続」を押して連携します。Chrome、Edge、Firefox で利用できます。[アカウントと同期](/docs/account-and-sync)に手順、接続後の機能、記録される内容をまとめています。

## キーを押しても反応しない場合

英字キーと数字キーには `Ctrl + Alt` が必要です。`[`、`]`、`=`、`\\`、`'`、`,`、`.`、`Esc` だけは単独で使えます。全キーは[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)で確認でき、[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)から割り当てを変えられます。

次は[再生速度を変える](/docs/user-guide/speed-control)をご覧ください。
