Video Controls Plus は各ブラウザーの公式ストアから追加できます。再生速度の調整は、インストール後すぐに使えます。

| ブラウザー | ストア |
|---|---|
| Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/video-controls-plus/ihafdbecgnhendhckoknblmcminoikdb) |
| Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/video-controls-plus/ghjcpobkbbhefdlgffopfhlepkgcknlb) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/video-controls-plus) |

同じリンクは製品サイトの[インストールページ](https://vcpeai.aoneahsan.com/install)にもあります。

## ブラウザーに追加する

1. 上の表から、お使いのブラウザーのストアページを開きます。
2. 拡張機能を追加し、ブラウザーに権限の確認が表示されたら承認します。
3. ブラウザーの拡張機能ボタンからツールバーに固定すると、ポップアップをすぐ開けます。

拡張機能内にウェルカムページが開きます。順に進めても、スキップしてもかまいません。「アカウントに接続」は後から設定できるため、この手順もスキップできます。

## Firefox の場合

Firefox 140 以降が必要です。Firefox は、追加時に拡張機能が収集するデータを表示します。

Firefox では、任意のデータ権限も 2 つ確認されます。「Technical and interaction data」を許可した場合だけ利用状況イベントが送信されます。「Website content」は必要になった最初の時点で許可を求め、許可後だけページ内容が送信されます。それぞれの範囲は[プライバシーと権限](/docs/privacy-and-permissions)をご覧ください。

アカウントへの接続は Chrome、Edge と同じ手順です。接続が必要な操作と接続方法は[アカウントと同期](/docs/account-and-sync)に記載しています。

## ブラウザーが求める権限

どのサイトでも動画を検出できるよう、拡張機能はすべてのサイトへのアクセス権を求めます。各権限が必要な理由は[プライバシーと権限](/docs/privacy-and-permissions)で説明しています。
