学習タイマーは集中と休憩を交互に進めます。文字起こしパネルでは動画にすでに付いている字幕を横で読めます。「AI で章を作る」はその字幕から章を作ります。タイマーと文字起こしにアカウントは不要です。

## 学習タイマー

ウィジェットの「スマート」タブで「学習タイマー」を開きます。

1. プリセットを選びます。「標準 25/5」「短め 15/3」「長時間集中 50/10」「学習 45/10」または自分で時間を指定できます。
2. 「開始」を押します。集中、休憩、長い休憩の状態と現在の回が表示されます。
3. 必要に応じて「一時停止」「再開」「休憩へ進む」を押します。
4. 「タイマーをリセット」で最初から始めます。

今日の集中時間は「1 日の集中目標」に加算され、連続した日数も表示されます。タイマーはブラウザー全体で 1 つ動き、記録はそのブラウザーに残ります。

設定の「動画機能」タブにある「学習タイマー」では、各時間、何回ごとに長い休憩を入れるか、目標を設定できます。休憩中の動画一時停止、休憩後の再開、各回の終了音、ブラウザー通知も選べます。

## 文字起こし

ウィジェットの「ツール」タブで「文字起こしを表示」を押すと、動画にもともと付いている字幕が横のパネルに出ます。再生中の行が強調されます。

- 行をクリックすると、その時刻へ移動します。
- 「文字起こしを検索」で行を探せます。
- 「動画を追う」で再生中の行を画面内に保てます。
- 「すべてコピー」で全文をコピーできます。

字幕がない動画では「この動画には字幕がないため、文字起こしはありません」と表示されます。拡張機能が音声から字幕を生成するわけではありません。

## 字幕から章を作る

文字起こしパネルで「AI で章を作る」を押します。1 回の AI 利用で字幕から 3～15 章を作ります。AI 要約と同じ経路を使い、接続済みアカウントの Shared allowance、自分のキー、またはローカルモデルを選べます。[AI 機能](/docs/ai-features)をご覧ください。

章をクリックするとそこへ移動し、再生中の章が示されます。「章をコピー」では「0:00 題名」の行を取得できます。「もう一度作る」には新たに 1 回分の利用が必要です。章はブラウザー内に動画ごとに保存され、最大 50 本分残ります。

## 区間を練習する

ウィジェットの「ループ」タブにある「練習」は、[A-B ループ](/docs/user-guide/ab-loop)の難しい区間を学ぶための機能で、アカウント接続が必要です。「各回の前に一時停止」は A 点で 1～5 秒待ちます。「毎回少し速く」は通常速度まで 5% または 10% ずつ上げます。先に遅い速度を設定してください。

## ショートカット

「学習タイマーの開始／一時停止」と「文字起こしの表示／非表示」は初期状態でキーがありません。[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)から割り当てられます。
