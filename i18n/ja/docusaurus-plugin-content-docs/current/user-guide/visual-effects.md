「見た目とオーバーレイ」では、色調、アート風の表示、シャープ化、周辺減光、フィルム粒子、文字、部分ぼかしを動画に加えられます。[アカウントの接続](/docs/account-and-sync)が必要なウィジェットの「フィルター」タブにあります。「ズームとフィット」は「表示」タブにあり、アカウント不要です。

効果が変えるのはページ上の映像だけで、動画ファイルは変わりません。保護された動画では、配信サイトによって効果が使えない場合があります。

## 見た目とオーバーレイ

ウィジェットの「フィルター」タブで「見た目とオーバーレイ」を開きます。

| 操作 | 内容 |
|---|---|
| 色調 | Teal & orange、Film noir、Vintage 8mm、Golden hour、Moonlight など 20 種類。「強さ」で調整 |
| アート風 | 油絵、鉛筆画、版画、色付きエンボス |
| シャープ化 | 0～100%、10 刻み。色の調整より前に適用 |
| 周辺減光 | 映像の四隅を暗くする |
| フィルム粒子 | 静止または動く粒子を加える |
| 文字 | 指定した文字を映像の隅に重ねる |
| 領域をぼかす | 動画上で枠をドラッグして、その部分をぼかす |
| すべての効果をオフ | 元の見た目に戻す |

ぼかした領域は「ぼかし領域を削除」を押すか、動画が変わるまで残ります。動画の画素を読み取らず、ページ上でぼかします。

## 詳しい効果設定

設定の「動画機能」タブにある「効果」では、周辺減光の強さ、粒子の強さ、動く粒子、重ねる文字、文字の位置（左上、右上、左下、右下）を調整できます。「効果をリセット」で初期値に戻ります。

効果は[映像フィルター](/docs/user-guide/video-filters)、[Comfort](/docs/user-guide/comfort-and-accessibility)と同時に使え、全画面表示でも動画に付いていきます。

## ズームとフィット

ウィジェットの「表示」タブで「ズームとフィット」を開きます。アカウントは不要です。

1. 「拡大」または「縮小」を押します。1x～4x の間を 0.25x ずつ変えられ、トラックパッドのピンチ操作も使えます。
2. 4 方向の矢印で表示位置を上下左右に動かします。
3. 「拡大鏡：ポインターを追う」をオンにすると、拡大位置がマウスに付いていきます。
4. 「フィット」を原寸、画面に合わせる（余白を切り取る）、引き伸ばす、4:3、16:9、21:9 から選びます。

「元の映像に戻す」でズームもリセットされます。ズームは回転、左右反転、上下反転と併用できますが、「変形をリセット」ではズームが残ります。新しい動画は原寸で始まり、ここでの設定は保存されません。

## ショートカット

「効果のオン・オフ」と「動画の一部をぼかす」は、初期状態ではキー未割り当ての操作です。押したときにアカウント接続が必要です。[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)から割り当ててください。
