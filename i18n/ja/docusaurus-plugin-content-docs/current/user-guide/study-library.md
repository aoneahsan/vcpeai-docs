ウィジェットの「ツール」タブから、現在の場面にクイズ、字幕行とともに単語、日記を保存し、動画を学習経路やコレクションへ追加できます。どれも[アカウントの接続](/docs/account-and-sync)が必要で、動画の題名とアドレスとともにアカウントに保存されます。サインアウト中は各欄に接続方法が表示されます。

## この場面でクイズを作る

「この場面のクイズ」で「質問」と「答え」を入力し、「クイズを保存」を押します。フラッシュカードとして保存されます。

同じ動画でその時刻を再生中に通過すると、動画が止まり、質問が表示されます。「答えを見る」の後に「分かった」または「まだ」を押すと、フラッシュカードページと同じ方法で採点されます。「この動画でクイズを表示しない」で今回の訪問中は止められます。各場面で尋ねるのは訪問ごとに 1 回だけで、シークで通過した場合は尋ねません。

## 単語を保存する

「単語を保存」に単語を 1 つ入力し、「調べる」を押します。意味は最大 3 件表示されます。「単語を保存」を押すと、その時点の字幕行を用例にしたフラッシュカードになります。

単語の意味は Wiktionary に問い合わせます。送信されるのはその単語だけです。

## 日記を残す

気分（うれしい、刺激を受けた、落ち着いた、考え込んだ、悲しい、いら立った）を選び、「この場面で感じたこと」を書いて「日記に保存」を押します。「Diary」フォルダーのブックマークとして気分タグ付きで保存され、ブックマーク側でも編集できます。

## 学習経路とコレクション

「学習経路」または「コレクション」で自分の項目を選び、「この動画を追加」を押します。すでに入っている動画は重複追加できません。先に製品サイトで経路やコレクションを作ってください。まだない場合はウィジェットが知らせます。

Watch History に視聴済みと記録されると、学習経路の動画も自動で完了になります。動画の 90% を超える位置まで進み、その過程で少なくとも半分を再生した場合に数えます。最後へ飛ぶだけでは数えられません。Watch History は設定の「プライバシーとデータ」タブでオンにするまで無効です。

## ライブラリーを検索する

「ライブラリーを検索」は、ウィジェットの「ライブラリー」メニューとポップアップのライブラリー一覧にあります。製品サイトで、メモ、ブックマーク、日記、フラッシュカード、保存した単語、文字起こし、Watch Later、Watch History、コレクション、学習経路をまとめて検索できます。2～100 文字入力すると、種類ごとに最大 10 件、該当する場面へのリンクとともに表示されます。

## 製品サイトのページ

| ページ | 内容 |
|---|---|
| フラッシュカード | 復習するクイズと単語 |
| 単語帳 | 保存した単語と、それぞれの動画の場面 |
| Clip Diary | 新しい日付から並ぶ日記。気分で絞り込み可能 |
| コースの進捗 | 学習経路ごとの完了数・総数と次の動画 |
| コレクション | JSON、CSV、Markdown、M3U プレイリストで書き出せる項目 |
