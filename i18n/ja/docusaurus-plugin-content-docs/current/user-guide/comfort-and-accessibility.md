Comfort には、映像を暖色にする、色を区別しやすくする、サイトが表示する字幕の見た目を変える、映像上に読書ガイドを置く 4 つの機能があります。ウィジェットの「表示」タブにあり、アカウントは不要です。

選んだ設定はほかの設定と一緒に保存されます。クラウド同期をオンにした場合だけ、アカウントにも同期されます。Comfort 自体が視聴内容を別のサービスへ送ることはありません。

## 設定の場所

| 場所 | 内容 |
|---|---|
| ウィジェットの「表示」タブ → Comfort | 4 つの機能のスイッチと「Comfort の詳細設定」 |
| 設定の「動画機能」タブ → Comfort とアクセシビリティ | 全項目と「Comfort 設定をリセット」 |
| 設定の「キーボードショートカット」→ Comfort | 初期状態ではキー未割り当ての 4 操作 |

## 目の負担を和らげる

夕方に見るなら「目に優しい表示」をオンにし、「暖かさ」を 0～100% で調整します。変わるのは動画だけで、ページ全体ではありません。「明るさも下げる」を選ぶと、さらに柔らかくできます。

「指定した時間に自動でオンにする」は自動で切り替えます。「開始」と「終了」を設定してください。変更するまでは 21:00 に始まり 07:00 に終わります。

## 色の見え方

「種類」では緑が弱い、赤が弱い、青と黄が見分けにくい、色を使わない表示から選びます。続けて「モード」を選びます。

- 「色を区別しやすくする」は、違いが分かりやすいよう色を調整します。
- 「見え方を確認する」は、選んだ色覚での映像の見え方を表示します。

## 字幕の見た目

サイトがすでに表示する字幕のスタイルを変えます。YouTube、Netflix、Prime Video、Udemy、Coursera、Vimeo、Khan Academy、Video.js プレーヤー、WebVTT 字幕付き動画に対応します。字幕そのものは生成しません。

「字幕の見た目」と「文字サイズ」を選びます。

| 見た目 | 内容 |
|---|---|
| 標準 | 暗い帯に白い文字 |
| 高コントラスト | 黒い帯に大きな太字の白い文字 |
| ダーク | 濃い灰色に柔らかい明色の文字 |
| ミニマル | 明るめの帯に小さな文字 |
| 大きな文字 | 大きく太い黄色の文字 |
| カラフル | 濃い紫に太い緑の文字 |
| 読みやすさ重視 | クリーム色の背景と濃い文字。字間・語間・行間を広くしたサンセリフ |

## 読書ガイド

柔らかい帯で字幕や画面上の文字の 1 行に視線を合わせられます。「形」は帯、線、スポットライトから選びます。「位置を固定」すると動画の一定の高さに置かれ、「ポインターを追う」ではマウスに合わせて動きます。「動画内の高さ」で位置、「強さ」で見え方を調整します。

## ほかの操作と合わせる

Comfort は[映像フィルター](/docs/user-guide/video-filters)やシネマの色設定と同時に使えます。拡張機能が動画上で 1 つのフィルターにまとめるため、一方をオンにしても他方はオフになりません。

## ショートカット

「目に優しい表示」「色の見え方」「字幕スタイル」「読書ガイド」の 4 操作は、初期状態ではキーがありません。必要なら設定から割り当ててください。[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)に手順があります。
