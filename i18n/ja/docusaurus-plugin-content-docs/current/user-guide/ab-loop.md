A-B ループは、指定した 2 点の間だけを繰り返し再生します。[アカウントの接続](/docs/account-and-sync)が必要です。速度調整には必要ありません。ループのキーが反応しない場合は、先にアカウントを接続してください。

## 繰り返す区間を決める

1. 繰り返したい箇所の始まりまで動画を再生します。
2. `Ctrl + Alt + A` を押して A 点を決めます。
3. 区間の終わりまで再生します。
4. `Ctrl + Alt + B` を押して B 点を決めます。

B 点に達すると A 点へ戻り、解除するまでその区間を再生します。ウィジェットの「ループ」タブからも A と B をそれぞれ 1 回のクリックで設定できます。

ギター練習の速い 1 小節、40 秒で過ぎる講義の証明、聞き取りにくい外国語の 1 文にも使えます。前後に A と B を置き、`[` で速度を落として繰り返してください。

## ループのキー

| キー | 動作 |
|---|---|
| `Ctrl + Alt + A` | 始点 A を設定 |
| `Ctrl + Alt + B` | 終点 B を設定 |
| `Ctrl + Alt + L` | ループのオン・オフ |
| `Ctrl + Alt + Backspace` | 2 点とも消去 |

## 繰り返し方を選ぶ

ウィジェットの「ループ」タブで選びます。表示言語は、英語、スペイン語、フランス語、ドイツ語、ウルドゥー語が有効な場合、そのブラウザー言語に従います。[言語表示の設定](/docs/user-guide/display-and-widget)もご覧ください。

| モード | B 点に達したとき |
|---|---|
| 無制限 | オフにするまで区間を繰り返す |
| 1 回 | 区間を 1 回繰り返す |
| 回数指定 | 指定した 1～20 回だけ繰り返す |

回数指定では進捗が表示され、20 回で止まります。それ以上繰り返すなら「無制限」を選び、`Ctrl + Alt + L` で手動停止してください。

## 関連するキー

`,` と `.` で 1 フレームずつ動かすと、A と B の位置を細かく決められます。[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)に全キーがあり、[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)で割り当てを変えられます。
