[アカウントを接続](/docs/account-and-sync)してから `Ctrl + Alt + C` を押すと、現在のフレームを PNG または JPEG で撮影できます。

## 1 枚撮る

1. 撮りたい場面で動画を止めます。再生したままでも撮影できます。
2. `Ctrl + Alt + C` を押すか、ウィジェットの「ツール」タブで「キャプチャ」を押します。
3. 設定で選んだ動作に従い、画像がダウンロード、コピー、またはアップロードされます。

一時停止して `,` または `.` で 1 フレームずつ動かすと、講義のスライドが完成した瞬間を撮れます。

## 形式と保存先を選ぶ

設定の「動画機能」タブで「スクリーンショット」カードを開きます。

| 項目 | 選択肢 |
|---|---|
| 形式 | PNG（画質重視）、JPEG（ファイルサイズ重視） |
| 動作 | ダウンロード、クリップボードへコピー、両方、クラウドへアップロード、クラウドとクリップボード |
| クラウド公開範囲 | 非公開または公開。クラウド操作で使用 |
| クラウドライブラリーと同期 | オン・オフ |
| 時刻を入れる | オン・オフ |
| 時刻の位置 | 左上、右上、左下、右下 |

画像に入る時刻は、撮影したフレームの動画内時刻です。講義スライドに入れておけば、後で元の位置を探せます。

## 画像はどこに保存されますか

クラウド操作を選ぶと画像がアップロードされます。それ以外では端末上に残ります。

## 動いている場面を残すには

スクリーンショットは 1 フレームです。動く区間は「クリップ録画」で記録してダウンロードできます。設定の「ダウンロードとキャプチャ」タブに切り替えがあります。

## 関連するキー

| キー | 動作 |
|---|---|
| `Ctrl + Alt + C` | 現在のフレームを撮影 |
| `,` | 1 フレーム戻す |
| `.` | 1 フレーム進める |

開始時の割り当ては[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)にあり、[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)で変えられます。
