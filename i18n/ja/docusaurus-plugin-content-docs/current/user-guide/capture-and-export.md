「キャプチャと書き出し」では動画から GIF、クリップ、タイムラプス、連続スクリーンショット、一覧画像を作り、画像に書き込むこともできます。ウィジェットの「ツール」タブにあり、[スクリーンショット](/docs/user-guide/screenshots)と同じく[アカウントの接続](/docs/account-and-sync)が必要です。

作成と保存はすべて端末上で行われ、ダウンロードされます。アップロードはしません。

## 作れるもの

| ボタン | 出力 |
|---|---|
| 「GIF・次の 5 秒」 | 次の 3、5、10、15 秒を繰り返す GIF。幅は 320、480、640 px |
| 「● クリップを録画」 | 映像と音声を含む WebM。「■ 録画停止」で終了 |
| 「タイムラプス 4x」 | 映像のみの WebM。2x、4x、8x、16x |
| 「5 秒ごとに連続撮影」 | 再生中に 2、5、10、30 秒ごとに撮影。最大 100 枚 |
| 「一覧画像 3×3」 | 動画全体から 3×3 または 4×4 コマを選び、時刻付きの 1 枚の PNG にする |
| 「注釈」 | 書き込み可能なスクリーンショット |

ボタン上の数値は設定に合わせて変わります。クリップとタイムラプスは動画終了時、または最長 10 分で自動停止します。

連続撮影中はボタンに枚数が表示されます。枚数付きの「…を ZIP で保存」では PNG をまとめた ZIP に、「一覧画像として保存」では 1 枚の画像にできます。

## スクリーンショットに注釈を入れる

1. 「注釈」を押すと、現在のフレームで「スクリーンショットに注釈」パネルが開きます。
2. 矢印、四角、ハイライト、文字、ペンから道具を選びます。
3. 赤、黄、緑、青、白から色を選びます。
4. 画像上をドラッグして描きます。文字ではクリックして入力し、Enter で確定します。
5. 「PNG を保存」でダウンロードするか、「コピー」でクリップボードへ送ります。

`Ctrl + Z` で最後の書き込みを取り消せます。`Esc` でパネルを閉じます。

## 撮影の設定

設定の「動画機能」タブにある「キャプチャと書き出し」で、GIF の長さと幅、タイムラプスの速度、連続撮影の間隔、一覧画像の大きさを選びます。「撮影設定をリセット」で初期値に戻せます。

## 撮影できない場合

Netflix、Disney+ など保護された動画は撮影できず、ほかのサイトでもフレーム保存が認められない場合があります。ウィジェットが理由を示します。一覧画像には長さが分かる動画が必要なので、ライブ配信では作れません。一時停止中も撮影できないため、まず再生してください。

## ショートカット

「クリップの録画／停止」「GIF を作成」「スクリーンショットに注釈」は初期状態でキーがありません。どれもアカウント接続が必要です。[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)から設定できます。

共有向けの形でクリップを作る場合は[共有と同時視聴](/docs/user-guide/share-and-watch-together)もご覧ください。
