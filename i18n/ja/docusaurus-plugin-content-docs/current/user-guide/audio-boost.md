[アカウントを接続](/docs/account-and-sync)すると、音量を 100% より上げ、最大 400% まで増幅できます。`Ctrl + Alt + U` で上げ、`Ctrl + Alt + Y` で下げます。

## 音声操作のキー

| キー | 動作 |
|---|---|
| `Ctrl + Alt + U` | 増幅率を 20% 上げる |
| `Ctrl + Alt + Y` | 増幅率を 20% 下げる |
| `Ctrl + Alt + N` | ノーマライズのオン・オフ |

同じ操作はウィジェットの「音声」タブからもできます。

## 音量を増幅する

教室の後方で録った講義など、プレーヤーの 100% でも聞こえにくい録音を 100%～400% の範囲で大きくできます。

キーを押すたびに 20% 変わります。400% では音量の大きい動画がさらに大きくなるため、少しずつ上げてください。

## 音の大小を均す

ノーマライズは音の最大・最小の差を小さくします。話し声は小さいのに冒頭の音楽が大きい動画なら、`Ctrl + Alt + N` でオンにできます。

## サイトごとの音量を記憶する

拡張機能はサイトごとに音量とミュート状態を覚えます。YouTube は小さく、講義サイトは大きく設定しておけば、次回もそれぞれの状態に戻ります。設定の「動画機能」タブに「音量を記憶」カードがあります。

## そのほかの音声操作

音を大きくする以外にも、低音増幅、ノイズ低減、ボーカルの分離など 8 種類のボタンが、ウィジェットの「音声」タブにある「高度な音声処理」に並んでいます。タブはアカウント接続後に使えます。

| ボタン | 動作 |
|---|---|
| Bass | 低音を増幅 |
| Denoise | 背景ノイズを低減 |
| Spatial | 立体的な音場にする |
| Vocals | ボーカルを分離 |
| Compress | 音声の強弱を圧縮 |
| Karaoke | カラオケモード |
| Pitch | 音程のプリセット |
| EQ | イコライザーのプリセット |

## 音声をダウンロードする

音声ダウンロードでは動画の音声を WebM または WAV で保存できます。MP3 には対応していません。設定の「ダウンロードとキャプチャ」タブにある「音声ダウンロード」をオンにします。処理は端末上で行われます。
