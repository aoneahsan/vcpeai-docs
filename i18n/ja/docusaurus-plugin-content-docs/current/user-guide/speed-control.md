---
title: 動画の再生速度を変える
sidebar_label: 速度調整
description: 角括弧キーやウィジェットで 0.1x 刻み、最大 4x まで調整できます。数値入力では最大 16x、プリセットは 8 件です。
---

`]` と `[` で 0.1x ずつ変えるか、ウィジェットのスライダーで最大 4x まで調整します。角括弧キーは `Ctrl + Alt` なしで使えます。速度調整にアカウントは不要です。

## 速度操作のキー

| キー | 動作 |
|---|---|
| `]` | 0.1x 速くする |
| `[` | 0.1x 遅くする |
| `=` | 既定の速度に戻す |
| `\\` | 現在の速度を表示 |
| `'` | 動的速度に切り替える |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## 速度の範囲

設定できる範囲は 0.1x～16x です。スライダーと角括弧キーは 4x で止まります。16x まで使うには、ウィジェットの「速度」タブにある数値入力、または設定の「一般」タブにある「カスタム速度（0.1x～16x）」へ直接入力します。

変更幅は常に 0.1x です。最小速度、最大速度、変更幅を変える設定はありません。

## 既定の速度と動的速度

設定の「一般」タブを開きます。

| 設定 | 用途 | キー |
|---|---|---|
| 既定の再生速度 | リセット時や新しい動画を開いたときの速度 | `=` |
| 現在の動的速度 | ここで別の速度を指定し、キー 1 回で適用 | `'` |

`'` は「現在の動的速度」を適用します。動画に保存された速度を呼び出すキーではありません。

## 速度のプリセット

初期設定では `Ctrl + Alt + 1`～`Ctrl + Alt + 8` に 8 件あります。それぞれ編集でき、使わないものは設定の「キーボードショートカット」タブで削除できます。

9 件目を追加すると `Ctrl + Alt + 9` を使えます。

## 速度を記憶する

拡張機能は動画ごとに指定した速度を覚え、次に同じ動画を開いたときに適用します。初期設定でオンです。

プレイリストやコース全体に 1 つの速度を保存する機能もあります。初期設定ではオフで、設定の「詳細」タブから有効にします。

動画に複数の保存済み速度がある場合は「速度の優先順位」で決めます。

| 設定 | 優先される速度 |
|---|---|
| プレイリスト／コースを優先 | プレイリストまたはコースに保存した速度 |
| 動画を優先 | 動画に保存した速度 |
| 全体設定のみ（保存値を無視） | 既定の速度。保存済み速度は使わない |

## 関連するキー

`,` と `.` は 1 フレームずつ戻す／進めるキーです。全キーは[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)にあり、[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)で割り当てを変えられます。
