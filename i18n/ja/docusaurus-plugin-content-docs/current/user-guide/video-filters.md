明るさ、コントラスト、彩度はそれぞれ 0～200% で調整できます。グレースケール、色の反転、夜間モードもあります。[アカウントを接続](/docs/account-and-sync)してから `Ctrl + Alt + F` を押すと、ウィジェットの「フィルター」タブが開きます。

## 操作の一覧

| 操作 | 範囲・効果 | キー |
|---|---|---|
| フィルタータブ | 開閉 | `Ctrl + Alt + F` |
| 明るさ | 0～200% | スライダー |
| コントラスト | 0～200% | スライダー |
| 彩度 | 0～200% | スライダー |
| グレースケール | オン・オフ | `Ctrl + Alt + G` |
| 色の反転 | オン・オフ | `Ctrl + Alt + I` |
| 夜間モード | オン・オフ | `Ctrl + Alt + T` |

100% がサイトから届いたままの映像です。100% 未満にすると弱く、超えると強くなり、スライダーは 200% で止まります。同じタブの「すべてのフィルターをリセット」で元に戻せます。

## 使いどころ

白い背景に薄い灰色の文字がある画面録画では、コントラストを上げると読みやすくなります。

明るい午後に暗い映像が見づらいときは、明るさを上げます。

夜に白板の講義を見るなら、`Ctrl + Alt + I` で色を反転するか、`Ctrl + Alt + T` で夜間モードを試せます。

## プリセットを保存する

3 つのスライダーを調整し、「フィルター」タブでプリセットとして保存します。最大 20 件保存できます。プリセットは設定の一部なので、[設定のエクスポート](/docs/account-and-sync)に含められます。

## ほかの映像操作

ウィジェットの別の 2 タブも映像を変えます。フィルタータブとは別の機能です。

| 場所 | 操作 | 効果 |
|---|---|---|
| 「表示」タブの「変形」 | 回転、左右反転、上下反転 | 90 度回転、水平または垂直方向に反転 |
| 「ツール」タブの「表示モード」 | Ambient | プレーヤーの周囲に環境光を表示 |
| 「ツール」タブの「表示モード」 | Cinema | 映画向けの色のプリセット |
| 「ツール」タブの「表示モード」 | Letterbox | 映像の上下に黒帯を追加 |

フィルターが変えるのはブラウザーでの映像表示です。スクリーンショットやダウンロードは別の操作です。
