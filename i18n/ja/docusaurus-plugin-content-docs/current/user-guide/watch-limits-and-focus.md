視聴制限では、全サイトまたは個別サイトで 1 日の動画時間を決め、動画を再生させないサイトも指定できます。Focus Mode は動画の周囲を暗くし、気が散る部分を隠します。どちらも設定の「動画機能」タブにあり、アカウントは不要です。

## 視聴時間を設定する

1. 設定の「動画機能」タブで「視聴制限」を探します。
2. 「視聴制限」をオンにします。
3. 「全サイトの 1 日の上限」を 30 分～4 時間で選びます。
4. 「上限前の通知」を 5、10、15 分前から選びます。
5. 「サイト別の制限」でサイトと 1 日の分数を入力し、「追加」を押します。
6. 「ブロックするサイト」には、動画を再生させないサイトを追加します。

カードの「この端末の今日の時間」に、これまでの分数が表示されます。

## 時間に達したとき

動画が止まり、全体の上限では「今日の視聴時間に達しました」、サイト別では「このサイトの今日の時間に達しました」と表示されます。「あと 5 分」で少し続けるか、「閉じる」を押します。集計は午前 0 時に始め直します。

ブロックしたサイトでは「このサイトの動画はブロックされています」と表示されます。

## PIN で設定を守る

「新しい PIN」に 4～8 桁の数字を入力し、「PIN を再入力」に同じ数字を入れて「ロック」を押します。その後、制限の変更、サイトのブロック解除、追加の 5 分には PIN が必要です。「PIN を削除」で解除できます。

PIN は安全な場所に控えてください。ハッシュ化してこの端末だけに保存し、同期しません。

## 何が数えられますか

視聴時間は、この端末で制限がオンの間だけ数えます。保存するのはサイトごとの今日の分数だけで、午前 0 時に始め直します。データは送信しません。

習慣や子どもの視聴時間を把握する助けになりますが、改変を完全に防ぐ機能ではありません。ブラウザーの拡張機能データを変更できる人は制限を回避できます。

[YouTube 専用の視聴制限](/docs/platforms/youtube)は別の機能で、これまでどおり動作します。

## Focus Mode

ウィジェットの「Focus」ボタンでオンにします。設定の「動画機能」タブにある「Focus Mode」で動作を選びます。

| 設定 | 動作 |
|---|---|
| ページを暗くする度合い | 動画の周りをどれだけ暗くするか |
| 隠す項目 | コメント、サイドバー、サイトのヘッダー、推奨動画、終了画面とカード、ライブチャット |
| 動画を開くたびに開始 | 新しい動画ごとに自動でオン |

変更はすでに開いている Focus Mode にもすぐ反映されます。YouTube、Netflix、Vimeo、Twitch、Udemy のほか、ページ構造が許す範囲でほかのサイトでも動作します。

Focus Mode と、`Ctrl + Alt + Z` で切り替えるシアターモードは別機能です。[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)もご覧ください。
