メモを保存する前にアカウントを接続してください。メモには動画の時刻が付き、製品サイトの「メモ」ページにも表示されます。ウィジェットの「ツール」タブに、メモ入力、書き出し、ライブラリーへの移動があります。

## メモを取る

1. ウィジェットの「ツール」タブを開きます。
2. 「メモと抽出」で「メモ」を押します。
3. 表示された入力欄に書き、確定します。

現在の時刻とともにアカウントへの保存待ちに入ります。動画を右クリックして「メモを追加」からも開けます。接続していない場合は、入力前に接続を求めます。

講義の 12:40 で書いたメモには 12:40 が残り、どの説明に対応するか分かります。メモは非公開で、サイトのコメント欄へ投稿されることはありません。

読み返したり編集したりするには、ウィジェットの「ツール」タブで「ライブラリー」から「メモ」を選びます。製品サイトのアカウント内「メモ」ページが開きます。

## メモを書き出す

同じ場所で形式を選びます。アカウントにあるメモと、このブラウザーで同期を待っているメモが含まれます。

| ボタン | 出力 |
|---|---|
| Notes MD | Markdown ファイル |
| Notes TXT | テキストファイル |
| Notes JSON | JSON ファイル |

Markdown では各メモが時刻とともに 1 行ずつ並ぶため、講義ノートと一緒に保管できます。

## ブックマークを付ける

「ツール」タブの「ブックマーク」、動画の右クリックメニューにある「ブックマークを追加」、または `Ctrl + Alt + O` を使います。アカウントがなくても保存できますが、その場合はこのブラウザー内だけに残ります。

拡張機能を接続していると、新しいブックマークは現在の時刻で保存され、アカウントへ同期されます。検索、編集、削除、書き出しは、ウィジェットの「ライブラリー」から「ブックマーク」を選ぶか、製品サイトの[メモページの「ブックマーク」タブ](https://vcpeai.aoneahsan.com/notes?tab=bookmarks)で行えます。接続前に作ったブックマークはそのブラウザー内に残り、後から接続しても自動アップロードされません。「クラウド同期を有効にする」は設定の同期を別に制御します。

## 文字起こしをダウンロードする

同じ場所の「文字起こし」を押すと、動画の文字起こしをテキストで保存できます。プレーヤーの外で読めます。

## 場面を共有する

`Ctrl + Alt + X` で現在の動画時刻を含むリンクをコピーできます。YouTube、Vimeo、Twitch などで使えます。リンクに含まれるのは時刻だけです。

## 関連するキー

| キー | 動作 |
|---|---|
| `Ctrl + Alt + O` | 現在位置にブックマークを追加 |
| `Ctrl + Alt + X` | 時刻付きリンクをコピー |
| `Ctrl + Alt + C` | 現在のフレームを撮影 |

開始時の割り当ては[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)にあり、[ショートカットの変更](/docs/keyboard-shortcuts/rebinding)で変えられます。
