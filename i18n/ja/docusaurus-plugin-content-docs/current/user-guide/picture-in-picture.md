アカウントを接続してから `Ctrl + Alt + P` を押すと、動画がピクチャーインピクチャーの小窓に移ります。もう一度押すと元に戻ります。

## 小窓で見る

1. 動画を再生します。
2. `Ctrl + Alt + P` を押します。
3. 別のタブに切り替えても、小窓で再生が続きます。
4. `Ctrl + Alt + P` をもう一度押して終了します。

小窓でも `]` と `[` で速度を変えられます。そのほかの速度操作も引き続き使えます。

## スクロールしたら自動で小窓にする

長いページで動画が画面外に出たとき、自動でピクチャーインピクチャーに切り替えられます。

1. 設定の「詳細」タブを開きます。
2. 「再生機能」を探します。
3. 「ピクチャーインピクチャー」がオンになっていることを確認します。
4. 「スクロール時に自動でピクチャーインピクチャーへ」をオンにします。

## 関連するキー

| キー | 動作 |
|---|---|
| `Ctrl + Alt + P` | 小窓のオン・オフ |
| `Ctrl + Alt + Z` | シアターモードのオン・オフ |
| `]` / `[` | 小窓でも 0.1x 速く／遅くする |

割り当てを変えるには、[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)を確認し、[ショートカットを変更](/docs/keyboard-shortcuts/rebinding)してください。
