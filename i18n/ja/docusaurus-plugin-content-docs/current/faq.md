## Video Controls Plus とは何ですか

HTML5 動画に再生操作を加えるブラウザー拡張機能です。標準的な動画のあるサイトで動き、YouTube、Netflix、LinkedIn には専用機能もあります。Chrome、Edge、Firefox 向けです。[インストール方法](/docs/getting-started/install)をご覧ください。

## 動画の速度はどう変えますか

`]` と `[` で 0.1x ずつ変えるか、ウィジェットのスライダーで最大 4x まで調整します。それより速くするにはウィジェットの数値入力、または設定の「一般」タブにあるカスタム速度欄に入力し、最大 16x まで指定します。アカウントは不要です。[速度調整](/docs/user-guide/speed-control)をご覧ください。

## A-B ループとは何ですか

自分で決めた 2 点の間を繰り返す機能で、[アカウントの接続](/docs/account-and-sync)が必要です。始点で `Ctrl + Alt + A`、終点で `Ctrl + Alt + B` を押します。`Ctrl + Alt + Backspace` で 2 点を消すまで繰り返します。[A-B ループ](/docs/user-guide/ab-loop)をご覧ください。

## 音量を 100% より上げられますか

はい。[アカウント接続後](/docs/account-and-sync)、最大 400% まで上げられます。`Ctrl + Alt + U` で増幅し、`Ctrl + Alt + Y` で下げます。[音量増幅](/docs/user-guide/audio-boost)をご覧ください。

## 動画のスクリーンショットはどう撮りますか

アカウント接続後に `Ctrl + Alt + C` を押すと、現在のフレームを PNG または JPEG で保存できます。設定でダウンロード、クリップボード、両方から選べます。[スクリーンショット](/docs/user-guide/screenshots)をご覧ください。

## どの映像フィルターがありますか

明るさ、コントラスト、彩度を 0～200% で調整できます。グレースケール、色の反転、夜間モードもあり、アカウント接続後は最大 20 件のプリセットを保存できます。[映像フィルター](/docs/user-guide/video-filters)をご覧ください。

## ショートカットは何ですか

英字と数字には `Ctrl + Alt` が必要で、`[`、`]`、`=`、`\\`、`'`、`,`、`.`、`Esc` だけは単独で動きます。設定から変更できます。[初期設定のショートカット](/docs/keyboard-shortcuts/defaults)と[変更方法](/docs/keyboard-shortcuts/rebinding)をご覧ください。

## 視聴しながらメモを取れますか

はい。アカウント接続後、ウィジェットの「ツール」タブで時刻付きのメモを保存し、Markdown、テキスト、JSON で書き出せます。`Ctrl + Alt + O` のブックマークはアカウントなしでブラウザー内に保存できます。接続中の新しいブックマークはアカウントにも表示されます。[メモとブックマーク](/docs/user-guide/notes-and-bookmarks)をご覧ください。

## 対応する動画サイトはどこですか

標準的な HTML5 動画があるサイトです。YouTube、Netflix、LinkedIn には専用機能があり、別のページに埋め込まれた動画にも共通操作が付きます。[そのほかのサイト](/docs/platforms/other-sites)をご覧ください。

## Firefox でも動きますか

はい。Firefox 140 以降が必要です。「アカウントに接続」をアドオンで押し、製品サイトで確認する手順は Chrome、Edge と同じです。どのブラウザーでも拡張機能内でのサインインはありません。[アカウントと同期](/docs/account-and-sync)をご覧ください。

## Netflix でも動きますか

速度などの共通操作は使えます。Netflix 専用機能は初期状態でオフで、設定の「Netflix 機能」タブからオンにします。[Netflix](/docs/platforms/netflix)をご覧ください。

## 個人データを収集しますか

はい、一部を記録します。「利用状況の分析」がオン（初期設定）なら、アカウントの有無にかかわらず利用イベントが送られ、位置確認のため IP アドレスが 1 日に最大 1 回 ipapi.co に送られます。接続したアカウントにはアカウント情報と設定も保存されます。設定の「プライバシーとデータ」で分析をオフにすると、利用状況の記録は止まります。[プライバシーと権限](/docs/privacy-and-permissions)をご覧ください。

## データはどう削除しますか

設定の「プライバシーとデータ」タブで、「あなたのデータ」の「すべてのデータを削除」を押します。アカウント本体、その下に保存されたファイルとデータがすべて消えるため、拡張機能がアカウントに接続中である必要があります。[アカウントと同期](/docs/account-and-sync)をご覧ください。
