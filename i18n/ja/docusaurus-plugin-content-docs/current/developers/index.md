# 開発者向け Video Controls Plus

**自分で接続したツールから、拡張機能の外にある Video Controls Plus のライブラリーへアクセスできます。** アクセスキーを使うスクリプト、Claude や ChatGPT などのアシスタント、変更を Webhook で受け取る自分のサーバーに対応しています。三つとも、ウェブサイトの**アカウント → [ほかのアプリ](https://vcpeai.aoneahsan.com/account/apps)**で設定できます。Free を含むすべてのプランで利用できます。

キー、アシスタント、Webhook のそれぞれでアクセス範囲を選びます。操作は自分の権限で行われ、ウェブサイトで自分に見えないデータにはアクセスできません。

## 三つの接続方法 {#three-ways-in}

| したいこと | 使うもの | 案内 |
|---|---|---|
| スクリプト、スプレッドシート同期、スマートフォンのショートカットからライブラリーを読み書きする | アクセスキーと REST API | [アクセスキー](./access-keys.md)、[API](./api.md) |
| Claude、ChatGPT、Claude Code、Cursor にメモやフラッシュカードについて尋ねる | アシスタント接続先（MCP） | [アシスタント](./assistants.md) |
| メモやブックマークを保存したらすぐに自分のサーバーへ知らせる | Webhook の接続先 | [Webhook](./webhooks.md) |

## 外部アプリがアクセスできる内容 {#what-an-outside-app-can-reach}

選んだ範囲の、自分のデータだけです。

- **読み取りと変更：** ブックマーク、メモ、コレクションとその中の動画、フラッシュカード、学習経路と動画、あとで見る項目、文字起こし、設定、拡張機能を接続したブラウザー。
- **読み取りと削除：** 視聴履歴。追加できるのは、視聴履歴をオンにした拡張機能だけです。
- **読み取り：** スクリーンショット。削除は拡張機能で行います。
- **削除：** 対象の「削除」を選んだ場合です。アクセスキーは直接削除します。アシスタントからの削除要求は、ウェブサイトでの承認を待ちます。
- **読み取り専用：** 主催または参加した共同視聴、コミュニティのサイト修正、投票を含む機能リクエスト。
- **常に読み取り可能：** プラン、上限、今日の利用状況。

### アクセスできない内容 {#what-it-never-reaches}

権限をどのように選んでも、キー、アシスタント、Webhook は次の操作ができません。

- 他人のライブラリーにアクセスする、または自分の共同視聴のほかの参加者を特定する。
- 共同視聴を主催・参加する、投票する、サイト修正を投稿する、機能リクエストを変更する。
- ログイン情報、二段階ログインのコード、復旧コード、アクセスキー、署名用シークレットを見る。
- プラン、支払い、メールアドレスを変える、または拡張機能を接続する。
- 音声メモ、AI の履歴、支払い、紹介情報、利用状況の分析を読む。
- スタッフ用ページを開く。

## プランごとの上限 {#limits-on-each-plan}

| | Free | Pro | Team（各メンバー） |
|---|---|---|---|
| アクセスキー | 5 | 25 | 50 |
| 一日あたりの API・アシスタントのリクエスト | 5,000 | 50,000 | 100,000 |
| Webhook 接続先 | 3 | 20 | 40 |
| アシスタント接続 | 3 | 10 | 25 |

一日のリクエスト数は、自分のすべてのキーとアシスタントを合算し、UTC の午前 0 時にリセットされます。各キーとアシスタントには毎分 120 リクエストの上限もあり、暴走したスクリプトはそこで止まります。**ほかのアプリ**では、プランの上限に対する利用状況を確認できます。プランと価格は[プラン](https://vcpeai.aoneahsan.com/plans)をご覧ください。

## キーとシークレットを再表示するには再ログインが必要 {#keys-and-secrets-stay-hidden}

アクセスキーと Webhook の署名用シークレットは、作成時に一度だけ全文を表示します。その後の再表示には、10 分以内の再ログインが必要です。[二段階ログイン](./two-step-sign-in.md)を有効にしている場合は、認証アプリのコードも必要です。開いたままのブラウザーから誰かが持ち出すことを防ぎます。キーの作成、アシスタントの接続、Webhook 接続先の追加時にはメールでお知らせします。キーやシークレットをメール本文に含めることはありません。
