Los filtros permiten ajustar brillo, contraste y saturación del 0 % al 200 %, y activar escala de grises, inversión de colores y modo nocturno. Con una cuenta conectada ([qué aporta la conexión](/docs/account-and-sync)), pulsa `Ctrl + Alt + F` para abrir la pestaña Filtros del widget.

## Controles

| Control | Rango o efecto | Atajo |
|---|---|---|
| Pestaña Filtros | Abrir o cerrar | `Ctrl + Alt + F` |
| Brillo | 0 % a 200 % | Deslizador |
| Contraste | 0 % a 200 % | Deslizador |
| Saturación | 0 % a 200 % | Deslizador |
| Escala de grises | Activar o desactivar | `Ctrl + Alt + G` |
| Invertir | Activar o desactivar | `Ctrl + Alt + I` |
| Modo nocturno | Activar o desactivar | `Ctrl + Alt + T` |

El 100 % muestra la imagen tal como la entrega el sitio. Un valor menor reduce el efecto y uno mayor lo aumenta, hasta 200 %. **Restablecer todos los filtros** devuelve todos los valores a su estado inicial.

## Cuándo ayuda cada filtro

Si una grabación de pantalla tiene texto gris claro sobre fondo blanco, aumenta el contraste.

Si un vídeo oscuro se ve mal en una tarde luminosa, aumenta el brillo.

Si una clase con pizarra blanca ilumina demasiado una habitación oscura, pulsa `Ctrl + Alt + I` para invertir la imagen o `Ctrl + Alt + T` para activar el modo nocturno.

## Ajustes predefinidos

Ajusta los tres deslizadores y guarda el resultado en la pestaña Filtros. Puedes guardar hasta 20 combinaciones. Como forman parte de tu configuración, también se incluyen al [exportar los ajustes](/docs/account-and-sync).

## Más controles de imagen

Otras dos pestañas del widget cambian la imagen sin usar Filtros.

| Dónde | Control | Acción |
|---|---|---|
| Pestaña Vista, **Transformar** | Girar, reflejar, voltear | Girar 90 grados, reflejar horizontalmente o voltear verticalmente |
| Pestaña Herramientas, **Modos visuales** | Ambiente | Luz ambiental alrededor del reproductor |
| Pestaña Herramientas, **Modos visuales** | Cine | Ajuste de color con aspecto de cine |
| Pestaña Herramientas, **Modos visuales** | Formato panorámico | Franjas de cine encima y debajo de la imagen |

Los filtros modifican cómo dibuja el navegador el vídeo. Una captura o una descarga es una función distinta.
