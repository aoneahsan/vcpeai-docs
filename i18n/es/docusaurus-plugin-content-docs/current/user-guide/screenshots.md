Prensa `Ctrl + Alt + C` para guardar el marco actual como PNG o JPEG; necesita [una cuenta](/docs/account-and-sync).

## Tome una captura de pantalla {#take-a-screenshot}

1. Pausa en el marco que quieras, o deja el video jugando.
2. Prensa `Ctrl + Alt + C`, o haga clic **Captura** en la pestaña Herramientas del widget.
3. El marco es descargado, copiado o subido, dependiendo de la acción que elijas en Ajustes.

Pausa, prensa `,` o `.` para paso un marco a la vez, y captura el marco exacto donde la diapositiva está completa.

## Elige el formato y dónde va la imagen {#choose-the-format-and-where-the-image-goes}

Abrir configuración, ir a la pestaña Características de vídeo y encontrar la **Captura** tarjeta.

| Opción                                  | Elecciones                                                                                  |
| --------------------------------------- | ------------------------------------------------------------------------------------------- |
| Formato                                 | PNG (alta calidad) o JPEG (archón pequeño)                                                  |
| Medida                                  | Descargar, Copiar para Clipboard, Descargar + Clipboard, Subir a Cloud, o Cloud + Clipboard |
| Visibilidad en la nube                  | Privada o Pública, para las acciones de la nube                                             |
| Sincronización a la biblioteca de nubes | En o apagado                                                                                |
| Incluir Timestamp                       | En o apagado                                                                                |
| Posición de Timestamp                   | Izquierda superior, Izquierda superior, Izquierda inferior, Abajo derecho                   |

El timetamp es la hora de vídeo del marco, escrita en la imagen. Enciende para diapositivas de conferencias y sabes de dónde vino cada uno.

## Donde va la imagen {#where-the-image-goes}

Elegir una acción en la nube sube la imagen. De lo contrario, la captura permanece en su dispositivo.

## Un marco o una parte móvil {#one-frame-or-a-moving-part}

Una captura de pantalla es un marco. Para una sección en movimiento, el grabador de clips registra una parte del vídeo y lo descarga, y su interruptor es **Grabación de clips**, en Ajustes en la pestaña Descargar & Capture.

## Claves relacionadas {#related-keys}

| Clave            | Lo que hace            |
| ---------------- | ---------------------- |
| `Ctrl + Alt + C` | Capturar el marco      |
| `,`              | Retroceder un marco    |
| `.`              | Paso adelante un marco |

Los tres se pueden mover: ver [Atajos predeterminados](/docs/keyboard-shortcuts/defaults) para las teclas de inicio y [Cambiar un atajo](/docs/keyboard-shortcuts/rebinding) para los pasos.
