Pulsa `Ctrl + Alt + C` para guardar el fotograma actual como PNG o JPEG. Necesitas [una cuenta](/docs/account-and-sync).

## Hacer una captura

1. Pausa el vídeo en el fotograma deseado o déjalo reproduciéndose.
2. Pulsa `Ctrl + Alt + C` o **Capturar** en la pestaña Herramientas del widget.
3. Según el ajuste de Configuración, el fotograma se descarga, copia o sube a la nube.

Si pausas y pulsas `,` o `.` para avanzar fotograma a fotograma, podrás capturar el instante exacto en que se completa una diapositiva.

## Elegir el formato y el destino

Abre Configuración, entra en Funciones de vídeo y busca la tarjeta **Captura de pantalla**.

| Opción | Valores |
|---|---|
| Formato | PNG (mayor calidad) o JPEG (archivo más pequeño) |
| Acción | Descargar, Copiar al portapapeles, Descargar + portapapeles, Subir a la nube o Nube + portapapeles |
| Visibilidad en la nube | Privada o pública, para las acciones de nube |
| Sincronizar con la biblioteca en la nube | Activado o desactivado |
| Incluir marca de tiempo | Activado o desactivado |
| Posición de la marca de tiempo | Arriba a la izquierda, arriba a la derecha, abajo a la izquierda o abajo a la derecha |

La marca de tiempo indica sobre la imagen el momento del vídeo. Actívala para saber de qué parte de una clase procede cada diapositiva.

## Dónde queda la imagen

Si eliges una acción de nube, la imagen se sube. En caso contrario, la captura permanece en tu dispositivo.

## Un fotograma o un fragmento en movimiento

Una captura contiene un solo fotograma. Para guardar un fragmento en movimiento, el grabador de clips registra una parte del vídeo y la descarga. Su interruptor **Grabación de clips** está en Descargas y capturas de Configuración.

## Atajos relacionados

| Atajo | Acción |
|---|---|
| `Ctrl + Alt + C` | Capturar el fotograma |
| `,` | Retroceder un fotograma |
| `.` | Avanzar un fotograma |

Puedes cambiar los tres: consulta [Atajos predeterminados](/docs/keyboard-shortcuts/defaults) y [Cambiar un atajo](/docs/keyboard-shortcuts/rebinding).
