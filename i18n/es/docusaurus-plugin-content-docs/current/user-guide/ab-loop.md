El bucle A-B repite el fragmento comprendido entre dos puntos que eliges. Requiere [una cuenta](/docs/account-and-sync); el control de velocidad no. Si los atajos del bucle no responden, conecta primero tu cuenta.

## Marcar un bucle

1. Reproduce el vídeo hasta el comienzo del fragmento.
2. Pulsa `Ctrl + Alt + A` para marcar el punto A.
3. Deja que avance hasta el final del fragmento.
4. Pulsa `Ctrl + Alt + B` para marcar el punto B.

Al llegar a B, el vídeo vuelve a A y repite ese tramo hasta que lo borres. También puedes marcar A y B con un clic para cada uno en la pestaña Bucle del widget.

Sirve para practicar un compás rápido de guitarra, revisar una demostración de 40 segundos en una clase o escuchar una frase difícil en otro idioma: rodea el fragmento con A y B, baja la velocidad con `[` y repítelo hasta entenderlo.

## Atajos del bucle

| Atajo | Acción |
|---|---|
| `Ctrl + Alt + A` | Marcar el inicio (A) |
| `Ctrl + Alt + B` | Marcar el final (B) |
| `Ctrl + Alt + L` | Activar o desactivar el bucle |
| `Ctrl + Alt + Backspace` | Borrar ambos puntos |

## Modos del bucle

Elige el modo en la pestaña Bucle del widget. Sus nombres siguen el idioma del navegador si está configurado en inglés, español, francés o alemán ([cambiar el idioma](/docs/user-guide/display-and-widget)).

| Modo | Qué ocurre al llegar a B |
|---|---|
| Siempre | El fragmento se repite hasta que desactives el bucle |
| Una vez | El fragmento se repite una vez |
| Veces | Se repite el número que indiques, entre 1 y 20 |

En el modo Veces, un indicador muestra el progreso. El máximo es 20 repeticiones; si necesitas más, usa Siempre y desactívalo con `Ctrl + Alt + L`.

`,` y `.` retroceden y avanzan un fotograma para colocar A y B en el punto exacto. Consulta todos los atajos en [Atajos predeterminados](/docs/keyboard-shortcuts/defaults) y cámbialos en [Cambiar un atajo](/docs/keyboard-shortcuts/rebinding).
