Un bucle A-B replaya el estiramiento entre dos puntos que estableces. Necesidades de fuga [una cuenta](/docs/account-and-sync)El control de velocidad no. Si las teclas de bucle no hacen nada, conecte una cuenta primero.

## Establecer un bucle {#set-a-loop}

1. Juega el video a donde empieza la parte dura.
2. Prensa `Ctrl + Alt + A`Es el punto A.
3. Que juegue a donde termina la parte.
4. Prensa `Ctrl + Alt + B`Es el punto B.

El video salta de nuevo a A cuando llega a B, y juega esa parte hasta que la despejas. También puede configurar A y B con un clic cada uno en la pestaña del widget.

Ayuda con una lección de guitarra que tiene una barra rápida, una conferencia donde la prueba pasa en 40 segundos, y un video de idioma con una frase que no se puede atrapar: establecer A y B alrededor de la parte, frenar la velocidad con `[`Y juega hasta que lo tengas.

## Las llaves del bucle {#the-loop-keys}

| Clave                    | Lo que hace                       |
| ------------------------ | --------------------------------- |
| `Ctrl + Alt + A`         | Establecer el punto de inicio (A) |
| `Ctrl + Alt + B`         | Establecer el punto final (B)     |
| `Ctrl + Alt + L`         | Enciende o apaga el bucle         |
| `Ctrl + Alt + Backspace` | Borrar ambos puntos               |

## Modos de bucle {#loop-modes}

Usted elige el modo en la pestaña de la boquilla del widget, y las etiquetas del widget están en inglés ([¿Por qué?](/docs/user-guide/display-and-widget)).

| Modo         | Qué pasa en B                                                |
| ------------ | ------------------------------------------------------------ |
| Para siempre | La parte repite hasta que apagues el bucle                   |
| Una vez      | La parte repite una vez                                      |
| Times        | La parte repite el número de veces que estableces, de 1 a 20 |

Con Times, un indicador de progreso muestra cuán lejos a través de las repeticiones que estás, y el conteo se detiene a 20, por lo que para más, utiliza Forever y apágalo con `Ctrl + Alt + L`.
