NudgePlay es un pequeño widget que aparece al pasar el puntero por el reproductor. Permite reproducir, pausar y ajustar una velocidad que recuerda para cada vídeo. Si te gusta precisamente esa sencillez, puedes conservarla. Nuestro widget añade velocidad hasta 16x, bucle A-B, filtros y notas, con una cuenta para tus dispositivos y control sobre cuánto se muestra.

**Última comprobación: 2026-11-27.** Widget al pasar el puntero con reproducción, pausa y velocidad de 0,1x a 5x recordada por vídeo. <a href="https://microsoftedge.microsoft.com/addons/detail/web-video-controller-nu/dmacnkcmaabfmgjdeobmjiehgdnppipi" target="_blank" rel="noopener noreferrer nofollow">Consulta Web Video Controller - NudgePlay</a>.

## Cuál te conviene

- **Web Video Controller - NudgePlay:** elígela si solo quieres un pequeño widget de velocidad con memoria por vídeo.
- **Video Controls Plus:** elígela si también quieres velocidad hasta 16x, bucle A-B, filtros, notas y una cuenta para varios dispositivos.

## Un widget en lugar del otro

1. [Instala Video Controls Plus](../getting-started/install.md).
2. Para evitar dos widgets sobre el mismo reproductor, desactiva NudgePlay en la página de extensiones.
3. Ajusta la posición y el tamaño de nuestro widget para dejarlo donde tenías el anterior: [cómo aparecen los controles](../user-guide/display-and-widget.md).
4. La velocidad supera el límite de 5x de NudgePlay y llega a 16x: [Controlar la velocidad](../user-guide/speed-control.md). Para recordarla, configura una velocidad por sitio en [Automatización](../user-guide/playback-automation.md).
5. Cuando tus vídeos habituales funcionen como quieres, elimina NudgePlay.

## Qué confirma la ficha de NudgePlay

La ficha cubre el widget y la velocidad. No menciona bucles, filtros, notas, transcripciones, tarjetas de estudio, historial, Ver más tarde, sincronización, funciones por sitio, Chrome ni Firefox; por eso no aparecen esas filas.
