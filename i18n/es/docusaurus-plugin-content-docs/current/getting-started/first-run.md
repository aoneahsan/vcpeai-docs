Abre cualquier página con un vídeo y pulsa `]`. El vídeo se acelera 0,1x: ya estás usando la extensión.

## Prueba los primeros controles

1. Abre un vídeo en YouTube, Udemy, Vimeo u otro sitio con vídeo estándar.
2. Pulsa `]` para acelerar 0,1x; sigue pulsando hasta llegar a 4x.
3. Pulsa `[` para reducir la velocidad 0,1x.
4. Pulsa `=` para volver a tu velocidad predeterminada.
5. Pulsa `Ctrl + Alt + 4` para ir directamente a 2x.

El control de velocidad no requiere cuenta. Con `,` y `.` también puedes avanzar fotograma a fotograma. Imagen en imagen se habilita al conectar una cuenta.

## Encuentra el widget

El widget es el panel flotante de controles sobre la página. Púlsalo para abrirlo y arrástralo a donde prefieras.

Pulsa `Esc` o `Ctrl + Alt + H` para ocultarlo; vuelve a pulsar para mostrarlo.

## Encuentra el popup y Configuración

Pulsa el icono de Video Controls Plus en la barra de herramientas para abrir el popup. Muestra el sitio actual y si la extensión está activa allí. También permite [pausarla en un sitio](/docs/getting-started/pause-per-site).

Configuración se abre en una pestaña propia.

## Qué requiere una cuenta conectada

Velocidad, valores predefinidos, avance fotograma a fotograma, enlaces con marca de tiempo, modo cine, marcadores locales y widget funcionan sin cuenta. Al conectar una cuenta se habilitan:

| Control | Atajo para probarlo tras conectar |
|---|---|
| Bucle A-B | `Ctrl + Alt + A` y luego `Ctrl + Alt + B` |
| Imagen en imagen | `Ctrl + Alt + P` |
| Amplificación de audio | `Ctrl + Alt + U` |
| Filtros de vídeo | `Ctrl + Alt + F` |
| Capturas de pantalla | `Ctrl + Alt + C` |
| Notas con marca de tiempo | **Nota** en la pestaña Herramientas del widget |
| Salto automático | Se activa en Configuración |

No inicias sesión dentro de la extensión. Tu cuenta está en vcpeai.aoneahsan.com; para conectarla, pulsa **Conectar con tu cuenta** en el popup o en la pestaña Cuenta y sincronización de Configuración. Funciona en Chrome, Edge y Firefox. [Cuenta y sincronización](/docs/account-and-sync) explica los pasos, lo que se habilita y lo que se registra.

## Si una tecla no hace nada

Las letras y números requieren `Ctrl + Alt`. Solo `[`, `]`, `=`, `\`, `'`, `,`, `.` y `Esc` funcionan por sí solas. Consulta la tabla en [Atajos predeterminados](/docs/keyboard-shortcuts/defaults) o cambia una tecla en [Cambiar un atajo](/docs/keyboard-shortcuts/rebinding).
