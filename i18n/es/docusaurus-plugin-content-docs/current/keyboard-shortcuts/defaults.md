Las claves de letras y dígitos necesitan `Ctrl + Alt`; sólo `[`, `]`, `=`, `\`, `'`, `,`, `.` y `Esc` trabajar solo. Eso mantiene las llaves de la extensión lejos de las llaves que utiliza el propio reproductor de un sitio.

Un "Sí" en la última columna significa que la clave funciona con una cuenta conectada, y [Cuenta y sincronización](/docs/account-and-sync) lista lo que la conexión añade.

## Speed {#speed}

La sección Control de velocidad en Ajustes contiene las teclas de velocidad y las teclas de widget.

| Clave            | Lo que hace                                                                                                      | Necesita una cuenta |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------- |
| `[`              | Disminuir la velocidad por 0.1x                                                                                  | No                  |
| `]`              | Aumentar la velocidad de 0.1x                                                                                    | No                  |
| `=`              | Reiniciar a velocidad predeterminada                                                                             | No                  |
| `\`              | Mostrar velocidad actual                                                                                         | No                  |
| `'`              | Sincronización a velocidad dinámica: aplica el set de velocidad dinámica actual en la pestaña General en Ajustes | No                  |
| `Esc`            | Ocultar o mostrar el widget                                                                                      | No                  |
| `Ctrl + Alt + H` | Ocultar o mostrar el widget                                                                                      | No                  |

## Atajos opcionales sin llave {#optional-shortcuts-with-no-key}

Estos comienzan sin llave. En Ajustes, abra la pestaña Atajos de teclado, encuentre el grupo, presione **Set**, luego presiona las llaves que quieras. Si una clave ya pertenece a otro atajo, Settings te dice cuál y te lleva a ella.

| Grupo en Ajustes      | Ataque                                       | Necesita una cuenta |
| --------------------- | -------------------------------------------- | ------------------- |
| Comfort               | Toggle eye comfort                           | No                  |
| Comfort               | Toggle colour vision                         | No                  |
| Comfort               | Toggle caption style                         | No                  |
| Comfort               | Guía de lectura                              | No                  |
| Estudio               | Iniciar o detener el temporizador de estudio | No                  |
| Estudio               | Mostrar o ocultar la transcripción           | No                  |
| Efectos               | Efectos de encendido o apagado               | Sí.                 |
| Efectos               | Desenfoque una región del vídeo              | Sí.                 |
| Herramientas de audio | Activar o apagar las herramientas de audio   | Sí.                 |
| Herramientas de audio | Cierre a la izquierda y a la derecha         | Sí.                 |
| Captura               | Grabar o detener un clip                     | Sí.                 |
| Captura               | Hacer un GIF                                 | Sí.                 |
| Captura               | Anota una captura de pantalla                | Sí.                 |
| Automatización        | Autojuego bloque en este sitio               | No                  |
| Automatización        | Iniciar o detener la rampa de velocidad      | No                  |

Cada uno se explica en su propia página: [Confort y accesibilidad](/docs/user-guide/comfort-and-accessibility), [Herramientas de estudio](/docs/user-guide/study-tools), [Efectos visuales y zoom](/docs/user-guide/visual-effects), [Herramientas de audio](/docs/user-guide/audio-tools), [Captura y exportación](/docs/user-guide/capture-and-export) y [Automatización de reproducción](/docs/user-guide/playback-automation).

## Atajos a nivel de navegador {#browser-level-shortcuts}

El navegador establece estos cuatro. Decide si cada uno es asignado, y los cambia en la propia página de accesos de extensión del navegador. La extensión no puede cambiarlos.

| Clave sugerida                                       | Lo que hace                               |
| ---------------------------------------------------- | ----------------------------------------- |
| `Alt + V`                                            | Abre el popup                             |
| `Ctrl + Shift + V` (`Command + Shift + V` en un Mac) | Mostrar o ocultar los controles flotantes |
| `Ctrl + Shift + P` (`Command + Shift + P` en un Mac) | Imagen en foto o apagada                  |
| `Ctrl + Shift + C` (`Command + Shift + C` en un Mac) | Tome una captura de pantalla              |

## Netflix {#netflix}

Netflix tiene su propio conjunto, que se enciende sólo en un caso, y la tabla está en la [Página de Netflix](/docs/platforms/netflix).

Para dar una de estas otra clave, vea [Cambiar un atajo](/docs/keyboard-shortcuts/rebinding).
