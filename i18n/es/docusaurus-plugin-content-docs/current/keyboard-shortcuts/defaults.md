Las letras y números requieren `Ctrl + Alt`. Solo `[`, `]`, `=`, `\`, `'`, `,`, `.` y `Esc` funcionan solos. Así los atajos de la extensión no interfieren con los del reproductor del sitio.

«Sí» en la última columna significa que el control requiere una cuenta conectada. [Cuenta y sincronización](/docs/account-and-sync) explica lo que se habilita al conectarla.

## Velocidad

La sección Control de velocidad de Configuración contiene los atajos de velocidad y del widget.

| Atajo | Acción | Requiere cuenta |
|---|---|---|
| `[` | Reducir la velocidad 0,1x | No |
| `]` | Aumentar la velocidad 0,1x | No |
| `=` | Restablecer la velocidad predeterminada | No |
| `\` | Mostrar la velocidad actual | No |
| `'` | Aplicar la velocidad dinámica actual configurada en General | No |
| `Esc` | Ocultar o mostrar el widget | No |
| `Ctrl + Alt + H` | Ocultar o mostrar el widget | No |

## Controles avanzados

| Atajo | Acción | Requiere cuenta |
|---|---|---|

## Atajos opcionales sin tecla inicial

Abre Configuración → Atajos de teclado, busca la sección, pulsa **Asignar** y elige la combinación. Si ya pertenece a otra acción, Configuración la identifica y te lleva hasta ella.

| Sección | Atajo | Requiere cuenta |
|---|---|---|
| Comodidad | Activar o desactivar descanso visual | No |
| Comodidad | Cambiar visión del color | No |
| Marcadores | Activar o desactivar modo de enfoque | No |
| Comodidad | Cambiar estilo de subtítulos | No |
| Comodidad | Cambiar guía de lectura | No |
| Estudio | Iniciar o pausar temporizador de estudio | No |
| Estudio | Mostrar u ocultar transcripción | No |
| Efectos | Activar o desactivar efectos | Sí |
| Efectos | Desenfocar una zona del vídeo | Sí |
| Herramientas de audio | Activar o desactivar herramientas de audio | Sí |
| Herramientas de audio | Intercambiar izquierda y derecha | Sí |
| Captura | Grabar o detener un clip | Sí |
| Captura | Crear un GIF | Sí |
| Captura | Anotar una captura | Sí |
| Automatización | Bloquear reproducción automática en este sitio | No |
| Automatización | Iniciar o detener aceleración gradual | No |

Cada grupo se explica en su página: [Comodidad y accesibilidad](/docs/user-guide/comfort-and-accessibility), [Herramientas de estudio](/docs/user-guide/study-tools), [Efectos visuales y zoom](/docs/user-guide/visual-effects), [Herramientas de audio](/docs/user-guide/audio-tools), [Captura y exportación](/docs/user-guide/capture-and-export) y [Automatización](/docs/user-guide/playback-automation).

## Atajos del navegador

El navegador asigna estos cuatro, decide cuáles están disponibles y permite cambiarlos en su propia página de atajos de extensiones. La extensión no puede modificarlos.

| Atajo sugerido | Acción |
|---|---|
| `Alt + V` | Abrir el popup |
| `Ctrl + Shift + V` (`Command + Shift + V` en Mac) | Mostrar u ocultar controles flotantes |
| `Ctrl + Shift + P` (`Command + Shift + P` en Mac) | Activar o desactivar imagen en imagen |
| `Ctrl + Shift + C` (`Command + Shift + C` en Mac) | Hacer una captura |

## Netflix

Netflix tiene su propio conjunto, que solo se activa en un caso. La tabla está en la [página de Netflix](/docs/platforms/netflix).

Para reasignar cualquier atajo, consulta [Cambiar un atajo](/docs/keyboard-shortcuts/rebinding).
