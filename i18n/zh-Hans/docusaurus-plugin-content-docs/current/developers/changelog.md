# 开发者更新记录

面向 Video Controls Plus 集成开发者的变更，按时间从新到旧排列。产品版本见[主更新记录](/changelog)。

## 2026-11-21：其他应用与两步登录 {#2026-11-21}

- **新增：[访问密钥](./access-keys.md)**（`vcp_pat_…`），在“账户”→“其他应用”中创建。每把密钥都可单独勾选读取、修改、删除权限；非只读密钥需要设置到期日。
- **新增：[API](./api.md) 第 1 版**，用于书签、笔记、合集、闪卡、学习路径、观看历史、稍后观看、文字稿、截图、设置和设备，并提供同步观看、网站修复、功能请求及计划的只读访问。OpenAPI 3.1 文档位于 `/v1/openapi.json`。
- **新增：[助手连接地址](./assistants.md)**，支持 Claude、ChatGPT、Claude Code 和 Cursor。助手请求删除内容时，网站会等待你确认。
- **新增：[Webhook](./webhooks.md)**，使用 Standard Webhooks 签名，有 32 种事件可选，并支持测试消息。默认发送简短消息，可按地址开启“包含写入内容”。
- **新增：[两步登录](./two-step-sign-in.md)**，网站提供 10 个恢复码，并可主动选择记住浏览器 7 天。开启后，已连接扩展会获得 7 天信任期。
- **限制：**Free 计划可有 5 把密钥、每天 5,000 次请求、3 个 Webhook 地址和 3 个助手；Pro 为 25、50,000、20 和 10；Team 每位成员为 50、100,000、40 和 25。
