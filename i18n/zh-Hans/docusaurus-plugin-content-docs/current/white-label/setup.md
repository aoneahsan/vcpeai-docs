付款后，你会收到包含授权密钥和以下步骤的邮件。各商店自行决定审核时长，因此实际日期取决于商店。

1. **在定价页面付款。**填写姓名、邮箱和网站域名，按“继续付款”。付款页面会在同一标签页打开。在那里通过 Wise 银行转账付款，并将转账参考编号发给我们；确认到账后才会颁发授权。
2. **回复授权邮件，**提供产品名称、SVG 或大尺寸 PNG 标志、品牌颜色和域名。
3. **我们构建你的版本。**扩展和网站会使用你的名称与颜色。我们会发商店页面文案和截图给你审核。
4. **我们在你的开发者账户下发布扩展，**覆盖 Chrome 应用商店、Firefox 附加组件和 Microsoft Edge 扩展商店。你需要将我们添加到各账户，或按商店允许的方式提供访问权限。
5. **我们连接你的域名并部署网站。**你需要添加我们提供的 DNS 记录。
6. **部署后授权生效。**你的网站会提供授权文件，[任何人都可以验证](./verify.md)。

## 需要提前准备

- 各商店的开发者账户：Chrome 应用商店、Firefox 附加组件（免费）和用于 Edge 的 Microsoft Partner Center。
- 域名 DNS 的管理权限。
- 标志与品牌颜色。

除名称、标志和颜色之外，任何改变功能的要求都属于[定制工作](https://vcpeai.aoneahsan.com/white-label/custom-work)，另行报价。
