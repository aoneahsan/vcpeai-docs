白标授权是指 Video Controls Plus 团队以你的企业名称运营这款扩展。用户从 Chrome 应用商店、Firefox 附加组件和 Microsoft Edge 扩展商店安装你的扩展，配套网站使用你的域名。我们负责构建、发布、托管网站和推送更新，你无需接触代码。

有两种购买方式，[白标页面](https://vcpeai.aoneahsan.com/white-label)提供了对比：

| | 白标授权 | 源代码买断 |
|---|---|---|
| 由谁运营 | 我们以你的品牌运营 | 你自行运营 |
| 源代码 | 仍由我们持有 | 交付构建扩展所需的所有代码仓库 |
| 我们能否继续出售 | 可以，直到有人买断 | 买断后停止销售 |
| 更新 | 包含 6 个月，之后可续订 | 包含 6 个月，之后可续订 |
| 首付款后还需支付什么 | 如需更多更新，支付续订费用 | 如需更多更新，支付续订费用；另按该产品产生的总收入支付 7% 版税，只要有收入就按季度支付 |

Video Controls Plus 只作为一个平台组出售：Chrome、Firefox 和 Edge 浏览器扩展一同提供。只有一个平台组，因此没有组合购买折扣。

价格和付款入口位于[定价页面](https://vcpeai.aoneahsan.com/white-label/pricing)，数据由我们的授权服务实时提供。买断也有[独立页面](https://vcpeai.aoneahsan.com/white-label/buyout)。
