打开任何有视频的网页，按 `]`。视频会加快 0.1x。你已经开始使用扩展了。

## 试试基本控制

1. 打开 YouTube、Udemy、Vimeo 或其他播放标准视频的网站。
2. 按 `]` 加快 0.1x，继续按可升至 4x。
3. 按 `[` 减慢 0.1x。
4. 按 `=` 恢复默认速度。
5. 按 `Ctrl + Alt + 4` 直接切换到 2x。

调速不需要账户。键盘还能做更多事：`,` 和 `.` 可逐帧播放。连接账户后才能打开画中画。

## 找到浮动控件

浮动控件是网页视频旁的控制面板。点击可展开，也可以拖到你想放的位置。

按 `Esc` 或 `Ctrl + Alt + H` 隐藏，再按一次重新显示。

## 找到弹出面板和设置

点击工具栏中的 Video Controls Plus 图标即可打开弹出面板。它会显示当前网站以及扩展是否在此运行，也能让你[在单个网站暂停扩展](/docs/getting-started/pause-per-site)。

“设置”会在单独的标签页中打开。

## 哪些功能需要连接账户

速度、预设、逐帧播放、分享时间戳、剧院模式、浏览器本地书签和浮动控件都无需账户。连接账户后可以使用：

| 控制 | 连接后可试的按键 |
|---|---|
| A-B 循环 | `Ctrl + Alt + A`，再按 `Ctrl + Alt + B` |
| 画中画 | `Ctrl + Alt + P` |
| 音量增强 | `Ctrl + Alt + U` |
| 视频滤镜 | `Ctrl + Alt + F` |
| 截图 | `Ctrl + Alt + C` |
| 带时间戳的笔记 | 浮动控件“工具”标签页中的“笔记” |
| 自动跳过 | 在“设置”中开启 |

扩展内没有登录入口。账户位于 vcpeai.aoneahsan.com；在弹出面板或“设置”→“账户与同步”中按“连接你的账户”，即可连接。Chrome、Edge 和 Firefox 都支持。查看[账户与同步](/docs/account-and-sync)中的步骤、连接后的功能及数据说明。

## 按键没有反应

字母键和数字键需要与 `Ctrl + Alt` 同时按。只有 `[`、`]`、`=`、`\`、`'`、`,`、`.` 和 `Esc` 可单独使用。完整列表见[默认快捷键](/docs/keyboard-shortcuts/defaults)，修改方法见[修改快捷键](/docs/keyboard-shortcuts/rebinding)。
