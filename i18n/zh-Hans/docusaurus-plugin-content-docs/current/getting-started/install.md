从 Chrome 应用商店、Microsoft Edge 扩展商店或 Firefox 附加组件安装 Video Controls Plus。安装后即可控制播放速度。

| 浏览器 | 商店页面 |
|---|---|
| Chrome | [Chrome 应用商店](https://chromewebstore.google.com/detail/video-controls-plus/ihafdbecgnhendhckoknblmcminoikdb) |
| Edge | [Microsoft Edge 扩展商店](https://microsoftedge.microsoft.com/addons/detail/video-controls-plus/ghjcpobkbbhefdlgffopfhlepkgcknlb) |
| Firefox | [Firefox 附加组件](https://addons.mozilla.org/en-US/firefox/addon/video-controls-plus) |

网站的[安装页面](https://vcpeai.aoneahsan.com/install)也提供相同链接。

## 添加到浏览器

1. 从上表打开对应浏览器的商店页面。
2. 添加扩展，并在浏览器显示权限时确认。
3. 从浏览器的“扩展”按钮将它固定到工具栏，之后只需点一下就能打开弹出面板。

欢迎页会在扩展内部打开。你可以按步骤完成，也可以跳过。其中一步提供“连接你的账户”；跳过后仍可随时连接。

## 在 Firefox 上

附加组件需要 Firefox 140 或更新版本。安装时，Firefox 会显示附加组件收集的数据。

Firefox 还会询问两项可选数据权限：只有允许“技术与交互数据”时才会发送使用事件；只有允许“网站内容”后才会发送页面内容。附加组件会在首次需要时请求后者。[隐私与权限](/docs/privacy-and-permissions)列出了各项权限的用途。

在 Firefox 上连接账户的步骤与 Chrome、Edge 相同。[账户与同步](/docs/account-and-sync)列出了连接步骤和需要账户的控制。

## 浏览器会请求什么

扩展需要访问所有网站，才能在你打开的任意页面找到视频。各项权限及原因见[隐私与权限](/docs/privacy-and-permissions)。
