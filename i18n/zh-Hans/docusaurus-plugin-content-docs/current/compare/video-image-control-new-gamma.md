Video Image Control 主要用来调整画面：伽马、锐度、亮度、棕褐色调和翻转。如果你常用伽马及锐度滑块，只需要一点速度控制，它很合适。在 Video Controls Plus 中，滤镜和视觉效果负责调整画面，其中大多数功能需要连接账户。速度最高可达 16x，另有 A-B 循环和笔记，支持 Chrome、Firefox 和 Edge。

**最近核查：2026-11-27。** 这款画面调节扩展程序支持锐度、亮度、对比度、饱和度、伽马、灰度、棕褐色调、旋转和翻转，播放速度范围是 0.5x 至 2.5x。<a href="https://microsoftedge.microsoft.com/addons/detail/video-image-control-new/gjjblcgfmgbgjlnffmdkojoikfpcidba" target="_blank" rel="noopener noreferrer nofollow">查看 Video Image Control ( new gamma )</a>。

## 哪个更适合你

- **Video Image Control ( new gamma )：**如果你需要画面的伽马和锐度滑块，只需要少量速度控制，就选它。
- **Video Controls Plus：**如果你想要滤镜、最高 16x 的速度、A-B 循环、笔记和账户，而且使用 Chrome、Firefox 或 Edge，就选它。

## 重新设置画面

1. [安装 Video Controls Plus](../getting-started/install.md)。
2. 滤镜需要账户，因此先[连接账户](../account-and-sync.md)。
3. 记下你在 Video Image Control 中使用的亮度、对比度和饱和度，再到[视频滤镜](../user-guide/video-filters.md)中设置。锐化功能见[视觉效果和缩放](../user-guide/visual-effects.md)。
4. 它的速度最高到 2.5x；我们的速度范围更宽：[控制播放速度](../user-guide/speed-control.md)。
5. 在浏览器的扩展程序页面关闭 Video Image Control，这样你一次只会看到一套滤镜的效果。画面符合预期后再移除它。
