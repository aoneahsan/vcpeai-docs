先选择你正在使用的扩展。每篇页面会给出迁移步骤；如果两款产品用途不同，也会直接说明，并列出从对方页面查到的价格与功能。

**最后核对：2026 年 11 月 27 日。**这些页面由 Video Controls Plus 团队撰写，请打开来源自行核查。网站的[对比中心](https://vcpeai.aoneahsan.com/compare/extensions)也提供相同事实，方便选择。

- [Video Roll](./video-roll-all-in-one-video-enhancements.md)：集速度、循环、滤镜、截图和下载于一体的视频工具扩展。页面宣传 Pro 价格，但购买按钮显示“即将推出”。
- [Super Video Speed Controller](./super-video-speed-controller.md)：适用于 Chrome 和 Edge 的纯调速扩展，提供预设、自定义百分比以及 A、D、S 按键。
- [Video Speed Control](./video-speed-control.md)：通过弹出面板调整 HTML5 视频速度，范围 0.07x 至 16x，每次需要按“播放”应用。
- [Floating Video Player](./floating-video-player.md)：将视频以画中画方式浮在其他窗口上方，方便继续浏览。
- [HTML5 Video Speed Control](./html5-video-speed-control.md)：使用键盘为 HTML5 视频加速、减速、快进和后退。
- [Video Popout](./video-popout.md)：按一个按钮，通过画中画 API 把正在播放的视频弹出为浮动窗口。
- [VideoControls](./videocontrols.md)：触控手势播放器，可点击播放、滑动跳转、上滑至 2x，并在后台自动暂停。
- [Video Controls for TikTok](./video-controls-for-tiktok.md)：为网页版 TikTok 提供按键、0.25x 至 2x 调速、音量记忆和弹出窗口。
- [Better YouTube Controls](./better-youtube-controls.md)：专为 YouTube 修正方向键：上下键始终调音量，左右键始终跳转。
- [Web Video Controller - NudgePlay](./web-video-controller-nudgeplay.md)：播放器上的小型悬停控件，可播放、暂停，并以 0.1x 至 5x 调速，按视频记住速度。
- [Video Image Control ( new gamma )](./video-image-control-new-gamma.md)：调整锐度、亮度、对比度、饱和度、伽马、灰度、棕褐色、旋转和翻转，调速范围 0.5x 至 2.5x。
- [Video Dominator](./video-dominator.md)：按住按键并在视频上滚动鼠标滚轮，可跳转、以 0x 至 16x 调速、调整音量或打开自定义播放器。
- [Video Player](./video-player-extension.md)：媒体播放器扩展，支持最高 300% 音量、8x 速度、重复播放、截图、本地文件和浏览器不支持格式的转码。
- [Video Download Helper](./video-downloadhelper.md)：适用于 Chrome、Firefox 和 Edge 的视频下载扩展，有免费版本和提供无限下载的付费授权。
- [video downloader - CocoCut](./video-downloader-cococut.md)：适用于 Chrome 和 Edge 的下载扩展，可捕获 HLS 流，并录制无法直接下载的内容；提供免费版和可选付费版。
- [Video & Audio Downloader](./video-audio-downloader.md)：在工具栏弹出面板中列出当前标签页播放的媒体，供下载或复制链接；不支持 YouTube。
- [Magic Actions for YouTube](./magic-actions-for-youtube.md)：专为 YouTube 提供影院模式和配色、滚轮音量、自动高清、重复播放、截图及隐藏页面元素。
