Video Controls Plus 将你的设置保存在浏览器中。“使用情况分析”默认开启。只要它开启，无论是否连接账户，使用事件都会发送到团队的后端；你的 IP 地址每天最多发送一次给 ipapi.co，用于查询位置。连接账户后，还会保存账户资料；若开启同步，也会保存设置。

关闭此开关，使用情况记录就会停止。

除非你主动开启默认关闭的“观看历史”，扩展不会记录你观看的视频、标题或地址。你主动保存的内容是另一种情况。连接账户后，只有你保存或从视频发起笔记、书签、日记、稍后观看项目、上传的截图、提取的视频详情、文字稿、由视频保存的闪卡、学习路径视频、合集项目或同步观看时，账户才会保留视频标题和地址。

本页以通俗语言说明[隐私政策](https://vcpeai.aoneahsan.com/privacy)。政策是法律文本；如有差异，以政策为准。

## 保存在浏览器中的内容

设置、键盘快捷键、每个视频记住的速度、播放位置、滤镜预设和音频设置都保存在浏览器中。只有连接扩展并开启同步后，它们才会进入账户。

音频下载在你的设备上处理。截图留在设备上，除非你主动选择上传图片的云端操作。

观看限制只在当前设备统计分钟数，PIN 经过哈希处理且从不同步。学习计时器的统计和根据视频字幕生成的章节留在当前浏览器。GIF、片段、延时视频和缩略图合集在设备上制作，并作为下载文件保存。

## 会记录什么

| 数据 | 何时记录 | 内容 |
|---|---|---|
| 使用事件 | “使用情况分析”开启时，无论是否连接账户 | 事件名称、网站主机名、浏览器、操作系统、扩展版本和会话 ID；连接账户时还包括账户信息 |
| 位置查询 | “使用情况分析”开启时，每天最多一次 | IP 地址会发往 ipapi.co。连接账户后，它返回的国家、城市和时区会保存到个人资料；地区信息留在浏览器中。IP 地址不会存储。 |
| 网站、功能与速度 | “使用情况分析”开启且账户已连接时 | 你使用过的网站、功能和速度 |
| 账户 | 连接账户后 | 邮箱地址、显示名称、头像及 Google 账户 ID |
| 当前浏览器 | 连接账户后 | 设备名称、浏览器、操作系统、扩展版本及上次活动时间 |
| 设置 | 连接账户并开启同步后 | 同步到账户的设置 |
| 你保存到账户的内容 | 连接账户后，只有逐项主动保存时 | 笔记、书签、稍后观看项目、上传的截图、右键操作提取的视频详情和保存到账户的文字稿，均带有视频标题和地址。书签还保存时间戳；日记是含心情和文字的书签。由视频保存的闪卡（某一时刻的测验，或附有屏幕字幕示例的单词）、学习路径视频和合集项目也按相同方式保存。 |
| 观看历史 | 在“设置”→“隐私与数据”主动开启“观看历史”，并在连接账户时播放视频后；每个浏览器的每个已连接账户默认关闭 | 每段持续 15 秒或更长的观看会话：视频标题与地址、观看时长、最后位置、播放过的片段、日期、播放速度及使用的功能。关闭开关会停止记录新会话；已有记录会留在账户中，直到你在网站删除或删除账户。 |
| 同步观看 | 创建或加入同步观看时 | 视频地址与标题、房间代码、加入者及加入时间。房间运行期间，播放、暂停、跳转和速度通过 Supabase Realtime 传给成员，不会存储。 |
| 错误报告 | “第三方错误追踪”开启时 | 发送给 Sentry 的崩溃报告 |
| AI 文本 | 只有你启动 AI 功能时 | 视频字幕或你正在撰写的文字。每次共享额度运行的使用记录会保留 13 个月，不含文本。详见[AI 功能](/docs/ai-features)。 |
| Speak 录音 | 只有你使用 Speak 录音时 | 最长 2 分钟的声音、转写文本和建议笔记。三者会在 24 小时内删除；按“丢弃”后立即删除（见[隐私政策](https://vcpeai.aoneahsan.com/privacy)第 1.8 节）。 |

使用事件中的网站只记主机名，例如 youtube.com，不包含完整地址、页面路径或页面标题。

## “使用情况分析”开关

打开“设置”→“隐私与数据”，找到“使用情况分析”。有无账户都可以使用此开关。

关闭后，以下三项都会停止：

1. 不再向团队的后端发送使用事件。
2. 已连接账户不再记录使用过的网站、功能和速度。
3. 不再将 IP 地址发送到 ipapi.co。

连接时，如果当前浏览器或账户中有一处已关闭此开关，连接后两处都会保持关闭。

## 其他开关

它们位于同一标签页。

| 开关 | 默认状态 | 控制内容 |
|---|---|---|
| 第三方错误追踪 | 开启 | 向 Sentry 发送崩溃报告 |
| 营销消息 | 关闭 | 偶尔发送关于团队新功能或其他产品的浏览器通知。邮件另行处理：账户持有人会收到产品动态，每封邮件都有一键退订链接。 |
| 设置同步 | 开启 | 将设置保存到账户 |

“第三方错误追踪”与“使用情况分析”相互独立，关闭其中一项不会关闭另一项。同页的“你的数据”中可以导出或删除数据；步骤见[账户与同步](/docs/account-and-sync)。

## 数据存放在哪里

| 服务 | 保存或接收的内容 |
|---|---|
| Supabase | 账户数据库、登录，以及同步观看的实时同步 |
| FilesHub | 已存截图、最多保留 24 小时的 Speak 录音，以及团队发送的邮件 |
| Sentry | “第三方错误追踪”开启期间的崩溃报告 |
| ipapi.co | “使用情况分析”开启期间，接收用于位置查询的 IP 地址 |
| Anthropic、OpenAI 和 Groq | 你启动的 AI 运行所用文字，以及 Speak 录音的音频或转写文本。[AI 功能](/docs/ai-features)说明各服务会收到什么。 |

另有 5 项功能只在使用时联系各自的服务：SponsorBlock（`sponsor.ajay.app`）；Netflix 字幕翻译或双语字幕（`api.mymemory.translated.net`）；使用你自己的密钥查询 Netflix 评分（`www.omdbapi.com`）；AI 摘要需要获取视频字幕时（`video.google.com/timedtext`）；以及浮动控件“保存单词”中的“查询”（`en.wiktionary.org`，只接收你输入的单词）。政策第 5.9 节还列出一项服务，对应的功能尚未在本文档中介绍。

## 不收集什么

隐私政策列明不会收集：你观看的视频（除非开启“观看历史”）；视频内容或媒体文件（你选择上传的截图除外）；扩展未运行页面上的浏览活动；密码；付款信息；访问页面的内容（你主动发送给 AI 功能的文字，以及上述 5 项功能发送到各自服务的内容除外）。

你的数据不会被出售。

## 麦克风

Speak 是唯一会上传声音的功能，首次使用时才会请求麦克风。

| 使用位置 | 你会看到什么 |
|---|---|
| 扩展 | “口述笔记”会显示“授权一次麦克风”。按“打开麦克风页面”后，会打开名为“允许 Speak 使用麦克风”的标签页。按“允许麦克风”，再在浏览器弹出的权限框中选择允许。只需操作一次。 |
| Android 应用 | 首次在 Speak 中按录音时，应用会请求麦克风权限。 |
| Firefox 附加组件 | 在录制或发送任何内容前，Firefox 还会请求可选的“个人通信”数据权限。 |

麦克风只在录音期间开启。如果拒绝权限，页面会告诉你在哪里重新开启。在“设置”→“AI 功能”中关闭 Speak 后，扩展不再提供此功能。

## 各项权限的用途

扩展请求 7 项权限以及网站访问权限；Chrome 和 Edge 还请求第 8 项 `offscreen`。扩展内部没有登录入口，所以不请求 `identity`。麦克风权限也不会在安装时请求。

| 权限 | 用途 |
|---|---|
| `storage` | 在浏览器中保存设置、快捷键、速度记忆、滤镜预设和主题 |
| `activeTab` | 打开弹出面板时，读取并控制当前标签页中的视频 |
| `contextMenus` | 添加右键菜单项 |
| `alarms` | 睡眠计时器、发送排队的同步和使用事件、检查待完成的账户连接、刷新远程开关、按时结束网站暂停，以及每天检查一次公告通知 |
| `notifications` | 当浮动控件隐藏或显示模式为“仅通知”时，显示速度变化、循环状态和睡眠计时器提醒 |
| `clipboardWrite` | 通过右键菜单中的“复制页面 URL”和“复制带时间戳的 URL”将链接写入剪贴板；不会读取剪贴板 |
| `scripting` | 将控制带入嵌入其他页面的视频，而且只在框架内确实有视频时注入 |
| `offscreen`（Chrome 和 Edge） | 让 Speak 在扩展的隐藏页面录音并从该页面上传，使上传期间录音仍能继续。Firefox 在后台页面录音，不需要此权限。 |
| 访问所有网站 | 在你打开的任意网站查找和控制视频 |

“访问所有网站”是范围最广的权限，因为视频可能出现在任何网站。在某个网站[暂停扩展](/docs/getting-started/pause-per-site)时，扩展不会在那里运行。

## 在 Firefox 上

Firefox 会请求 3 项可选数据权限，每项都限制对应内容是否可以发送。

| Firefox 权限 | 控制内容 |
|---|---|
| 技术与交互数据 | 只有允许后才会发送使用事件。“使用情况分析”开关会请求此权限。 |
| 网站内容 | 只有允许后才会发送页面内容：你上传的截图、保存到账户的文字稿、用于 AI 运行的字幕，以及附带字幕示例保存的单词。首次使用其中一项时才会请求。 |
| 个人通信 | 只有允许后才会发送 Speak 录音和转写文本。首次使用 Speak 时才会请求。 |

## 你连接的密钥、助手与 Webhook

只有你在网站的“账户”→“其他应用”中自行设置后，外部工具才能访问资料库。访问密钥、Claude 或 ChatGPT 等助手，以及 Webhook 地址，只能访问你勾选的部分，不能访问登录、付款、语音笔记、AI 历史或使用情况分析。Webhook 消息包含项目 ID、视频和时间；只有为该地址勾选“包含写入内容”时才会包含你写的文字。文字稿正文绝不会发出。各项权限和撤销方法见[Video Controls Plus 开发者文档](/docs/developers)。

## 同一团队的其他应用

“设置”中有一个标签页列出团队的其他应用。列表随扩展提供，显示时无需获取数据。旁边的公告从团队后端读取。扩展不含广告网络或广告 SDK。
