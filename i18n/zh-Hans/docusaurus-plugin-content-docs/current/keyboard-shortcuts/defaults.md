字母键和数字键需要与 `Ctrl + Alt` 同时按；只有 `[`、`]`、`=`、`\`、`'`、`,`、`.` 和 `Esc` 可单独使用。这样可以避开网站播放器自身的按键。

最后一列写“是”表示需要连接账户。连接后增加的功能见[账户与同步](/docs/account-and-sync)。

## 速度

“设置”中的“速度控制”分区包含速度和浮动控件按键。

| 按键 | 作用 | 需要账户 |
|---|---|---|
| `[` | 减慢 0.1x | 否 |
| `]` | 加快 0.1x | 否 |
| `=` | 恢复默认速度 | 否 |
| `\` | 显示当前速度 | 否 |
| `'` | 切换到动态速度：应用“设置”→“常规”中的“当前动态速度” | 否 |
| `Esc` | 显示或隐藏浮动控件 | 否 |
| `Ctrl + Alt + H` | 显示或隐藏浮动控件 | 否 |

## 高级控制

| 按键 | 作用 | 需要账户 |
|---|---|---|
| `Ctrl + Alt + P` | 开启或关闭画中画 | 是 |
| `Ctrl + Alt + S` | 跳过 Netflix 和 Prime Video 的片头 | 是 |

| 按键 | 作用 | 需要账户 |
|---|---|---|
| `Ctrl + Alt + 1` | 预设：0.5x | 否 |
| `Ctrl + Alt + 2` | 预设：1x | 否 |
| `Ctrl + Alt + 3` | 预设：1.5x | 否 |
| `Ctrl + Alt + 4` | 预设：2x | 否 |
| `Ctrl + Alt + 5` | 预设：2.5x | 否 |
| `Ctrl + Alt + 6` | 预设：3x | 否 |
| `Ctrl + Alt + 7` | 预设：3.5x | 否 |
| `Ctrl + Alt + 8` | 预设：4x | 否 |

默认没有第 9 个预设。添加后可使用 `Ctrl + Alt + 9`。

## 默认未分配按键的可选快捷操作

这些操作默认没有按键。在“设置”→“键盘快捷键”中找到对应分区，按“设置”，再按想使用的组合。如果按键已被占用，“设置”会指出冲突项并带你前往。

| 设置中的分区 | 快捷操作 | 需要账户 |
|---|---|---|
| 舒适 | 切换眼睛舒适度 | 否 |
| 舒适 | 切换色觉辅助 | 否 |
| 书签 | 切换专注模式 | 否 |
| 舒适 | 切换字幕样式 | 否 |
| 舒适 | 切换阅读辅助线 | 否 |
| 学习 | 开始或暂停学习计时器 | 否 |
| 学习 | 显示或隐藏文字稿 | 否 |
| 效果 | 开启或关闭效果 | 是 |
| 效果 | 模糊视频区域 | 是 |
| 音频工具 | 开启或关闭音频工具 | 是 |
| 音频工具 | 交换左右声道 | 是 |
| 捕获 | 开始或停止录制片段 | 是 |
| 捕获 | 制作 GIF | 是 |
| 捕获 | 标注截图 | 是 |
| 自动化 | 在此网站阻止自动播放 | 否 |
| 自动化 | 开始或停止逐渐加速 | 否 |

各功能的说明分别见[舒适与无障碍](/docs/user-guide/comfort-and-accessibility)、[学习工具](/docs/user-guide/study-tools)、[视觉效果与缩放](/docs/user-guide/visual-effects)、[音频工具](/docs/user-guide/audio-tools)、[捕获与导出](/docs/user-guide/capture-and-export)和[播放自动化](/docs/user-guide/playback-automation)。

## 浏览器级快捷键

以下 4 个按键由浏览器分配。浏览器决定它们是否已设置，也只能在浏览器的扩展快捷键页面修改，扩展无法更改。

| 建议按键 | 作用 |
|---|---|
| `Alt + V` | 打开弹出面板 |
| `Ctrl + Shift + V`（Mac 为 `Command + Shift + V`） | 显示或隐藏浮动控件 |
| `Ctrl + Shift + P`（Mac 为 `Command + Shift + P`） | 开启或关闭画中画 |
| `Ctrl + Shift + C`（Mac 为 `Command + Shift + C`） | 截图 |

## Netflix

Netflix 有一组只在特定情况下启用的按键，详见 [Netflix 页面](/docs/platforms/netflix)。

修改任意按键的方法见[修改快捷键](/docs/keyboard-shortcuts/rebinding)。
