## Video Controls Plus 是什么？

这是一款为 HTML5 视频增加播放控制的浏览器扩展。它适用于播放标准视频的任意网站，并为 YouTube、Netflix 和 LinkedIn 提供专属工具，支持 Chrome、Edge 和 Firefox。安装方法见[安装](/docs/getting-started/install)。

## 如何控制视频播放速度？

按 `]` 或 `[`，每次调整 0.1x；也可以拖动浮动控件中的滑块，最高至 4x。若需要更快的速度，可在浮动控件的自定义输入框，或“设置”→“常规”中的自定义速度框中输入，最高 16x。调速无需账户。详见[速度控制](/docs/user-guide/speed-control)。

## A-B 循环是什么，如何使用？

A-B 循环会反复播放你标定的两个位置之间的片段，需要[连接账户](/docs/account-and-sync)。在起点按 `Ctrl + Alt + A`，终点按 `Ctrl + Alt + B`；视频会一直循环这一段，直到按 `Ctrl + Alt + Backspace` 清除。详见[A-B 循环](/docs/user-guide/ab-loop)。

## 能把音量提高到 100% 以上吗？

可以。[连接账户](/docs/account-and-sync)后，最高可增强至 400%。按 `Ctrl + Alt + U` 增强，按 `Ctrl + Alt + Y` 降低。详见[音量增强](/docs/user-guide/audio-boost)。

## 如何截取视频画面？

连接账户后，按 `Ctrl + Alt + C` 将当前画面保存为 PNG 或 JPEG。在“设置”中可选择下载、复制到剪贴板或两者都执行。详见[截图](/docs/user-guide/screenshots)。

## 有哪些视频滤镜？

亮度、对比度和饱和度可在 0% 至 200% 之间调整，还包括灰度、反色和夜间模式。连接账户后最多可保存 20 个预设。详见[视频滤镜](/docs/user-guide/video-filters)。

## 有哪些键盘快捷键？

字母键和数字键需与 `Ctrl + Alt` 同时按；只有 `[`、`]`、`=`、`\`、`'`、`,`、`.` 和 `Esc` 可单独使用。你可以在“设置”中改键。详见[默认快捷键](/docs/keyboard-shortcuts/defaults)和[修改快捷键](/docs/keyboard-shortcuts/rebinding)。

## 看视频时可以记笔记吗？

可以。连接账户后，可在浮动控件的“工具”标签页保存带时间戳的笔记，并导出为 Markdown、文本或 JSON。无需账户也可按 `Ctrl + Alt + O` 在当前位置添加书签；连接账户时新保存的书签还会出现在账户的书签资料库中。详见[笔记与书签](/docs/user-guide/notes-and-bookmarks)。

## 支持哪些视频平台？

凡是播放标准 HTML5 视频的网站都可以使用；YouTube、Netflix 和 LinkedIn 还有专属工具。嵌入其他页面的视频也能使用控制。详见[其他网站](/docs/platforms/other-sites)。

## Firefox 上可以使用吗？

可以。附加组件要求 Firefox 140 或更新版本。与 Chrome 和 Edge 一样，在扩展中按“连接你的账户”，再到网站确认即可。任何浏览器的扩展内部都没有登录入口。详见[账户与同步](/docs/account-and-sync)。

## Netflix 上可以使用吗？

速度和基本控制可以。Netflix 的附加功能默认关闭，需要在“设置”→“Netflix 功能”中开启。详见[Netflix](/docs/platforms/netflix)。

## Video Controls Plus 会收集个人数据吗？

会收集部分数据。“使用情况分析”开关默认开启。开启时，无论是否有账户都会发送使用事件，你的 IP 地址每天最多向 ipapi.co 发送一次以查询位置。连接账户后，也会保存账户资料和设置。在“隐私与数据”标签页关闭该开关，即可停止使用情况记录。详见[隐私与权限](/docs/privacy-and-permissions)。

## 如何删除数据？

打开“设置”→“隐私与数据”，在“你的数据”下按“删除所有数据”。这会删除账户本身、账户下的文件和所有已保存内容，因此扩展必须先连接账户。详见[账户与同步](/docs/account-and-sync)。
