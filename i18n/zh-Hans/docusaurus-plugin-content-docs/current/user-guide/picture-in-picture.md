先连接账户，再按 `Ctrl + Alt + P`，即可将视频移入画中画窗口。再按一次便会返回原位置。

## 如何使用

1. 开始播放视频。
2. 按 `Ctrl + Alt + P`。
3. 切换到其他标签页。视频会在单独的小窗口中继续播放。
4. 再按 `Ctrl + Alt + P` 退出画中画。

快捷键仍然有效：`[` 和 `]` 可以调整小窗口中的播放速度，其他速度控制也会继续工作。

## 滚动离开视频时自动进入

阅读长页面时，视频可能滚出视野。你可以让扩展在此时自动把视频移入画中画。

1. 打开“设置”→“高级”。
2. 找到“播放功能”。
3. 确认“画中画”已开启。
4. 开启“滚动时自动进入画中画”。

## 相关按键

| 按键 | 作用 |
|---|---|
| `Ctrl + Alt + P` | 开启或关闭画中画 |
| `Ctrl + Alt + Z` | 开启或关闭剧院模式 |
| `]` / `[` | 加快或减慢 0.1x，小窗口中也适用 |

要修改按键，请从[默认快捷键](/docs/keyboard-shortcuts/defaults)进入[修改快捷键](/docs/keyboard-shortcuts/rebinding)。
