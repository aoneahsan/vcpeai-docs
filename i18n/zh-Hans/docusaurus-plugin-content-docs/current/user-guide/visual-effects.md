“色调与叠层”可为视频添加调色、艺术风格、锐化、暗角、胶片颗粒、文字叠层和区域模糊。它位于浮动控件的“滤镜”标签页，和标签页的其他功能一样，需要[连接账户](/docs/account-and-sync)。“缩放与适配”位于“视图”标签页，无需账户。

所有效果只改变网页中显示的画面，不会修改视频文件。有些流媒体网站会阻止对受保护视频应用效果，扩展不会声称在这些视频上有效。

## 色调与叠层

打开浮动控件的“滤镜”标签页，找到“色调与叠层”。

| 控制 | 作用 |
|---|---|
| 调色 | 20 种风格之一，如青橙色调、黑色电影、复古 8mm、金色时刻和月光，附带“强度”滑块 |
| 艺术风格 | 油画、铅笔素描、版画或彩色浮雕 |
| 锐化 | 0% 至 100%，每次调整 10，先于色彩工具应用 |
| 暗角 | 调暗画面四角 |
| 胶片颗粒 | 添加静止或移动的颗粒 |
| 文字 | 将“叠层文字”放在视频一角 |
| 区域模糊 | 在视频上拖出方框，模糊其中的画面 |
| 关闭所有效果 | 恢复原画面 |

模糊区域会一直保留，直到你按“移除模糊区域”或切换视频。扩展不会读取视频像素；模糊效果直接在页面上实现。

## 效果设置

“设置”→“视频功能”→“效果”提供更细的选项：“暗角强度”“颗粒强度”“移动颗粒”“叠层文字”以及“文字位置”（左上、右上、左下、右下）。“重置效果”会恢复默认值。

效果可与[视频滤镜](/docs/user-guide/video-filters)和[舒适工具](/docs/user-guide/comfort-and-accessibility)同时使用，进入全屏后也会跟随视频。

## 缩放与适配

打开浮动控件“视图”标签页中的“缩放与适配”，无需账户。

1. 按“放大”或“缩小”。缩放范围是 1x 至 4x，每次调整 0.25x；触控板的双指捏合也可使用。
2. 用 4 个方向箭头移动视野。
3. 开启“放大镜：跟随指针”，放大的区域便会跟随鼠标。
4. 选择“适配”：原始、填满（裁掉黑边）、拉伸、4:3、16:9 或 21:9。

按“恢复原画面”可重置。缩放可与旋转、镜像和翻转一起使用；“重置变换”不会清除缩放。新视频会从“原始”开始，本节设置不会保存。

## 快捷键

“开启或关闭效果”和“模糊视频区域”默认没有按键，使用时都需连接账户。可在[修改快捷键](/docs/keyboard-shortcuts/rebinding)中设置。
