保存笔记前需连接账户。每条笔记保留视频时间戳，并显示在网站的“笔记”页。浮动控件的“工具”标签页包含笔记编辑器、导出按钮和资料库入口。

## 记笔记

1. 打开浮动控件，进入“工具”标签页。
2. 在“笔记与提取”下按“笔记”。
3. 输入内容并确认。

笔记会带当前时间戳，排队保存到账户。也可以右键点击视频，选择“添加笔记”。未连接账户时，扩展会要求先连接，再打开编辑器。

如果你在讲座的 12:40 写下一条笔记，它会一直对应 12:40，方便找到相关片段。笔记是私密的，不会作为评论发布到网站。

要阅读或编辑笔记，从浮动控件“工具”标签页的“你的资料库”中选择“笔记”。网站上的账户笔记页会打开。

## 导出笔记

在同一分区中点击所需格式。导出内容包括账户中的笔记，以及当前浏览器里仍待同步的笔记。

| 按钮 | 文件 |
|---|---|
| Notes MD | Markdown 文件 |
| Notes TXT | 文本文件 |
| Notes JSON | JSON 文件 |

Markdown 导出会把每条笔记及其时间戳放在单独一行，可以直接与其他讲座笔记放在一起。

## 添加书签

在“工具”标签页按“书签”，或右键点击视频选择“添加书签”，也可以按 `Ctrl + Alt + O`。无需账户即可保存书签；它会留在当前浏览器。

连接账户时，新书签会保存当前时刻并同步到账户。从浮动控件“工具”标签页的“你的资料库”中选择“书签”，或打开网站[笔记页中的书签标签](https://vcpeai.aoneahsan.com/notes?tab=bookmarks)，就能搜索、编辑、删除或导出账户书签。连接前创建的书签仍只留在原浏览器；稍后连接不会自动上传。单独的“启用云同步”开关控制的是设置同步。

## 下载文字稿

在同一分区按“文字稿”，可下载文本文件，在播放器外阅读。

## 分享某个时刻

按 `Ctrl + Alt + X` 可复制带当前时间戳的视频链接，适用于 YouTube、Vimeo、Twitch 等网站。链接只携带时间信息。

## 相关按键

| 按键 | 作用 |
|---|---|
| `Ctrl + Alt + O` | 在当前位置添加书签 |
| `Ctrl + Alt + X` | 复制带时间戳的链接 |
| `Ctrl + Alt + C` | 截取当前画面 |

初始按键见[默认快捷键](/docs/keyboard-shortcuts/defaults)；在[修改快捷键](/docs/keyboard-shortcuts/rebinding)中可更改。
