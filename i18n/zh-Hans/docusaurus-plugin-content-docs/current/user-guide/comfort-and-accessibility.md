“舒适”设置可以调暖画面，让颜色更易区分，调整网站已有字幕的样式，并在视频上添加阅读辅助线。打开浮动控件“视图”标签页中的“舒适”即可使用，无需账户。

舒适设置会与其他设置一起保存在浏览器中；只有开启云同步后才会同步到账户。舒适工具不会将你观看的内容发送给单独的服务。

## 在哪里找到

| 位置 | 内容 |
|---|---|
| 浮动控件→“视图”→“舒适” | 4 项工具的快捷开关，以及“更多舒适设置” |
| “设置”→“视频功能”→“舒适与无障碍” | 全部选项和“重置舒适设置” |
| “设置”→“键盘快捷键”→“舒适” | 4 个默认未分配按键的快捷键 |

## 眼睛舒适度

开启“眼睛舒适度”，调整“暖色程度”（0% 至 100%），适合晚间观看。只改变视频，不改变整个页面。勾选“同时降低亮度”可进一步柔化画面。

开启“在设定时段自动启用”可让它定时开关。设置“开始”和“结束”时间；默认在 21:00 开始、07:00 结束，直到你修改。

## 色觉辅助

选择“类型”：绿弱、红弱、蓝黄辨色困难或无色觉。再选“模式”：

- “让颜色更清楚”会调整颜色，让不同颜色更易区分。
- “模拟观看效果”会展示该色觉类型的人可能看到的画面。

## 字幕样式

字幕样式会改变网站已有的字幕，适用于 YouTube、Netflix、Prime Video、Udemy、Coursera、Vimeo、Khan Academy、Video.js 播放器和含 WebVTT 轨道的视频。它不会生成字幕。

选择“字幕外观”和“文字大小”。

| 外观 | 效果 |
|---|---|
| 默认 | 深色底上的白字 |
| 高对比度 | 纯黑底上的较大加粗白字 |
| 深色 | 深灰底上的柔和浅色文字 |
| 精简 | 较浅底色上的小字 |
| 大字 | 较大的加粗黄字 |
| 彩色 | 深紫底上的加粗绿字 |
| 易读 | 字母和词间距更大、行距更高的无衬线字体，奶油色底上的深色文字 |

## 阅读辅助线

柔和的带状标记可帮助你将视线停留在一行字幕或屏幕文字上。选择“形状”（条带、线条或聚光区域），再选“固定位置”将它留在视频的同一高度，或选“跟随指针”让它随鼠标移动。“视频中的高度”决定位置，“强度”决定明显程度。

## 与其他控制同时使用

舒适设置可以与[视频滤镜](/docs/user-guide/video-filters)和影院色彩同时开启，效果会叠加。扩展会将它们合成应用于视频的一个滤镜，因此开启其中一项不会关闭另一项。

## 快捷键

4 个舒适功能快捷键默认都未分配按键：“切换眼睛舒适度”“切换色觉辅助”“切换字幕样式”和“切换阅读辅助线”。它们都是可选项，可按[修改快捷键](/docs/keyboard-shortcuts/rebinding)中的步骤设置。
