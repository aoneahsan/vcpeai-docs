按 `]` 或 `[`，每次调整 0.1x；也可拖动浮动控件的滑块，最高至 4x。方括号键可单独使用，无需 `Ctrl + Alt`；调速也无需账户。

## 调速按键

| 按键 | 作用 |
|---|---|
| `]` | 加快 0.1x |
| `[` | 减慢 0.1x |
| `=` | 恢复默认速度 |
| `\` | 显示当前速度 |
| `'` | 切换到动态速度 |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## 速度范围

范围为 0.1x 至 16x。滑块和方括号键最高到 4x。在浮动控件“速度”标签页的自定义输入框，或“设置”→“常规”中的“自定义速度（0.1x - 16x）”输入数值，最高可播放到 16x。

每次调整固定为 0.1x。“设置”中没有修改最低速度、最高速度或步长的选项。

## 默认速度与动态速度

打开“设置”→“常规”。

| 设置 | 含义 | 按键 |
|---|---|---|
| 默认播放速度 | 重置速度或加载新视频时使用 | `=` |
| 当前动态速度 | 在此另设一个速度，按一次键即可应用 | `'` |

`'` 会应用“当前动态速度”，不是该视频单独保存的速度。

## 速度预设

`Ctrl + Alt + 1` 至 `Ctrl + Alt + 8` 对应 8 个预设。你可以在“设置”→“键盘快捷键”中修改每个预设，并移除不用的预设。

添加第 9 个预设后，可使用 `Ctrl + Alt + 9`。

## 速度记忆

扩展会记住你为某个视频设置的速度，下次打开时自动应用。此项默认开启。

它还可以为整个播放列表或课程记住一个速度；此开关默认关闭，可在“设置”→“高级”中开启。

视频有多个已保存速度时，由“速度优先级”决定使用哪一个：

| 设置 | 优先使用 |
|---|---|
| 播放列表 / 课程优先 | 为播放列表或课程保存的速度 |
| 视频优先 | 为单个视频保存的速度 |
| 仅全局设置（忽略已保存速度） | 默认速度，忽略已保存速度 |
