在浮动控件的“工具”标签页，你可以保存当前位置的测验、带字幕示例的单词、日记，还能把视频加入学习路径或合集。每项都需要[连接账户](/docs/account-and-sync)，并随视频标题和地址一起保存在账户中。

未连接时，各分区会显示连接账户的方法。

## 此处出题

在“此处出题”下填写“问题”和“答案”，再按“保存测验”。测验会保存为闪卡。

同一视频播放经过这个位置时，视频会暂停并显示问题。按“显示答案”，再选“我知道”或“还没记住”，与“闪卡”页面一样为卡片评分。“此视频不再出题”会在本次访问期间关闭测验。每个位置每次访问只问一次，直接跳过该位置不会触发。

## 保存单词

在“保存单词”下输入一个单词，按“查询”，最多会显示 3 条释义。按“保存单词”，它会作为闪卡保存，并附上当时屏幕上的字幕行作为例句。

查询使用 Wiktionary，只会发送这个单词。

## 日记

选择“心情”（开心、受到启发、平静、沉思、难过或沮丧），填写“这一刻对你意味着什么”，再按“保存到日记”。这条记录是“日记”文件夹中的书签，带有心情标签，因此也可在“书签”中编辑。

## 学习路径与合集

在“学习路径”或“合集”下选择一个项目，按“添加此视频”。如果视频已在其中，会拒绝重复添加。请先到网站创建学习路径或合集；创建前，浮动控件会显示尚无项目。

开启“观看历史”后，若记录显示你已观看视频超过 90%，且过程中至少实际播放了一半，该学习路径视频会自动标为完成。直接跳到结尾不算。“观看历史”默认关闭，可在“设置”→“隐私与数据”中开启。

## 搜索资料库

浮动控件的“你的资料库”菜单和弹出面板的资料库网格都有“搜索资料库”。它会打开网站搜索，可查找笔记、书签和日记、闪卡和保存的单词、文字稿、稍后观看、观看历史、合集和学习路径。输入 2 至 100 个字符，每类最多返回 10 条结果，各结果都有指向对应视频时刻的链接。

## 网站上的页面

| 页面 | 显示内容 |
|---|---|
| 闪卡 | 供你复习的测验时刻和单词 |
| 词汇 | 已保存的单词，每个都链接到对应时刻 |
| 视频日记 | 按日期从新到旧排列的日记，可按心情筛选 |
| 课程进度 | 各学习路径的已完成数、总数和下一条视频 |
| 合集 | 你的合集，可下载为 JSON、CSV、Markdown 或 M3U 播放列表 |
