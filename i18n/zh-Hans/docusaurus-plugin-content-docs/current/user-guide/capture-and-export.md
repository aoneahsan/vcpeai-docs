“捕获与导出”可从视频制作 GIF、片段、延时视频、连续截图或缩略图合集，还可在截图上绘制标记。打开浮动控件“工具”标签页，找到“捕获与导出”。和[截图](/docs/user-guide/screenshots)一样，它需要[连接账户](/docs/account-and-sync)。

所有内容都在你的设备上制作，并作为下载文件保存，不会上传。

## 可制作的内容

| 按钮 | 结果 |
|---|---|
| “GIF · 接下来 5 秒” | 将接下来的 3、5、10 或 15 秒做成循环 GIF，宽度可选 320、480 或 640 px |
| “● 录制片段” | 将画面和声音录为 WebM，按“■ 停止录制”结束 |
| “延时 4x” | 将视频以 2x、4x、8x 或 16x 做成仅有画面的 WebM |
| “每 5 秒截图” | 播放期间每隔 2、5、10 或 30 秒截一张图，最多 100 张 |
| “缩略图合集 3×3” | 从整段视频中提取 3 × 3 或 4 × 4 帧，每帧标注时间，合成一张 PNG |
| “标注” | 在截图上绘制标记 |

按钮上的数字会随“设置”中的选择变化。片段与延时录制在 10 分钟后或视频结束时自动停止。

连续截图期间，按钮会显示已截张数。按“将……张保存为 ZIP”（按钮显示实际数量）可下载 PNG 压缩包；按“保存为合集”可合成一张图片。

## 标注截图

1. 按“标注”，在当前画面打开“标注截图”面板。
2. 选择工具：箭头、方框、高亮、文字或画笔。
3. 选择颜色：红、黄、绿、蓝或白。
4. 在画面上拖动绘制。使用文字工具时，点击、输入，再按 Enter。
5. 按“保存 PNG”下载，或按“复制”放入剪贴板。

`Ctrl + Z` 撤销上一个标记；`Esc` 关闭面板。

## 捕获设置

“设置”→“视频功能”→“捕获与导出”可设定“GIF 时长”“GIF 宽度”“延时速度”“连续截图间隔”以及“缩略图合集”尺寸。“重置捕获设置”会恢复默认值。

## 无法使用时

Netflix、Disney+ 等受保护视频无法捕获。有些其他网站也不允许保存视频帧，浮动控件会说明具体原因。缩略图合集需要已知视频时长，因此不适用于直播。暂停的视频无法捕获，请先按播放。

## 快捷键

“开始或停止录制片段”“制作 GIF”和“标注截图”这 3 个可选快捷键默认没有按键，均需连接账户。可在[修改快捷键](/docs/keyboard-shortcuts/rebinding)中设置。

若要制作适合社交帖文的片段，请查看[分享与同步观看](/docs/user-guide/share-and-watch-together)。
