连接[账户](/docs/account-and-sync)后，按 `Ctrl + Alt + C` 可将当前画面保存为 PNG 或 JPEG。

## 截图步骤

1. 暂停在需要的画面，或让视频继续播放。
2. 按 `Ctrl + Alt + C`，也可以在浮动控件的“工具”标签页按“捕获”。
3. 根据“设置”中的选择，画面会被下载、复制或上传。

暂停后按 `,` 或 `.` 逐帧移动，可以精确截取幻灯片显示完整的那一帧。

## 选择格式和保存位置

打开“设置”→“视频功能”，找到“截图”卡片。

| 选项 | 可选值 |
|---|---|
| 格式 | PNG（画质较高）或 JPEG（文件较小） |
| 操作 | 下载、复制到剪贴板、下载并复制、上传到云端、上传云端并复制 |
| 云端可见性 | 私密或公开，适用于云端操作 |
| 同步到云端资料库 | 开或关 |
| 包含时间戳 | 开或关 |
| 时间戳位置 | 左上、右上、左下、右下 |

时间戳是截图对应的视频时间，会写在图片上。给讲座幻灯片加上时间戳，之后便能找到它出现的位置。

## 图片保存在哪里

选择云端操作会上传图片。否则截图只留在当前设备。

## 单帧与动态片段

截图只保存一帧。如需保存移动的片段，可用片段录制器录制并下载。开关“片段录制”位于“设置”→“下载与捕获”。

## 相关按键

| 按键 | 作用 |
|---|---|
| `Ctrl + Alt + C` | 截取当前画面 |
| `,` | 后退一帧 |
| `.` | 前进一帧 |

这 3 个按键都能更改：初始按键见[默认快捷键](/docs/keyboard-shortcuts/defaults)，步骤见[修改快捷键](/docs/keyboard-shortcuts/rebinding)。
