滤镜包括亮度、对比度和饱和度（0% 至 200%），以及灰度、反色和夜间模式。[连接账户](/docs/account-and-sync)后，按 `Ctrl + Alt + F` 可打开浮动控件的“滤镜”标签页。

## 控制项

| 控制 | 范围或效果 | 按键 |
|---|---|---|
| 滤镜标签页 | 打开或关闭 | `Ctrl + Alt + F` |
| 亮度 | 0% 至 200% | 滑块 |
| 对比度 | 0% 至 200% | 滑块 |
| 饱和度 | 0% 至 200% | 滑块 |
| 灰度 | 开或关 | `Ctrl + Alt + G` |
| 反色 | 开或关 | `Ctrl + Alt + I` |
| 夜间模式 | 开或关 | `Ctrl + Alt + T` |

100% 是网站原本提供的画面，低于 100% 会减弱效果，高于 100% 会增强。各滑块最高到 200%。同一标签页中的“重置所有滤镜”会恢复原状。

## 什么时候使用

屏幕录制中，白底上的浅灰字难以阅读，可以提高对比度。

明亮的下午，暗色视频看不清，可以提高亮度。

深夜观看白板讲座时，白板像暗房中的亮矩形。按 `Ctrl + Alt + I` 反色，或按 `Ctrl + Alt + T` 开启夜间模式。

## 预设

将 3 个滑块调到合适的值，然后在“滤镜”标签页保存为预设。最多可保存 20 个。预设属于设置，因此可选择包含在[设置导出文件](/docs/account-and-sync)中。

## 更多画面控制

另有两个浮动控件标签页可改变画面，与“滤镜”标签页不同。

| 位置 | 控制 | 作用 |
|---|---|---|
| “视图”→“变换” | 旋转、镜像、翻转 | 旋转画面 90 度、水平镜像或垂直翻转 |
| “工具”→“视觉模式” | 环境光 | 在播放器周围显示环境光 |
| “工具”→“视觉模式” | 影院 | 应用影院色彩预设 |
| “工具”→“视觉模式” | 宽银幕 | 在画面上下添加影院黑边 |

滤镜只改变浏览器中的视频显示效果。截图和下载属于不同控制。
