A-B 循环会反复播放你指定的两个位置之间的片段。循环需要[连接账户](/docs/account-and-sync)，调速则不需要。如果循环快捷键没有反应，请先连接账户。

## 设置循环

1. 播放视频，找到想反复看的片段起点。
2. 按 `Ctrl + Alt + A`，设为 A 点。
3. 继续播放到片段终点。
4. 按 `Ctrl + Alt + B`，设为 B 点。

播放到 B 点时，视频会跳回 A 点，直到你清除循环。也可以在浮动控件的“循环”标签页中分别点一下设置 A 点和 B 点。

例如吉他课里一小节太快、讲座的证明过程只有 40 秒，或语言视频中某句话听不清：把 A、B 两点放在那段前后，用 `[` 降速，就可以反复看。

## 循环按键

| 按键 | 作用 |
|---|---|
| `Ctrl + Alt + A` | 设置起点 A |
| `Ctrl + Alt + B` | 设置终点 B |
| `Ctrl + Alt + L` | 开启或关闭循环 |
| `Ctrl + Alt + Backspace` | 清除两处标记 |

## 循环模式

在浮动控件的“循环”标签页中选择模式。浏览器语言为英语、西班牙语、法语、德语或乌尔都语时，标签会使用相应语言（见[更改语言](/docs/user-guide/display-and-widget)）。

| 模式 | 到达 B 点后 |
|---|---|
| 一直循环 | 持续重复，直到你关闭 |
| 循环一次 | 再重复一次 |
| 指定次数 | 按你设定的次数重复，可设 1 至 20 次 |

指定次数模式会显示进度，最多计 20 次。若要更多次，请使用“一直循环”，再用 `Ctrl + Alt + L` 手动停止。

## 相关按键

`,` 和 `.` 可逐帧后退或前进，方便精确放置 A、B 点。全部按键见[默认快捷键](/docs/keyboard-shortcuts/defaults)；在[修改快捷键](/docs/keyboard-shortcuts/rebinding)中可更改。
