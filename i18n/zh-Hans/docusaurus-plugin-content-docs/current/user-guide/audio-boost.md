[连接账户](/docs/account-and-sync)后，音量增强可将视频音量提高到 100% 以上，最高 400%。按 `Ctrl + Alt + U` 增强，按 `Ctrl + Alt + Y` 降低。

## 音频按键

| 按键 | 作用 |
|---|---|
| `Ctrl + Alt + U` | 增强 20% |
| `Ctrl + Alt + Y` | 降低增强量 20% |
| `Ctrl + Alt + N` | 开启或关闭音量均衡 |

浮动控件的“音频”标签页也有这些控制。

## 增强音量

从教室后排录制的讲座，即使播放器调到 100% 也可能很轻。音量增强可以超过这个上限，调到 100% 至 400%。

每按一次调整 20%。响亮的视频在 400% 时会非常大声，请逐步提高。

## 音量均衡

音量均衡会缩小最响与最轻片段之间的差距。如果讲者声音很轻而片头音乐很响，可以按 `Ctrl + Alt + N` 开启。

## 记住音量

扩展会按网站记住音量和静音状态。你可以让 YouTube 保持安静，让课程网站保持较大音量，下次打开时会恢复各自的设置。“记住音量”卡片位于“设置”→“视频功能”。

## 更多音频控制

音频标签页不止调大声音。连接账户后，在“高级音频”下可以按一个按钮使用低音增强、降噪、人声分离及其他功能。

| 按钮 | 作用 |
|---|---|
| Bass | 增强低音 |
| Denoise | 滤除背景噪声 |
| Spatial | 空间音频 |
| Vocals | 分离人声 |
| Compress | 压缩音频动态范围 |
| Karaoke | 卡拉 OK 模式 |
| Pitch | 音高预设 |
| EQ | 均衡器预设 |

## 下载音频

音频下载会将视频中的音频保存为 WebM 或 WAV，不提供 MP3。“音频下载”开关位于“设置”→“下载与捕获”，处理过程在你的设备上完成。
