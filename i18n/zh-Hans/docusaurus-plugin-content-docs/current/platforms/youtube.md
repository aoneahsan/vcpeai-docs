YouTube 上除了通用控制，还有专门的附加功能：评论搜索、踩数计数、频道屏蔽、字幕和缩略图下载都默认开启，每项在“设置”中都有独立开关。默认开启的功能无需账户即可运行；只有用来切换它们的“YouTube 功能”设置标签页需要连接账户，详见[账户与同步](/docs/account-and-sync)。

## 基本控制

速度、浮动控件和快捷键在 YouTube 上与其他网站一样。按 `]` 加快 0.1x，速度记忆会为每个视频保存速度。

## 默认开启的功能

多数 YouTube 附加功能默认开启，少数需要你自行打开。

| 功能 | 作用 | 默认状态 |
|---|---|---|
| 踩数计数 | 使用 Return YouTube Dislike API 显示踩数 | 开启，也在右键菜单中 |
| 评论搜索 | 搜索视频评论 | 开启，也在右键菜单中 |
| 频道屏蔽 | 从推荐中排除指定频道 | 开启，也在右键菜单中 |
| 缩略图下载 | 下载视频缩略图 | 开启 |
| 字幕下载 | 下载字幕 | 开启 |
| Shorts 屏蔽 | 从 YouTube 信息流中隐藏 Shorts | 关闭 |
| 自动宽屏 | 始终使用 YouTube 的宽屏剧院布局 | 关闭 |
| 跳过广告 | 当 YouTube 显示“跳过广告”时按下该按钮 | 关闭 |

“跳过广告”只会按 YouTube 显示的按钮，不会移除广告；按钮出现前不会执行操作。

## 开关在哪里

1. 打开“设置”。
2. 进入“YouTube 功能”标签页。
3. 如果标签页要求，请先连接账户。

附加功能按评论、发现与屏蔽、导航、观看体验、播放器、效率、学习、分析、高级和下载分组。网站的[YouTube 全部功能指南](https://vcpeai.aoneahsan.com/blog/youtube-extras-guide)说明 62 项功能分别做什么、有什么限制。

每项功能有两个开关。

| 开关 | 作用 |
|---|---|
| 启用 | 开启或关闭功能 |
| 在右键菜单中显示 | 将功能加入 YouTube 的右键菜单 |

这些附加功能只在 youtube.com 上运行。

## 如何运行附加功能

从浮动控件的 YouTube 标签页或右键菜单运行。浮动控件标签使用扩展所选语言（见[更改语言](/docs/user-guide/display-and-widget)）。

只有你选择加入右键菜单的功能才会出现在那里，以免菜单过长。

## 相关按键

`Ctrl + Alt + X` 可复制带当前时间戳的视频链接。其他默认按键见[默认快捷键](/docs/keyboard-shortcuts/defaults)，在[修改快捷键](/docs/keyboard-shortcuts/rebinding)中可更改。
