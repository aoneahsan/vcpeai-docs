在 LinkedIn 上，它不止控制视频：还可以评估个人资料完整度、追踪职位申请和导出帖子。每项工具在你从浮动控件或右键菜单选中时立即运行。基本视频控制与其他网站相同。默认开启的工具无需账户即可运行；但“设置”中的“LinkedIn 功能”标签页需要连接账户，才能切换功能（见[账户与同步](/docs/account-and-sync)）。

## 工具

工具会立即打开面板，或执行导出与下载。48 项工具各有专页，含步骤、示例和常见问题，从网站的[个人资料工具](https://vcpeai.aoneahsan.com/features/linkedin-profile)开始。

| 工具 | 作用 | 默认状态 |
|---|---|---|
| 个人资料评分 | 分析个人资料的完整度 | 开启 |
| 标题生成器 | 根据关键词生成个人标题 | 开启 |
| 职位追踪 | 追踪职位申请 | 开启 |
| 帖子导出 | 将帖子导出为 CSV 或 JSON | 开启 |
| 个人资料备份 | 备份个人资料 | 开启 |
| 消息导出 | 将消息导出为 CSV 或 JSON | 开启 |
| 信息流筛选 | 筛选信息流内容 | 关闭 |
| 专注模式 | 减少 LinkedIn 上的干扰 | 关闭 |

## 默认开启与关闭的区别

需要你主动选择才会运行的工具默认开启。网页加载时就会显示内容或改变 LinkedIn 信息流的工具则默认关闭；信息流筛选和专注模式属于后者。

## 开关在哪里

1. 打开“设置”。
2. 进入“LinkedIn 功能”标签页。
3. 如果标签页要求，请先连接账户。

工具按个人资料、内容创作、帖子与信息流、人脉、消息、职位、分析、导出、隐私和效率分组。

每项工具都有启用开关和“在右键菜单中显示”开关。工具只在 linkedin.com 上运行。

开关状态在重新加载 LinkedIn 页面后生效；菜单操作无需重新加载。

## 信息按钮

LinkedIn 工具打开的每个面板都有信息按钮。点击后可查看面板用途和用法。

## 写作辅助

LinkedIn 写作辅助是 AI 功能之一，提供 3 种使用方式。有关发送的内容与目标服务，请查看[AI 功能](/docs/ai-features)。
