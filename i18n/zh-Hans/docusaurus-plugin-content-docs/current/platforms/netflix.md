Netflix 上可使用速度和基本控制；专属功能默认关闭，需自行开启。“设置”中的“Netflix 功能”标签页需要连接账户，详见[账户与同步](/docs/account-and-sync)。

## 基本控制

无论是否连接账户，按 `]` 都可加快 0.1x，按 `[` 可减慢 0.1x。

## Netflix 附加功能由你开启

1. 打开“设置”。
2. 进入“Netflix 功能”标签页。
3. 如果标签页要求，请先连接账户。
4. 使用每项功能的启用开关。
5. 重新加载 Netflix 页面。

开关状态在重新加载后生效。菜单操作则不需等待：从浮动控件或右键菜单打开面板、启动计时器、导出或下载都会立即执行。

每项功能还有“在右键菜单中显示”开关。功能只在 netflix.com 上运行。网站的[Netflix 全部附加功能指南](https://vcpeai.aoneahsan.com/blog/netflix-extras-guide)介绍 50 项功能及 Netflix 自身保护带来的限制。

| 附加功能 | 作用 | 默认状态 |
|---|---|---|
| 跳过回顾 | 跳过“前情提要” | 关闭 |
| 双语字幕 | 同时显示两种字幕语言 | 关闭 |
| 字幕下载 | 下载 SRT 或 VTT 字幕 | 关闭 |
| 睡眠计时器 | 在设定分钟数后暂停 | 关闭 |
| 剧集导航 | 在剧集之间切换 | 关闭 |
| 观看限制 | 设定每日观看上限 | 关闭 |
| 对白增强 | 相对音乐与音效提高人声 | 关闭 |

观看限制只在可见标签页中视频实际播放时计时。后台标签页不会消耗每日限额。

## Netflix 恢复控制

Netflix 有时会显示“此设备不属于 Netflix 家庭”提示。扩展清除该页面后，Netflix 仍会隐藏自己的播放器控制。只有在这种情况下，下列键盘控制才会启用。

播放器上会显示简短提示，并链接到完整列表。

| 按键 | 作用 |
|---|---|
| `Space` | 播放或暂停 |
| `←` / `→` | 后退或前进 10 秒 |
| `Shift + ←` / `Shift + →` | 后退或前进 1 分钟 |
| `Ctrl + ←` / `Ctrl + →` | 后退或前进 5 分钟 |
| `Ctrl + 0` | 跳到开头 |
| `Ctrl + 1` 至 `Ctrl + 9` | 跳到 10% 至 90% 的位置 |
| `Ctrl + -` | 跳到结束前 1 分钟 |
| `↑` / `↓` | 调高或调低音量 |
| `M` | 静音或取消静音 |
| `F` | 开启或关闭全屏 |
| `V` | 切换到下一个字幕轨道，包括关闭字幕 |
| `B` | 切换到下一个音轨 |

每个按键都可在“设置”→“键盘快捷键”→“Netflix 恢复控制”中修改。一个按键只能属于一项快捷操作，因此恢复按键不能同时分配给通用快捷键。

## 限制

其他情况下，这些按键仍由 Netflix 自己处理。

扩展不会修复 Netflix 的所有错误。它会清除家庭设备提示，并提供键盘控制。
