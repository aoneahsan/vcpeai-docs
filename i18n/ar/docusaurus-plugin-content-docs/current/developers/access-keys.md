# مفاتيح الوصول

**يعمل مفتاح الوصول مثل كلمة مرور لأداة واحدة:** مزامنة جدول دراسة، أو نص برمجي، أو اختصار على هاتفك. ترسله الأداة مع كل طلب إلى [واجهة API](./api.md)، ولا يصل إلا إلى أجزاء مكتبتك التي حددتها عند إنشائه. يبدأ المفتاح بـ`vcp_pat_` ويتبعه نص عشوائي طويل. لا تضعه في شيء تشاركه مع الآخرين.

## إنشاء مفتاح {#making-a-key}

1. افتح **الحساب ← [التطبيقات الأخرى](https://vcpeai.aoneahsan.com/account/apps)** على الموقع، ثم اضغط **إنشاء مفتاح**.
2. أعطه **اسمًا** يذكّرك بالأداة التي تستخدمه، مثل «مزامنة جدول الدراسة».
3. حدد ما يمكنه الوصول إليه. لكل جزء ثلاث خانات: **قراءة** و**تغيير** و**حذف**. حدد جزءًا واحدًا على الأقل للقراءة.
4. اختر موعد **انتهاء الصلاحية بعد**: 30 أو 90 أو 365 يومًا، أو **أبدًا**. خيار «أبدًا» متاح لمفتاح القراءة فقط؛ أما مفتاح التغيير أو الحذف فلا بد له من تاريخ انتهاء.
5. اضغط **إنشاء مفتاح**، ثم انسخه. هذه هي المرة الوحيدة التي يظهر فيها من دون إعادة تسجيل الدخول.

يتطلب إنشاء المفتاح تسجيل دخول خلال آخر عشر دقائق، ورمز [تسجيل الدخول بخطوتين](./two-step-sign-in.md) إذا كانت الميزة مفعّلة. نرسل إليك رسالة تفيد بإنشاء المفتاح، من دون أن تتضمنه.

## ما يبلغه كل إذن {#what-each-tick-reaches}

تصبح كل خانة تحددها إذنًا للمفتاح. إذا طلب الوصول إلى شيء لم تسمح به، ترد الواجهة بـ`403 scope_required` وتذكر الإذن المطلوب.

| الجزء على الموقع | قراءة | تغيير | حذف | ما يبلغه في واجهة API |
|---|---|---|---|---|
| الإشارات المرجعية | `bookmarks:read` | `bookmarks:write` | `bookmarks:delete` | `bookmarks` |
| الملاحظات | `notes:read` | `notes:write` | `notes:delete` | `notes` |
| المجموعات | `collections:read` | `collections:write` | `collections:delete` | `collections`, `collection_videos` |
| البطاقات التعليمية | `flashcards:read` | `flashcards:write` | `flashcards:delete` | `flashcards` |
| مسارات التعلم | `paths:read` | `paths:write` | `paths:delete` | `learning_paths`, `path_videos` |
| سجل المشاهدة | `history:read` | | `history:delete` | `watch_history` |
| المشاهدة لاحقًا | `later:read` | `later:write` | `later:delete` | `watch_later` |
| النصوص المستخرجة | `transcripts:read` | `transcripts:write` | `transcripts:delete` | `transcripts`, `transcript_texts` |
| لقطات الشاشة | `screenshots:read` | | | `screenshots` |
| الإعدادات والاختصارات | `settings:read` | `settings:write` | | `settings` |
| الأجهزة | `devices:read` | `devices:write` | `devices:delete` | `devices` |
| حفلات المشاهدة | `parties:read` | | | `watch_parties`, `party_members` |
| إصلاحات المواقع المجتمعية | `fixes:read` | | | `site_fixes` |
| طلبات الميزات | `requests:read` | | | `feature_requests`, `request_votes` |

الخانة الفارغة تعني أن الموقع لا يقدّم ذلك الإذن: لا يمكن تغيير سجل المشاهدة بهذا المفتاح، ولقطات الشاشة والأجزاء المشتركة للقراءة فقط، ولا يمكن حذف الإعدادات. ويستطيع كل مفتاح قراءة خطتك واستخدامك اليومي (`account:read`، وهو جزء `account` من الواجهة) من دون خانة إضافية.

## إظهار المفتاح مرة أخرى {#showing-a-key-again}

اضغط **إظهار مجددًا** على المفتاح. لا نعرضه إلا إذا سجّلت الدخول خلال آخر عشر دقائق، حتى لا يكشفه متصفح تُرك مفتوحًا. وإذا فعّلت التحقق بخطوتين، نطلب الرمز حتى من المتصفح الذي اخترت تذكّره. يبقى المفتاح ظاهرًا مدة قصيرة؛ أغلقه بعد نسخه.

## استبدال مفتاح {#replacing-a-key}

اضغط **استبدال** إذا ظننت أن المفتاح انكشف أو أردت واحدًا جديدًا. تحصل على مفتاح جديد بالاسم والأذونات نفسيهما. يستمر القديم في العمل 24 ساعة حتى تبدّله في أدواتك، ثم يتوقف.

## حذف مفتاح {#removing-a-key}

اضغط **حذف**، ثم اضغطه ثانيةً للتأكيد. يحصل الطلب التالي الذي يستخدم ذلك المفتاح على `401 invalid_token`. لا يتغير شيء آخر: تبقى مكتبتك ومفاتيحك الأخرى ومساعدوك كما هي.

## التحقق من أذونات المفتاح {#checking-what-a-key-can-do}

يعيد `GET /token` نوع المفتاح وأذوناته مرتبة:

```bash
curl https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/api/v1/token \
  -H "Authorization: Bearer $VCP_KEY"
```

```json
{
  "data": {
    "kind": "pat",
    "user_id": "6a1f0c52-3b7d-4e8a-9f21-0c4d5e6b7a89",
    "client_id": null,
    "scopes": ["account:read", "bookmarks:read", "notes:read", "notes:write"]
  }
}
```

تعرض **التطبيقات الأخرى** أيضًا تاريخ إنشاء كل مفتاح وآخر استخدام له وموعد انتهاء صلاحيته.

## عدد المفاتيح المتاح {#how-many-you-can-have}

تسمح خطة Free بخمسة مفاتيح، وPro بخمسة وعشرين، وTeam بخمسين لكل عضو. لا يُحتسب المفتاح المحذوف. عند بلوغ الحد، احذف مفتاحًا أو انتقل إلى خطة أعلى من [صفحة الخطط](https://vcpeai.aoneahsan.com/plans).
