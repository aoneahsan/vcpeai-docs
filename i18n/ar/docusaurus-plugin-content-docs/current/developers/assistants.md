# المساعدون

**اربط مساعدًا لتسأله عن مكتبتك أنت:** «أي البطاقات التعليمية من محاضرات الأسبوع الماضي حان وقت مراجعتها؟» أو «لخّص ملاحظاتي عن هذا الفيديو» أو «أضف هذه المحاضرة إلى المشاهدة لاحقًا». يتصل Claude وChatGPT وClaude Code وCursor بعنوان واحد:

```text
https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp
```

يفتح لك المساعد موقع Video Controls Plus؛ تسجّل الدخول وتحدد ما يمكنه بلوغه وتوافق. لا تعطيه كلمة مرور أو مفتاحًا. تجد العنوان أيضًا في **الحساب ← [التطبيقات الأخرى](https://vcpeai.aoneahsan.com/account/apps)**، مع زر لنسخه.

## الربط {#connecting}

### Claude {#claude}

1. افتح **Settings → Connectors** في Claude واختر **Add custom connector**.
2. سمّه Video Controls Plus والصق العنوان أعلاه.
3. يفتح Claude موقعنا. حدد ما يمكنه بلوغه ووافق.

### ChatGPT {#chatgpt}

1. افتح **Settings → Apps and connectors** في ChatGPT، ثم **Advanced**، وشغّل وضع المطوّر.
2. اختر **Create**، وسمّه Video Controls Plus، والصق العنوان أعلاه.
3. يفتح ChatGPT موقعنا. حدد ما يمكنه بلوغه ووافق.

### Claude Code {#claude-code}

1. شغّل هذا الأمر في الطرفية:

   ```bash
   claude mcp add --transport http video-controls-plus https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp
   ```

2. شغّل `/mcp` داخل Claude Code واختر Video Controls Plus لتسجيل الدخول.
3. يفتح المتصفح موقعنا. حدد ما يمكنه بلوغه ووافق.

### Cursor {#cursor}

1. افتح **Settings → Tools & MCP** في Cursor واختر **New MCP server**.
2. أضف الأسطر التالية إلى الملف الذي يفتحه، ثم احفظه:

   ```json
   { "mcpServers": { "video-controls-plus": { "url": "https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp" } } }
   ```

3. يعرض Cursor عبارة **Needs login**. اضغطها وحدد ما يمكنه بلوغه على موقعنا ووافق.

## ما توافق عليه {#what-you-approve}

تذكر صفحة الموافقة اسم المساعد ووجهة عودته، ثم تعرض خانات القراءة والتغيير والحذف نفسها التي في [مفتاح الوصول](./access-keys.md#what-each-tick-reaches). يبدأ الحذف غير محدد. حدد شيئًا واحدًا على الأقل ليقرأه، أو اضغط **رفض**؛ فالمساعد المرفوض لا يبلغ شيئًا.

إذا كان [تسجيل الدخول بخطوتين](./two-step-sign-in.md) مفعّلًا، تدخل الرمز للموافقة. يتجاوز المتصفح المتذكَّر الرمز فقط عندما يكون الاتصال للقراءة. والسماح للمساعد بالتغيير أو الحذف يتطلب كذلك تسجيل دخول خلال آخر عشر دقائق. نرسل إليك رسالة تفيد بربط المساعد.

كل ما يقرؤه هو كلامك وبياناتك أنت. لا يرى تسجيل دخولك أو مفاتيحك أو مكتبة أي شخص آخر.

## الحذف ينتظر موافقتك {#deleting-waits-for-your-yes}

لا يحذف المساعد شيئًا بمفرده، حتى إن حددت له إذن الحذف. إذا طلبت منه إزالة ملاحظة، يعطيك رابطًا وينتظر طلب الحذف على الموقع:

1. يعطيك المساعد الرابط، وتعرض **التطبيقات الأخرى** الطلب تحت **طُلب الحذف، في انتظار موافقتك**.
2. افتحه. تعرض الصفحة ما سيُحذف والفيديو المرتبط به ووقت الطلب وآخر موعد للرد.
3. اضغط **حذف الملاحظة** (أو الإشارة أو البطاقة)، أو **الاحتفاظ بها**.

يبقى الطلب عشر دقائق. إذا انتهت المدة، فلا يُحذف شيء، ويمكنك إعادة الطلب من المساعد. تصله نتيجة «حُذفت» في المرة التالية التي يتحقق فيها.

## إعادة التسمية والفصل {#renaming-and-disconnecting}

يظهر كل مساعد متصل في **التطبيقات الأخرى** مع وقت ربطه وآخر استخدام له. أعطه اسمًا تتعرف عليه، أو اضغط **فصل** ثم أكّد بالضغط مرة أخرى. يُرفض طلبه التالي.

## عدد المساعدين المتاح {#how-many-you-can-connect}

تسمح Free بثلاثة اتصالات، وPro بعشرة، وTeam بخمسة وعشرين لكل عضو. إذا ربطت المساعد نفسه مجددًا، تُستبدل موافقته القديمة من دون شغل مكان إضافي. تُحتسب طلباته ضمن حدك اليومي ([الحدود](./index.md#limits-on-each-plan)).

## يقرأ المساعد ما كتبته أنت {#your-own-writing}

تصل ملاحظاتك وتسمياتك ونصوص بطاقاتك إلى المساعد بوصفها بيانات، كما كتبتها. إذا لصقت تعليمات داخل ملاحظة، يراها كنص من مكتبتك. حدد فقط الأجزاء التي تحتاجها المحادثة.

## لمطوّري عملاء MCP {#for-mcp-client-developers}

| | |
|---|---|
| النقل | Streamable HTTP، بلا حالة، عبر عنوان واحد |
| تسجيل الدخول | OAuth 2.1 مع PKCE، من خادم Supabase للمصادقة على `https://gjajgvsjhdbtrpvfiuwl.supabase.co/auth/v1` |
| الاكتشاف | بيانات المورد المحمي على `https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp/.well-known/oauth-protected-resource` |
| غياب الرمز | `401` مع ترويسة `WWW-Authenticate` تشير إلى بيانات الاكتشاف |
| مفاتيح الوصول | يعمل مفتاح `vcp_pat_` أيضًا كرمز bearer لعميل تديره بنفسك |
| الحدود | 120 طلبًا في الدقيقة لكل اتصال، إضافةً إلى حد الخطة اليومي |

تأتي الأدوات من الأجزاء نفسها في [واجهة API](./api.md#your-library): `list_<part>` و`get_<part>` و`create_<part>` و`update_<part>` و`prepare_delete_<part>` بحسب ما يسمح به كل جزء. لا يعرض `tools/list` إلا أدوات الأذونات التي منحتها لهذا الاتصال. للأجزاء المشتركة وخطتك أداتا عرض القائمة والتفاصيل فقط، ولا تصل الأدوات إلى الملاحظات الصوتية أو سجل الذكاء الاصطناعي.
