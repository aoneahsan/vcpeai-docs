# Video Controls Plus للمطوّرين

**يمكن لأدوات تربطها بنفسك الوصول إلى مكتبتك في Video Controls Plus من خارج الإضافة:** نص برمجي يستخدم مفتاح وصول، أو مساعد مثل Claude وChatGPT، أو خادمك الذي تصله التغييرات عبر ويب هوك. تُعدّ هذه الخيارات من الموقع، ضمن **الحساب ← [التطبيقات الأخرى](https://vcpeai.aoneahsan.com/account/apps)**، على جميع الخطط بما فيها المجانية.

لا يصل أي مفتاح أو مساعد أو ويب هوك إلا إلى الأجزاء التي تختارها له، ويتصرف باسمك. لا يرى شيئًا لا يمكنك رؤيته بنفسك على الموقع.

## ثلاث طرق للربط {#three-ways-in}

| ما تريد فعله | استخدم | الصفحة |
|---|---|---|
| نص برمجي أو مزامنة جدول بيانات أو اختصار هاتف يقرأ مكتبتك أو يغيّرها | مفتاح وصول وواجهة REST API | [مفاتيح الوصول](./access-keys.md)، [واجهة API](./api.md) |
| سؤال Claude أو ChatGPT أو Claude Code أو Cursor عن ملاحظاتك وبطاقاتك التعليمية | عنوان المساعد (MCP) | [المساعدون](./assistants.md) |
| إبلاغ خادمك فور حفظ ملاحظة أو إشارة مرجعية | عنوان ويب هوك | [الويب هوكس](./webhooks.md) |

## ما يمكن لتطبيق خارجي الوصول إليه {#what-an-outside-app-can-reach}

فقط ما تختاره، ومن بياناتك أنت:

- **القراءة والتغيير:** إشاراتك المرجعية وملاحظاتك ومجموعاتك والفيديوهات فيها، والبطاقات التعليمية ومسارات التعلم وفيديوهاتها، والمشاهدة لاحقًا، والنصوص المستخرجة، والإعدادات، والمتصفحات المتصلة بالإضافة.
- **القراءة والإزالة:** سجل مشاهدتك. لا تضيف إليه إلا الإضافة عندما يكون سجل المشاهدة مفعّلًا.
- **القراءة:** لقطات الشاشة. تبقى إزالتها داخل الإضافة.
- **الحذف:** عندما تختار إذن الحذف لذلك الجزء. يحذف المفتاح مباشرة. أما الحذف الذي يطلبه المساعد فينتظر موافقتك على الموقع.
- **قراءة فقط:** حفلات المشاهدة التي تستضيفها أو تنضم إليها، وإصلاحات المواقع المجتمعية، وطلبات الميزات وتصويتاتك.
- **متاح للقراءة دائمًا:** خطتك وحدودها وما استخدمته اليوم.

### ما لا يصل إليه مطلقًا {#what-it-never-reaches}

مهما اخترت من أذونات، لا يستطيع أي مفتاح أو مساعد أو ويب هوك:

- الوصول إلى مكتبة شخص آخر، أو كشف هويات أعضاء حفلة مشاهدتك الآخرين؛
- استضافة حفلة مشاهدة أو الانضمام إليها، أو التصويت، أو نشر إصلاح لموقع، أو تغيير طلب ميزة؛
- رؤية تسجيل دخولك أو رموز خطوتَي التحقق أو رموز الاسترداد أو المفاتيح أو أسرار التوقيع؛
- تغيير خطتك أو مدفوعاتك أو بريدك، أو ربط الإضافة؛
- قراءة ملاحظاتك الصوتية أو سجل الذكاء الاصطناعي أو المدفوعات أو الإحالات أو تحليلات الاستخدام؛
- فتح صفحة خاصة بالموظفين.

## حدود كل خطة {#limits-on-each-plan}

| | مجاني | Pro | Team (لكل عضو) |
|---|---|---|---|
| مفاتيح الوصول | 5 | 25 | 50 |
| طلبات الواجهة والمساعد يوميًا | 5,000 | 50,000 | 100,000 |
| عناوين الويب هوك | 3 | 20 | 40 |
| اتصالات المساعد | 3 | 10 | 25 |

تُحسب الطلبات اليومية لكل مفاتيحك ومساعديك معًا، ويُعاد العد عند منتصف الليل بتوقيت UTC. ولكل مفتاح أو مساعد حد مستقل قدره 120 طلبًا في الدقيقة، حتى يتوقف النص البرمجي الذي يرسل طلبات بلا حد. تعرض **التطبيقات الأخرى** استخدامك مقارنة بخطتك. تجد الخطط والأسعار في [الخطط](https://vcpeai.aoneahsan.com/plans).

## لا تظهر المفاتيح والأسرار مجددًا إلا بعد تسجيل دخول جديد {#keys-and-secrets-stay-hidden}

يظهر المفتاح أو سر توقيع الويب هوك كاملًا مرة واحدة عند إنشائه. بعد ذلك، لا نعرضه ثانية إلا خلال عشر دقائق من تسجيل دخولك، ومع رمز تطبيق المصادقة إذا كان [تسجيل الدخول بخطوتين](./two-step-sign-in.md) مفعّلًا. لا يمكن لمتصفح تُرك مفتوحًا أن يكشفه. نرسل إليك بريدًا عند إنشاء مفتاح أو ربط مساعد أو إضافة عنوان ويب هوك، ولا يحتوي البريد على المفتاح أو السر.
