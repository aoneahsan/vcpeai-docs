افتح أي صفحة تحتوي على فيديو واضغط `]`. ستزداد السرعة بمقدار 0.1x؛ وبهذا تكون قد استخدمت الإضافة.

## جرّب أدوات التحكم الأولى

1. افتح فيديو على YouTube أو Udemy أو Vimeo أو أي موقع يشغّل فيديو عاديًا.
2. اضغط `]` لزيادة السرعة بمقدار 0.1x، وكرّر الضغط حتى تصل إلى 4x.
3. اضغط `[` لتقليل السرعة بمقدار 0.1x.
4. اضغط `=` للعودة إلى سرعتك الافتراضية.
5. اضغط `Ctrl + Alt + 4` للانتقال مباشرةً إلى 2x.

لا يحتاج التحكم بالسرعة إلى حساب. ويمكنك استخدام المفتاحين `,` و`.` للانتقال بين إطارات الفيديو واحدًا تلو الآخر. وتصبح ميزة صورة داخل صورة متاحة بعد ربط الحساب.

## اعثر على لوحة التحكم العائمة

لوحة التحكم العائمة هي اللوحة التي تظهر بجانب الفيديو على الصفحة. انقر عليها لفتحها، واسحبها إلى الموضع الذي يناسبك.

اضغط `Esc` أو `Ctrl + Alt + H` لإخفائها، واضغط المفتاح نفسه مرة أخرى لإظهارها.

## اعثر على اللوحة المنبثقة والإعدادات

انقر على أيقونة Video Controls Plus في شريط أدوات المتصفح لفتح اللوحة المنبثقة. تعرض الموقع الحالي وما إذا كانت الإضافة تعمل عليه، ويمكنك منها [إيقاف الإضافة مؤقتًا على موقع واحد](/docs/getting-started/pause-per-site).

تفتح الإعدادات في علامة تبويب مستقلة.

## الأدوات التي تحتاج إلى حساب متصل

تعمل السرعة والإعدادات المسبقة والانتقال بين الإطارات ومشاركة الوقت ووضع المسرح والعلامات المحفوظة في المتصفح ولوحة التحكم العائمة دون حساب. بعد ربط الحساب، تتوفر هذه الأدوات:

| الأداة | مفتاح لتجربته بعد الربط |
|---|---|
| تكرار A-B | `Ctrl + Alt + A`، ثم `Ctrl + Alt + B` |
| صورة داخل صورة | `Ctrl + Alt + P` |
| تعزيز الصوت | `Ctrl + Alt + U` |
| فلاتر الفيديو | `Ctrl + Alt + F` |
| لقطات الشاشة | `Ctrl + Alt + C` |
| ملاحظات مرتبطة بالوقت | **ملاحظة** في تبويب الأدوات بلوحة التحكم العائمة |
| التخطي التلقائي | تشغيله من الإعدادات |

لا يوجد تسجيل دخول داخل الإضافة. حسابك موجود على vcpeai.aoneahsan.com؛ ولربطه، اضغط **ربط حسابك** في اللوحة المنبثقة أو تبويب الحساب والمزامنة في الإعدادات. تعمل هذه الطريقة في Chrome وEdge وFirefox. تشرح صفحة [الحساب والمزامنة](/docs/account-and-sync) الخطوات وما يضيفه الربط وما يُسجَّل.

## إذا لم يستجب المفتاح

تحتاج مفاتيح الأحرف والأرقام إلى `Ctrl + Alt`. أما `[`, `]`, `=`, `\`, `'`, `,`, `.` و`Esc` فتعمل وحدها. تجد الجدول الكامل في [الاختصارات الافتراضية](/docs/keyboard-shortcuts/defaults)، ويمكنك تغيير أي مفتاح في [تغيير اختصار](/docs/keyboard-shortcuts/rebinding).
