اضغط `]` أو `[` لتغيير السرعة بخطوات 0.1x، أو اسحب شريط السرعة في لوحة التحكم العائمة حتى 4x. تعمل مفاتيح الأقواس وحدها دون `Ctrl + Alt`، ولا يحتاج التحكم بالسرعة إلى حساب.

## مفاتيح السرعة

| المفتاح | ما يفعله |
|---|---|
| `]` | زيادة السرعة بمقدار 0.1x |
| `[` | تقليل السرعة بمقدار 0.1x |
| `=` | العودة إلى سرعتك الافتراضية |
| `\` | عرض السرعة الحالية |
| `'` | استخدام السرعة الديناميكية |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## حدود السرعة

يتراوح النطاق بين 0.1x و16x. يتوقف الشريط ومفاتيح الأقواس عند 4x. للوصول إلى 16x، أدخل السرعة في الحقل المخصص ضمن تبويب السرعة بلوحة التحكم العائمة، أو في حقول **السرعة المخصصة (0.1x - 16x)** ضمن التبويب العام في الإعدادات.

تكون خطوة التغيير دائمًا 0.1x. لا تتضمن الإعدادات خيارًا لتغيير الحد الأدنى أو الحد الأقصى أو حجم الخطوة.

## السرعة الافتراضية والسرعة الديناميكية

افتح الإعدادات وانتقل إلى التبويب العام.

| الإعداد | معناه | المفتاح |
|---|---|---|
| سرعة التشغيل الافتراضية | السرعة التي تُستخدم عند إعادة الضبط وعند تحميل فيديو جديد | `=` |
| السرعة الديناميكية الحالية | سرعة ثانية تحددها هنا وتطبّقها بمفتاح واحد | `'` |

يطبّق المفتاح `'` السرعة الديناميكية الحالية. وهي ليست السرعة المحفوظة للفيديو.

## السرعات المسبقة

توجد ثماني سرعات مسبقة على المفاتيح من `Ctrl + Alt + 1` إلى `Ctrl + Alt + 8`. يمكنك تعديل كل منها وحذف ما لا تستخدمه من تبويب اختصارات لوحة المفاتيح في الإعدادات.

أضف سرعة مسبقة تاسعة لاستخدام `Ctrl + Alt + 9`.

## تذكّر السرعة

تتذكر الإضافة السرعة التي ضبطتها لفيديو وتطبّقها عند فتح الفيديو مرة أخرى. هذه الميزة مفعّلة افتراضيًا.

يمكنها أيضًا تذكّر سرعة لقائمة تشغيل أو دورة كاملة. هذا الخيار معطّل افتراضيًا؛ ويمكن تشغيله من التبويب المتقدم في الإعدادات.

عندما تتوفر أكثر من سرعة محفوظة، يحدد **ترتيب أولوية السرعة** أيها يُستخدم:

| الإعداد | السرعة المستخدمة |
|---|---|
| قائمة التشغيل أو الدورة أولًا | السرعة المحفوظة لقائمة التشغيل أو الدورة |
| الفيديو أولًا | السرعة المحفوظة للفيديو |
| السرعة العامة فقط (تجاهل المحفوظة) | سرعتك الافتراضية؛ تُتجاهل السرعات المحفوظة |

## مفاتيح ذات صلة

ينقلك `,` و`.` إطارًا واحدًا إلى الخلف أو الأمام.

تجد المجموعة الكاملة في [الاختصارات الافتراضية](/docs/keyboard-shortcuts/defaults)، وتشرح صفحة [تغيير اختصار](/docs/keyboard-shortcuts/rebinding) طريقة تغيير أي مفتاح.

الأداة التالية: [تكرار A-B](/docs/user-guide/ab-loop).
