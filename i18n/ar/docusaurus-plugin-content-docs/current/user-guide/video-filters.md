تضبط الفلاتر السطوع والتباين والتشبع بين 0% و200%، وتضيف التدرج الرمادي وعكس الألوان والوضع الليلي. بعد ربط الحساب ([ما الذي يضيفه الربط؟](/docs/account-and-sync))، اضغط `Ctrl + Alt + F` لفتح تبويب الفلاتر في لوحة التحكم العائمة.

## أدوات التحكم

| الأداة | النطاق أو التأثير | المفتاح |
|---|---|---|
| تبويب الفلاتر | فتح التبويب أو إغلاقه | `Ctrl + Alt + F` |
| السطوع | من 0% إلى 200% | شريط التمرير |
| التباين | من 0% إلى 200% | شريط التمرير |
| التشبع | من 0% إلى 200% | شريط التمرير |
| التدرج الرمادي | تشغيل أو إيقاف | `Ctrl + Alt + G` |
| عكس الألوان | تشغيل أو إيقاف | `Ctrl + Alt + I` |
| الوضع الليلي | تشغيل أو إيقاف | `Ctrl + Alt + T` |

تعرض قيمة 100% الصورة كما يرسلها الموقع. ما دونها يقلل التأثير وما فوقها يزيده، ويتوقف كل شريط عند 200%. يعيد زر **إعادة ضبط جميع الفلاتر** في التبويب نفسه القيم الأصلية.

## متى تفيد هذه الأدوات؟

إذا صعبت قراءة نص رمادي فاتح على خلفية بيضاء في تسجيل شاشة، فزد التباين.

إذا كانت الصورة داكنة في نهار ساطع، فزد السطوع.

إذا بدت السبورة البيضاء مستطيلًا ساطعًا في غرفة مظلمة، فاضغط `Ctrl + Alt + I` لعكس الألوان، أو `Ctrl + Alt + T` للوضع الليلي.

## الإعدادات المسبقة

اضبط الأشرطة الثلاثة كما تريد واحفظ النتيجة إعدادًا مسبقًا من تبويب الفلاتر. يمكنك حفظ ما يصل إلى 20 إعدادًا، ويمكن تضمينها عند [تصدير إعداداتك](/docs/account-and-sync).

## أدوات أخرى للصورة

يغيّر تبويبان آخران في لوحة التحكم العائمة شكل الصورة، وهما منفصلان عن تبويب الفلاتر.

| المكان | الأداة | ما تفعله |
|---|---|---|
| تبويب العرض، **التحويل** | تدوير وعكس وقلب | تدوير الصورة 90 درجة أو عكسها أفقيًا أو قلبها رأسيًا |
| تبويب الأدوات، **الأوضاع البصرية** | الإضاءة المحيطة | إضاءة حول المشغّل |
| تبويب الأدوات، **الأوضاع البصرية** | السينما | نمط ألوان سينمائي |
| تبويب الأدوات، **الأوضاع البصرية** | الأشرطة السينمائية | أشرطة أعلى الصورة وأسفلها |

تغيّر الفلاتر طريقة عرض الفيديو في متصفحك. أما لقطة الشاشة والتنزيل فهما أداتان منفصلتان.

## مفاتيح ذات صلة

توجد مفاتيح الفلاتر في [جدول الاختصارات الافتراضية](/docs/keyboard-shortcuts/defaults)، وتشرح صفحة [تغيير اختصار](/docs/keyboard-shortcuts/rebinding) طريقة تغييرها.
