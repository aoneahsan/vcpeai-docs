تحتاج مفاتيح الحروف والأرقام إلى `Ctrl + Alt`؛ ولا تعمل وحدها إلا `[` و`]` و`=` و`\` و`'` و`,` و`.` و`Esc`. هكذا تبقى اختصارات الإضافة بعيدة عن مفاتيح مشغّل الموقع.

تعني «نعم» في العمود الأخير أن المفتاح يعمل مع حساب متصل. تسرد صفحة [الحساب والمزامنة](/docs/account-and-sync) ما يضيفه ربط الحساب.

## السرعة

يضم قسم التحكم بالسرعة في الإعدادات مفاتيح السرعة ولوحة التحكم العائمة.

| المفتاح | ما يفعله | يحتاج إلى حساب |
|---|---|---|
| `[` | تقليل السرعة بمقدار 0.1x | لا |
| `]` | زيادة السرعة بمقدار 0.1x | لا |
| `=` | العودة إلى السرعة الافتراضية | لا |
| `\` | عرض السرعة الحالية | لا |
| `'` | تطبيق السرعة الديناميكية الحالية المحددة في تبويب عام بالإعدادات | لا |
| `Esc` | إخفاء لوحة التحكم العائمة أو إظهارها | لا |
| `Ctrl + Alt + H` | إخفاء لوحة التحكم العائمة أو إظهارها | لا |

| المفتاح | ما يفعله | يحتاج إلى حساب |

## اختصارات اختيارية بلا مفتاح

تبدأ هذه الاختصارات من دون مفاتيح. افتح تبويب اختصارات لوحة المفاتيح في الإعدادات، واعثر على المجموعة، واضغط **تعيين**، ثم اضغط المفاتيح المطلوبة. إذا كان المفتاح مستخدمًا لاختصار آخر، تخبرك الإعدادات باسمه وتوصلك إليه.

| المجموعة في الإعدادات | الاختصار | يحتاج إلى حساب |
|---|---|---|
| الراحة | تبديل راحة العين | لا |
| الراحة | تبديل رؤية الألوان | لا |
| الإشارات المرجعية | تبديل وضع التركيز | لا |
| الراحة | تبديل شكل الترجمة المصاحبة | لا |
| الراحة | تبديل دليل القراءة | لا |
| الدراسة | بدء مؤقت الدراسة أو إيقافه مؤقتًا | لا |
| الدراسة | إظهار النص المستخرج أو إخفاؤه | لا |
| المؤثرات | تشغيل المؤثرات أو إيقافها | نعم |
| المؤثرات | تمويه منطقة من الفيديو | نعم |
| أدوات الصوت | تشغيل أدوات الصوت أو إيقافها | نعم |
| أدوات الصوت | تبديل اليسار واليمين | نعم |
| الالتقاط | تسجيل مقطع أو إيقافه | نعم |
| الالتقاط | إنشاء GIF | نعم |
| الالتقاط | التعليق على لقطة شاشة | نعم |
| الأتمتة | منع التشغيل التلقائي على هذا الموقع | لا |
| الأتمتة | بدء مسار السرعة أو إيقافه | لا |

تشرح كل مجموعة صفحتها: [الراحة وإمكانية الوصول](/docs/user-guide/comfort-and-accessibility)، و[أدوات الدراسة](/docs/user-guide/study-tools)، و[المؤثرات البصرية والتكبير](/docs/user-guide/visual-effects)، و[أدوات الصوت](/docs/user-guide/audio-tools)، و[الالتقاط والتصدير](/docs/user-guide/capture-and-export)، و[أتمتة التشغيل](/docs/user-guide/playback-automation).

## اختصارات يحددها المتصفح

يحدد المتصفح هذه المفاتيح الأربعة. ويقرر ما إذا كان كل منها معيّنًا؛ يمكنك تغييرها من صفحة اختصارات الإضافات في المتصفح. لا تستطيع الإضافة تغييرها.

| المفتاح المقترح | ما يفعله |
|---|---|
| `Alt + V` | فتح اللوحة المنبثقة |
| `Ctrl + Shift + V` (أو `Command + Shift + V` على Mac) | إظهار أدوات التحكم العائمة أو إخفاؤها |
| `Ctrl + Shift + P` (أو `Command + Shift + P` على Mac) | تشغيل صورة داخل صورة أو إيقافها |
| `Ctrl + Shift + C` (أو `Command + Shift + C` على Mac) | التقاط لقطة شاشة |

## Netflix

لدى Netflix مفاتيح خاصة لا تعمل إلا في حالة واحدة. تجد جدولها في [صفحة Netflix](/docs/platforms/netflix).

لتغيير أي مفتاح، راجع [تغيير اختصار](/docs/keyboard-shortcuts/rebinding).
