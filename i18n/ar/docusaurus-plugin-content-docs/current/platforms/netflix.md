تعمل السرعة وأدوات التحكم الأساسية على Netflix، وتبقى أدواته الخاصة معطّلة حتى تشغّلها. تجد مفاتيحها في تبويب ميزات Netflix بالإعدادات، وهو يحتاج إلى حساب متصل؛ راجع [الحساب والمزامنة](/docs/account-and-sync).

## أدوات التحكم الأساسية

اضغط `]` لزيادة السرعة بمقدار 0.1x أو `[` لتقليلها بالمقدار نفسه، سواء كان لديك حساب أم لا.

## تشغيل أدوات Netflix باختيارك

1. افتح الإعدادات.
2. انتقل إلى تبويب **ميزات Netflix**.
3. اربط حسابًا إذا طلب منك التبويب ذلك.
4. شغّل الأداة بمفتاح التفعيل الخاص بها.
5. أعد تحميل صفحة Netflix.

تطبّق مفاتيح التشغيل والإيقاف بعد إعادة التحميل. أما إجراءات القائمة فلا تنتظرها: فتح لوحة أو بدء مؤقت أو تصدير أو تنزيل من لوحة التحكم العائمة أو قائمة النقر الأيمن يبدأ فورًا.

لكل أداة أيضًا مفتاح **عرضها في قائمة النقر الأيمن**. تعمل الأدوات على netflix.com فقط. يشرح [دليل أدوات Netflix كلها](https://vcpeai.aoneahsan.com/blog/netflix-extras-guide) الأدوات الخمسين، مع الحدود التي تفرضها حماية Netflix.

| الأداة | ما تفعله | الوضع الافتراضي |
|---|---|---|
| تخطي الملخص | يتجاوز ملخص «سابقًا في…» | معطّل |
| ترجمتان مصاحبتان | يعرض لغتَي ترجمة في الوقت نفسه | معطّل |
| تنزيل الترجمة المصاحبة | ينزّلها بصيغة SRT أو VTT | معطّل |
| مؤقت النوم | يوقف الفيديو بعد عدد الدقائق الذي تحدده | معطّل |
| التنقل بين الحلقات | ينتقل بين الحلقات | معطّل |
| حدود المشاهدة | يحدد حدًا يوميًا للمشاهدة | معطّل |
| تعزيز الحوار | يرفع صوت الكلام مقارنة بالموسيقى والمؤثرات | معطّل |

لا يحسب حد المشاهدة الوقت إلا أثناء تشغيل فيديو في تبويب ظاهر. لا يستهلك التبويب الموجود في الخلفية الحد اليومي.

## أدوات الاستعادة على Netflix

يعرض Netflix أحيانًا شاشة تفيد بأن الجهاز ليس ضمن منزل Netflix. عندما تزيل الإضافة هذه الشاشة، تبقى أدوات المشغّل الأصلية مخفية. في هذه الحالة وحدها تعمل مفاتيح التحكم البديلة.

يظهر إشعار صغير على المشغّل يوضح أنها مفعّلة ويربط بقائمتها الكاملة.

| المفتاح | ما يفعله |
|---|---|
| `Space` | تشغيل أو إيقاف مؤقت |
| `←` / `→` | الرجوع أو التقدم 10 ثوانٍ |
| `Shift + ←` / `Shift + →` | الرجوع أو التقدم دقيقة واحدة |
| `Ctrl + ←` / `Ctrl + →` | الرجوع أو التقدم 5 دقائق |
| `Ctrl + 0` | الانتقال إلى البداية |
| `Ctrl + 1` إلى `Ctrl + 9` | الانتقال إلى 10% حتى 90% من الفيديو |
| `Ctrl + -` | الانتقال إلى ما قبل النهاية بدقيقة |
| `↑` / `↓` | زيادة مستوى الصوت أو تقليله |
| `M` | كتم الصوت أو إلغاء كتمه |
| `F` | تشغيل ملء الشاشة أو إيقافه |
| `V` | المسار التالي للترجمة المصاحبة، بما في ذلك إيقافها |
| `B` | مسار الصوت التالي |

يمكن تغيير كل مفتاح في الإعدادات، ضمن تبويب اختصارات لوحة المفاتيح تحت **أدوات استعادة Netflix**. لا يمكن تخصيص المفتاح لأكثر من إجراء واحد، فلا يجتمع اختصار استعادة مع اختصار عام.

## الحدود

في غير هذه الحالة، تبقى هذه المفاتيح من أدوات Netflix نفسها.

لا تصلح الإضافة جميع أخطاء Netflix؛ إنها تزيل شاشة المنزل وتوفر أدوات تحكم من لوحة المفاتيح.

## مفاتيح ذات صلة

تجد المفاتيح العامة في [الاختصارات الافتراضية](/docs/keyboard-shortcuts/defaults)، وخطوات تغيير أي مفتاح، عام أو خاص بالاستعادة، في [تغيير اختصار](/docs/keyboard-shortcuts/rebinding).
