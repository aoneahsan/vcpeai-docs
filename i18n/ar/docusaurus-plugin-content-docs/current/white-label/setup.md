بعد الدفع، تصلك رسالة الترخيص ومعها مفتاحك وهذه الخطوات. تحدد المتاجر مدد مراجعة الإضافات، ولذلك تعتمد مواعيد النشر عليها.

1. **ادفع من صفحة التسعير.** أدخل اسمك وبريدك والنطاق الذي سيستخدمه موقعك، ثم اضغط **المتابعة إلى الدفع**. تفتح صفحة الدفع في التبويب نفسه. تدفع بتحويل بنكي عبر Wise وترسل إلينا مرجع التحويل؛ نصدر الترخيص بعد تأكيد التحويل.
2. **رد على رسالة الترخيص** باسم منتجك وشعارك بصيغة SVG أو PNG كبيرة وألوانك ونطاقك.
3. **نبني نسختك.** تحمل الإضافة وموقعها اسمك وألوانك. نرسل إليك نص صفحات المتاجر ولقطات الشاشة للموافقة.
4. **ننشر الإضافة** ضمن حسابات المطوّر الخاصة بك في Chrome Web Store وFirefox Add-ons وMicrosoft Edge Add-ons. تضيفنا إلى كل حساب أو تمنحنا وصولًا بالطريقة التي يتيحها المتجر.
5. **نربط نطاقك** وننشر الموقع. تضيف أنت سجلات DNS التي نرسلها.
6. **يبدأ ترخيصك** عند نشر النسخة. يقدّم موقعك ملف الترخيص، ويمكن [لأي شخص التحقق منه](./verify.md).

## ما تحتاج إلى تحضيره

- حساب مطوّر في كل متجر: Chrome Web Store، وFirefox Add-ons (مجاني)، وMicrosoft Partner Center لإضافة Edge.
- وصول إلى سجلات DNS الخاصة بنطاقك.
- شعارك وألوانك.

أي تغيير في طريقة عمل نسختك يتجاوز الاسم والشعار والألوان يُعد [عملًا مخصصًا](https://vcpeai.aoneahsan.com/white-label/custom-work) ويُسعّر على حدة.
