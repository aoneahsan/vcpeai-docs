NudgePlay لوحة صغيرة تظهر عند تمرير المؤشر فوق المشغّل، للتشغيل والإيقاف وسرعة تتذكرها لكل فيديو. إذا كانت هذه اللوحة الصغيرة كل ما يعجبك، فاحتفظ بها. لدى Video Controls Plus لوحة أيضًا، مع سرعة حتى 16x وتكرار A-B وفلاتر وملاحظات، وحساب واحد عبر أجهزتك. وأنت تختار مقدار ما يظهر منها.

**آخر تحقق: 2026-11-27.** لوحة صغيرة فوق المشغّل تظهر عند تمرير المؤشر، للتشغيل والإيقاف وسرعة من 0.1x إلى 5x تُحفظ لكل فيديو. <a href="https://microsoftedge.microsoft.com/addons/detail/web-video-controller-nu/dmacnkcmaabfmgjdeobmjiehgdnppipi" target="_blank" rel="noopener noreferrer nofollow">افحص Web Video Controller - NudgePlay بنفسك</a>.

## أيهما يناسبك

- **Web Video Controller - NudgePlay:** اختره إذا أردت لوحة سرعة صغيرة فوق المشغّل تتذكر كل فيديو، ولا تحتاج أدوات أخرى.
- **Video Controls Plus:** اختره إذا أردت هذه اللوحة مع سرعة حتى 16x، وتكرار A-B، وفلاتر، وملاحظات، وحسابًا واحدًا عبر الأجهزة.

## لوحة بدل لوحة

1. [ثبّت Video Controls Plus](../getting-started/install.md).
2. لوحتان فوق مشغّل واحد أكثر مما تحتاج، لذا أوقف NudgePlay من صفحة الإضافات الآن.
3. حدد موضع لوحتنا وحجمها لتكون حيث كانت لوحة NudgePlay: [طريقة ظهور أدوات التحكم على الصفحة](../user-guide/display-and-widget.md).
4. تتجاوز السرعة حد NudgePlay البالغ 5x لتصل إلى 16x: [التحكم بسرعة التشغيل](../user-guide/speed-control.md). ولحفظها، حدد سرعة لكل موقع ضمن [الأتمتة](../user-guide/playback-automation.md).
5. عندما تعمل فيديوهاتك المعتادة كما تريد، أزل NudgePlay.

## ما تذكره صفحة NudgePlay

تغطي الصفحة اللوحة والسرعة. لا تذكر التكرار أو الفلاتر أو الملاحظات أو النصوص أو البطاقات التعليمية أو السجل أو المشاهدة لاحقًا أو المزامنة أو أدوات المواقع أو Chrome أو Firefox، ولا نعرض هذه البنود في الجدول.
