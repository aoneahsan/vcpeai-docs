मौजूदा फ़्रेम को PNG या JPEG में सहेजने के लिए `Ctrl + Alt + C` दबाएँ। इसके लिए [अकाउंट](/docs/account-and-sync) चाहिए।

## स्क्रीनशॉट लें

1. मनचाहे फ़्रेम पर वीडियो रोकें या चलने दें।
2. `Ctrl + Alt + C` दबाएँ या विजेट के Tools टैब पर **Capture** क्लिक करें।
3. Settings में चुने गए विकल्प के अनुसार फ़्रेम डाउनलोड, कॉपी या अपलोड होगा।

सटीक फ़्रेम के लिए वीडियो रोककर `,` या `.` से एक-एक फ़्रेम आगे-पीछे जाएँ; फिर स्क्रीनशॉट लें।

## फ़ॉर्मैट और जगह चुनें

Settings के Video Features टैब पर **Screenshot** कार्ड खोलें।

| विकल्प | चुनाव |
|---|---|
| Format | PNG (अधिक गुणवत्ता) या JPEG (छोटी फ़ाइल) |
| Action | Download, Copy to Clipboard, Download + Clipboard, Upload to Cloud या Cloud + Clipboard |
| Cloud Visibility | क्लाउड विकल्पों के लिए Private या Public |
| Sync to cloud library | चालू या बंद |
| Include Timestamp | चालू या बंद |
| Timestamp Position | Top Left, Top Right, Bottom Left, Bottom Right |

समय चिह्न फ़्रेम के वीडियो समय को चित्र पर लिखता है। व्याख्यान की स्लाइड पर इसे चालू रखें, ताकि बाद में पता रहे कि हर चित्र कहाँ से लिया था।

## चित्र कहाँ जाता है

क्लाउड वाला विकल्प चुनने पर चित्र अपलोड होता है। अन्य विकल्पों में कैप्चर आपके डिवाइस पर रहता है।

## एक फ़्रेम या चलता हुआ हिस्सा

स्क्रीनशॉट केवल एक फ़्रेम है। वीडियो का चलता हुआ भाग सहेजने के लिए क्लिप रिकॉर्डर इस्तेमाल करें। उसका **Clip Recording** स्विच Settings के Download & Capture टैब में है।

## संबंधित कुंजियाँ

| कुंजी | काम |
|---|---|
| `Ctrl + Alt + C` | फ़्रेम कैप्चर |
| `,` | एक फ़्रेम पीछे |
| `.` | एक फ़्रेम आगे |

तीनों बदली जा सकती हैं। शुरुआती कुंजियाँ [डिफ़ॉल्ट शॉर्टकट](/docs/keyboard-shortcuts/defaults) में और बदलने के चरण [शॉर्टकट बदलें](/docs/keyboard-shortcuts/rebinding) में हैं।

आगे [नोट्स और बुकमार्क](/docs/user-guide/notes-and-bookmarks) पढ़ें।
