`]` और `[` से 0.1x के अंतर में स्पीड बदलें या विजेट का स्लाइडर 4x तक खिसकाएँ। इन ब्रैकेट कुंजियों के साथ `Ctrl + Alt` नहीं चाहिए। स्पीड नियंत्रण बिना अकाउंट के चलता है।

## स्पीड की कुंजियाँ

| कुंजी | काम |
|---|---|
| `]` | 0.1x तेज़ |
| `[` | 0.1x धीमा |
| `=` | आपकी डिफ़ॉल्ट स्पीड पर लौटें |
| `\` | मौजूदा स्पीड दिखाएँ |
| `'` | डायनेमिक स्पीड लगाएँ |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## स्पीड की सीमा

सीमा 0.1x से 16x है। स्लाइडर और ब्रैकेट कुंजियाँ 4x पर रुकती हैं। विजेट के Speed टैब के कस्टम इनपुट या Settings के General टैब के **Custom Speed (0.1x - 16x)** बॉक्स में स्पीड लिखकर 16x तक चलाएँ।

बदलाव हमेशा 0.1x का होता है। Settings में न्यूनतम स्पीड, अधिकतम स्पीड या इस अंतर को बदलने का नियंत्रण नहीं है।

## डिफ़ॉल्ट और डायनेमिक स्पीड

Settings के General टैब पर जाएँ।

| सेटिंग | अर्थ | कुंजी |
|---|---|---|
| Default Playback Speed | रीसेट करने और नया वीडियो खुलने पर लगने वाली स्पीड | `=` |
| Current Dynamic Speed | यहाँ तय की गई दूसरी स्पीड, जिसे एक कुंजी से लगाएँ | `'` |

`'` Current Dynamic Speed लगाता है। यह वीडियो के लिए सहेजी स्पीड नहीं है।

## पूर्वनिर्धारित स्पीड

`Ctrl + Alt + 1` से `Ctrl + Alt + 8` पर 8 प्रीसेट हैं। हर एक बदला जा सकता है; जो इस्तेमाल नहीं करते, हटा सकते हैं। Settings के Keyboard Shortcuts टैब में इन्हें बदलें।

नौवाँ प्रीसेट जोड़ने पर `Ctrl + Alt + 9` मिलता है।

## स्पीड मेमोरी

एक्सटेंशन वीडियो के लिए तय स्पीड याद रखता है और अगली बार वही वीडियो खोलने पर लगाता है। यह शुरू में चालू है।

पूरी प्लेलिस्ट या पाठ्यक्रम के लिए एक स्पीड भी याद रख सकता है। यह स्विच शुरू में बंद है; Settings के Advanced टैब में चालू करें।

एक वीडियो के लिए एक से अधिक स्पीड सहेजी हों तो **Speed Priority** तय करता है कि कौन-सी लगेगी:

| सेटिंग | प्राथमिक स्पीड |
|---|---|
| Playlist/Course first | प्लेलिस्ट या पाठ्यक्रम के लिए सहेजी स्पीड |
| Video first | उस वीडियो के लिए सहेजी स्पीड |
| Global only (ignore saved) | आपकी डिफ़ॉल्ट स्पीड; सहेजी स्पीड अनदेखी |

## संबंधित कुंजियाँ

`,` और `.` एक फ़्रेम पीछे और आगे ले जाती हैं।

पूरी सूची [डिफ़ॉल्ट शॉर्टकट](/docs/keyboard-shortcuts/defaults) में है। कुंजी बदलना [शॉर्टकट बदलें](/docs/keyboard-shortcuts/rebinding) में समझाया गया है।

अगला नियंत्रण: [A-B लूप](/docs/user-guide/ab-loop)।
