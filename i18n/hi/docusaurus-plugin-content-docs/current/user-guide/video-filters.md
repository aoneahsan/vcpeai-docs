ब्राइटनेस, कॉन्ट्रास्ट और सैचुरेशन 0% से 200% तक बदले जा सकते हैं। ग्रेस्केल, इनवर्ट और नाइट मोड भी हैं। [अकाउंट जोड़ने](/docs/account-and-sync) के बाद विजेट का Filters टैब खोलने के लिए `Ctrl + Alt + F` दबाएँ।

## नियंत्रण

| नियंत्रण | सीमा या असर | कुंजी |
|---|---|---|
| Filters tab | फ़िल्टर टैब खोलें या बंद करें | `Ctrl + Alt + F` |
| Brightness | 0% से 200% | स्लाइडर |
| Contrast | 0% से 200% | स्लाइडर |
| Saturation | 0% से 200% | स्लाइडर |
| Grayscale | चालू या बंद | `Ctrl + Alt + G` |
| Invert | चालू या बंद | `Ctrl + Alt + I` |
| Night mode | चालू या बंद | `Ctrl + Alt + T` |

100% पर चित्र वैसा है जैसा साइट भेजती है। इससे नीचे असर कम और ऊपर ज़्यादा है; स्लाइडर 200% पर रुकते हैं। उसी टैब का **Reset All Filters** सब कुछ वापस करता है।

## कब कौन-सा फ़िल्टर उपयोगी है

सफ़ेद पृष्ठभूमि पर हल्का धूसर पाठ पढ़ना कठिन हो तो कॉन्ट्रास्ट बढ़ाएँ।

तेज़ धूप में गहरा वीडियो साफ़ न दिखे तो ब्राइटनेस बढ़ाएँ।

रात में सफ़ेद व्हाइटबोर्ड कमरे में बहुत चमके तो `Ctrl + Alt + I` से रंग उलटें या `Ctrl + Alt + T` से नाइट मोड चालू करें।

## प्रीसेट

तीनों स्लाइडर मनचाहे स्तर पर रखकर Filters टैब में प्रीसेट सहेजें। 20 तक प्रीसेट रख सकते हैं। वे आपकी सेटिंग्स का हिस्सा हैं, इसलिए [सेटिंग्स निर्यात](/docs/account-and-sync) में शामिल हो सकते हैं।

## चित्र के और नियंत्रण

विजेट के दो और टैब चित्र बदलते हैं; वे Filters टैब से अलग हैं।

| कहाँ | नियंत्रण | काम |
|---|---|---|
| View टैब, **Transform** | Rotate, mirror, flip | चित्र को 90 डिग्री घुमाना, दाएँ-बाएँ उलटना या ऊपर-नीचे पलटना |
| Tools टैब, **Visual Modes** | Ambient | प्लेयर के चारों ओर परिवेशी रोशनी |
| Tools टैब, **Visual Modes** | Cinema | सिनेमा रंग प्रीसेट |
| Tools टैब, **Visual Modes** | Letterbox | चित्र के ऊपर और नीचे सिनेमा पट्टियाँ |

फ़िल्टर आपके ब्राउज़र में वीडियो दिखने का तरीका बदलते हैं। स्क्रीनशॉट और डाउनलोड अलग नियंत्रण हैं।
