# Двухэтапный вход

**После входа через Google двухэтапная проверка запрашивает шестизначный код из приложения-аутентификатора.** Одного пароля Google уже недостаточно для входа в Video Controls Plus. Для пользователей это необязательная функция, для сотрудников — обязательная. Включите её на сайте в **Account → [Security](https://vcpeai.aoneahsan.com/account/security)**. Подключение расширения следует тем же правилам: см. [ниже](#the-extension).

## Настройте второй шаг {#setting-it-up}

Нужны телефон и надёжное место для десяти кодов восстановления. Настройка занимает около двух минут.

1. Откройте **Security** и нажмите **Set up two-step**.
2. Сканируйте QR-код через Google Authenticator, Microsoft Authenticator, 1Password, Authy или другое приложение для таких кодов. Если сканирование невозможно, вручную введите ключ как ключ с ограничением по времени.
3. Введите текущий код Video Controls Plus из приложения и нажмите **Turn on two-step**. Код меняется каждые 30 секунд.
4. Сохраните десять кодов восстановления через **Copy all** или **Download .txt**, затем нажмите **I've saved them**.

## Коды восстановления {#recovery-codes}

Код восстановления позволяет войти без телефона. Каждый действует один раз и выглядит как `k7m2p-x9qr4`; дефис можно не вводить. Мы храним только преобразованную копию, поэтому полный набор виден лишь при настройке.

**Security** показывает остаток и предупреждает, когда остаётся три. **Make new codes** заменяет все десять: старые перестают работать при появлении новых. Требуются код из приложения и вход в течение последних 10 минут.

## Войдите в учётную запись {#signing-in}

Войдите через Google как обычно, затем введите код из приложения. После нескольких неверных кодов придётся подождать 10 минут либо использовать код восстановления.

### Запомните браузер {#remembering-a-browser}

После ввода кода можно отметить **Remember this browser for 7 days**. По умолчанию отметки нет; включайте её только на собственном браузере. В течение 7 дней код при входе там не нужен. Посещения не продлевают срок.

Для показа ключа доступа или секрета вебхука код всё равно нужен, как и для служебных страниц. **Security** перечисляет запомненные браузеры и срок их действия. **Forget** и **Forget all browsers** снова требуют код при следующем входе. Выход из учётной записи тоже забывает браузер.

## Если телефон потерян {#losing-your-phone}

1. На экране кода выберите **Lost your phone?** и **Use a recovery code instead**.
2. Введите один код. Вы войдёте на этот сеанс, а двухэтапная проверка останется включённой. Мы сообщим по почте об использовании кода.
3. Сразу нажмите **Add a new phone** и сканируйте новый QR-код. Для показа ключа или секрета нужен код из приложения-аутентификатора, поэтому настройте новое устройство заранее.

Если нет ни телефона, ни кодов, напишите нам с адреса своей учётной записи через [форму связи](https://vcpeai.aoneahsan.com/contact). Мы проверим вашу личность по сведениям о собственной библиотеке и затем отключим второй шаг, чтобы вы смогли войти через Google и настроить его снова. Об этом придёт письмо. По запросу с другого адреса мы проверку не отключаем.

## Новый телефон или отключение {#a-new-phone-or-turning-it-off}

- **Новый телефон:** введите код со старого, затем сканируйте новый QR-код. Коды старого устройства перестанут работать.
- **Отключение:** введите код из приложения и нажмите **Turn it off**. После этого для входа нужен только Google; коды восстановления и запомненные браузеры удаляются.

Для служебных учётных записей второй шаг остаётся включённым.

## Последние входы {#recent-sign-ins}

**Security** перечисляет входы на сайте и подключения расширения с указанием способа: Google, Google с кодом, запомненный браузер, код восстановления или подключение расширения. **Sign out everywhere else** завершает все остальные сеансы и отключает расширение в тех браузерах до нового подключения.

## Расширение {#the-extension}

У расширения нет собственного пароля или входа. Оно подключается к учётной записи сайта: открывает сайт, где вы входите, сверяете короткий код и нажимаете **Connect this browser** ([порядок подключения](../account-and-sync.md#connect-the-extension-to-your-account)). При включённой двухэтапной проверке до подтверждения понадобится код либо запомненный браузер.

- **Семь дней.** Подключённое расширение считается доверенным 7 дней с момента подключения, не дольше. Затем оно показывает **Connect again**. Управление скоростью и другие функции без учётной записи продолжают работать.
- **Включение позже.** Если второй шаг включён после подключения, прежнее подключение не считается доверенным. Подключите расширение заново.
- **Удаление браузера.** Удалите его в разделе **The extension** страницы Security или через [API](./api.md#devices). Расширение на нём выйдет из учётной записи и покажет **Connect again**.

Код никогда не вводится внутри расширения — только на сайте.
