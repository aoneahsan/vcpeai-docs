# Изменения для разработчиков

Здесь перечислены изменения для тех, кто подключает инструменты к Video Controls Plus, начиная с новых. Выпуски продукта — в [общей истории изменений](/ru/changelog).

## 21 ноября 2026 г.: другие приложения и двухэтапный вход {#2026-11-21}

- **Новое: [ключи доступа](./access-keys.md)** вида `vcp_pat_…`, созданные в **Account → Other apps**. Для каждого отдельно задаются Read, Change и Delete и срок действия, если ключ не только читает.
- **Новое: [API](./api.md) версии 1** для закладок, заметок, коллекций, карточек, учебных путей, истории и отложенных видео, расшифровок, снимков, настроек и устройств. Совместный просмотр, исправления сайтов, запросы функций и план доступны только для чтения. Документ OpenAPI 3.1 находится по адресу `/v1/openapi.json`.
- **Новое: [адрес для помощников](./assistants.md)** Claude, ChatGPT, Claude Code и Cursor. Удаление по запросу помощника ждёт вашего подтверждения на сайте.
- **Новое: [вебхуки](./webhooks.md)** с подписью Standard Webhooks, 32 событиями на выбор и тестовым сообщением. По умолчанию сообщения короткие; для каждого адреса отдельно включается **Include what was written**.
- **Новое: [двухэтапный вход](./two-step-sign-in.md)** на сайте с десятью кодами восстановления и необязательным запоминанием браузера на 7 дней. Подключённое расширение при включённой проверке считается доверенным 7 дней.
- **Лимиты:** Free — 5 ключей, 5 000 запросов в день, 3 адреса вебхуков и 3 помощника; Pro — 25, 50 000, 20 и 10; Team — 50, 100 000, 40 и 25 на участника.
