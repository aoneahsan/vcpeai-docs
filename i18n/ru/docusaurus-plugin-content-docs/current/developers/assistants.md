# Помощники

**Подключённый помощник отвечает на вопросы о вашей библиотеке:** какие карточки прошлой недели пора повторить, как обобщить заметки по видео или как добавить выступление в Watch Later. Claude, ChatGPT, Claude Code и Cursor используют один адрес:

```text
https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp
```

Помощник направит вас на сайт Video Controls Plus. Там вы войдёте, отметите доступные ему разделы и подтвердите подключение. Пароль или ключ ему передавать не нужно. Адрес с кнопкой копирования есть и в **Account → [Other apps](https://vcpeai.aoneahsan.com/account/apps)**.

## Подключение {#connecting}

### Claude {#claude}

1. В Claude откройте **Settings → Connectors** и выберите **Add custom connector**.
2. Назовите подключение Video Controls Plus и вставьте адрес выше.
3. В открывшемся сайте отметьте доступные разделы и подтвердите.

### ChatGPT {#chatgpt}

1. В ChatGPT откройте **Settings → Apps and connectors → Advanced** и включите режим разработчика.
2. Нажмите **Create**, назовите подключение Video Controls Plus и вставьте адрес.
3. В открывшемся сайте отметьте доступные разделы и подтвердите.

### Claude Code {#claude-code}

1. В терминале выполните:

   ```bash
   claude mcp add --transport http video-controls-plus https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp
   ```

2. В Claude Code выполните `/mcp` и выберите Video Controls Plus для входа.
3. В открывшемся сайте отметьте доступные разделы и подтвердите.

### Cursor {#cursor}

1. В Cursor откройте **Settings → Tools & MCP** и выберите **New MCP server**.
2. Добавьте строки в открывшийся файл и сохраните:

   ```json
   { "mcpServers": { "video-controls-plus": { "url": "https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp" } } }
   ```

3. Cursor покажет **Needs login**. Нажмите эту кнопку, отметьте доступные разделы на сайте и подтвердите.

## Что вы разрешаете {#what-you-approve}

Страница подтверждения показывает имя помощника и адрес возврата, затем те же поля Read, Change и Delete, что у [ключа доступа](./access-keys.md#what-each-tick-reaches). Delete изначально выключено. Отметьте хотя бы один раздел для чтения или нажмите **Deny**; после отказа помощник не получит ничего.

При включённом [двухэтапном входе](./two-step-sign-in.md) нужен код. Запомненный браузер пропускает его, только если помощник получает одно чтение. Для изменения или удаления дополнительно требуется вход в течение последних 10 минут. О подключении помощника приходит письмо.

Помощник читает только ваши собственные данные. Данные входа, ключи и чужие библиотеки ему недоступны.

## Удаление ждёт вашего подтверждения {#deleting-waits-for-your-yes}

Даже с отмеченным Delete помощник не удаляет сам. Если вы просите убрать заметку, он возвращает ссылку, а запрос ждёт на сайте:

1. Помощник даст ссылку; в **Other apps** запрос появится под **Asked to delete, waiting for you**.
2. Откройте её. Страница покажет удаляемый элемент, его видео, время запроса и крайний срок ответа.
3. Нажмите **Delete the note** (или соответствующий другой элемент) либо **Keep it**.

Запрос действует 10 минут. Затем ничего не удаляется: при необходимости попросите помощника снова. При следующей проверке он получит ответ «deleted».

## Переименование и отключение {#renaming-and-disconnecting}

Каждый подключённый помощник показан в **Other apps** с датами подключения и последнего использования. Назначьте понятное имя или нажмите **Disconnect** и подтвердите повторным нажатием. Его следующий запрос будет отклонён.

## Сколько подключений доступно {#how-many-you-can-connect}

Free позволяет 3 подключения, Pro — 10, Team — 25 на участника. Повторное подключение того же помощника заменяет старое разрешение и не занимает новое место. Запросы помощника и ключей входят в общий дневной лимит ([таблица планов](./index.md#limits-on-each-plan)).

## Помощник читает ваш текст {#your-own-writing}

Заметки, подписи и текст карточек передаются помощнику как данные в том виде, в котором вы их написали. Если в заметке есть инструкции, помощник увидит их как часть библиотеки. Отмечайте только нужные для беседы разделы.

## Для разработчиков клиентов MCP {#for-mcp-client-developers}

| | |
|---|---|
| Передача | Streamable HTTP, без сохранения сеанса, один адрес |
| Вход | OAuth 2.1 с PKCE через сервер авторизации Supabase `https://gjajgvsjhdbtrpvfiuwl.supabase.co/auth/v1` |
| Обнаружение | Метаданные защищённого ресурса `https://gjajgvsjhdbtrpvfiuwl.supabase.co/functions/v1/mcp/.well-known/oauth-protected-resource` |
| Без токена | `401` с заголовком `WWW-Authenticate`, ведущим к метаданным |
| Ключи доступа | `vcp_pat_` тоже может быть bearer-токеном собственного клиента |
| Лимит | 120 запросов в минуту на подключение плюс дневной лимит плана |

Инструменты происходят из тех же частей, что [API](./api.md#your-library): `list_<part>`, `get_<part>`, `create_<part>`, `update_<part>` и `prepare_delete_<part>`, если разрешено. `tools/list` показывает только доступные этому подключению действия. Для общих разделов и плана доступны лишь list/get; голосовых заметок и истории ИИ нет ни в одном инструменте.
