Лицензия даёт расширение и сайт под вашим брендом с обновлениями от нашей команды. Выкуп передаёт исходный код.

## По лицензии под своим брендом

- **Расширение под вашим названием.** Название, логотип и цвета в панели браузера, плавающей панели и настройках Chrome, Firefox и Edge.
- **Ваши страницы в магазинах.** Мы публикуем расширение в ваших учётных записях Chrome Web Store, Firefox Add-ons и Microsoft Edge Add-ons. Учётные записи и возможные сборы магазинов оплачиваете вы.
- **Связанный сайт на вашем домене.** Страницы учётной записи, к которым подключается расширение, размещаются нами.
- **Нынешние функции Video Controls Plus:** скорость 0.1x–16x, повтор A–B, усиление звука до 400 %, фильтры, снимки, заметки с отметкой времени, переназначаемые клавиши и инструменты YouTube, Netflix и LinkedIn.
- **6 месяцев обновлений** со дня покупки. См. [обновления и продление](./updates.md).
- **Ключ и файл лицензии** на вашем сайте, доступные для [проверки](./verify.md).

Лицензия не включает исходный код и не является исключительной: до выкупа мы можем выдавать её другим компаниям.

## Из чего состоит сборка

| Часть | Что это сейчас |
|---|---|
| Расширение | Одна кодовая база WXT, React и TypeScript: Manifest V3 для Chrome и Edge, Manifest V2 для Firefox. Удалённого кода нет: все библиотеки включены в пакет, как требует Chrome Web Store. |
| Инструменты сайтов | Три реестра: 62 функции YouTube, 52 Netflix (50 с переключателем, все выключены при установке) и 48 инструментов LinkedIn. Запись реестра определяет переключатель, вкладку панели и пункт меню. |
| Вход | В расширении нет пароля. Пользователь входит через Google на сайте и подключает расширение коротким кодом на обоих экранах. Порядок одинаков в Chrome, Edge и Firefox. |
| Связанный сайт | Vite и React: страницы учётной записи, заметки, закладки, отложенные видео, планы и страницы для разработчиков. |
| Серверная часть | Postgres с защитой строк, схема на Drizzle и серверные функции для ИИ, загрузки файлов, почты, платежей, API, адреса помощника MCP и вебхуков. |

Приложение Android не входит в группу браузерного расширения.
