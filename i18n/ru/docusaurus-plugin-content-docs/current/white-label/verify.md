Любой человек может проверить лицензию на [странице проверки](https://vcpeai.aoneahsan.com/verify-license). Проверку выполняет наш лицензирующий сервис.

## Проверка по ключу

Выберите **License key**, вставьте ключ и нажмите **Check**. Страница покажет, активна ли лицензия, кому выдана, какие домены охватывает, её состояние и дату окончания обновлений. Почта, телефон и цена не показываются.

## Проверка по домену

Выберите **Domain**, укажите хост, например `videos.example.com`, и нажмите **Check**. Сервис прочитает файл лицензии на этом домене и проверит ключ.

| Ответ | Значение |
|---|---|
| This domain serves a valid license. | Файл найден, ключ действует для домена. |
| This domain serves a license issued for another domain. | Ключ настоящий, но выдан для другого домена. |
| This domain serves no license file. | Файла по адресу ниже нет. |
| We could not reach that domain. | Домен не ответил по HTTPS. |

## Файл лицензии

Каждая версия под своим брендом отдаёт файл по адресу:

```text
/.well-known/vcpeai-white-label-license.json
```

В нём указаны продукт, клиент, домен, ключ и ссылка на страницу проверки. Рядом лежит сертификат PDF по тому же пути с окончанием `.pdf`. Оба файла добавляем мы при публикации: вам не нужно создавать их самостоятельно.

Если ключ отозван или версия работает на неохваченном домене, вместо приложения появляется страница «This license is not active». Данные при этом не удаляются.
