Лицензия на выпуск под своим брендом означает, что команда Video Controls Plus ведёт расширение для вашей компании под вашим названием. Пользователи устанавливают ваше расширение из Chrome Web Store, Firefox Add-ons и Microsoft Edge Add-ons, а связанный сайт работает на вашем домене. Мы собираем, публикуем и обновляем продукт, размещаем сайт. Вам не нужно работать с кодом.

Есть два варианта покупки; они сопоставлены на [странице лицензирования](https://vcpeai.aoneahsan.com/white-label):

| | Лицензия под своим брендом | Выкуп исходного кода |
|---|---|---|
| Кто ведёт продукт | Наша команда, под вашим брендом | Вы |
| Исходный код | Остаётся у нас | Вам передаются все репозитории, из которых собирается расширение |
| Продажа другим | Возможна до выкупа | После выкупа продажи прекращаются |
| Обновления | 6 месяцев включено, затем продление | 6 месяцев включено, затем продление |
| Платежи после покупки | Продление обновлений по желанию | Продление по желанию и 7 % от валовой выручки продукта ежеквартально, пока он приносит доход |

Video Controls Plus продаётся одной платформенной группой: расширение для Chrome, Firefox и Edge вместе. Другой группы для пакета нет, поэтому скидка на пакет не применяется.

Цены и оформление — на [странице цен](https://vcpeai.aoneahsan.com/white-label/pricing), которая читает их из лицензирующего сервиса. У выкупа есть [отдельная страница](https://vcpeai.aoneahsan.com/white-label/buyout).
