Установите Video Controls Plus из магазина расширений своего браузера. Скорость можно менять сразу после установки.

| Браузер | Магазин |
|---|---|
| Chrome | [Chrome Web Store](https://chromewebstore.google.com/detail/video-controls-plus/ihafdbecgnhendhckoknblmcminoikdb) |
| Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/video-controls-plus/ghjcpobkbbhefdlgffopfhlepkgcknlb) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/video-controls-plus) |

Эти же ссылки есть на [странице установки](https://vcpeai.aoneahsan.com/install).

## Добавьте расширение

1. Откройте из таблицы страницу магазина для своего браузера.
2. Добавьте расширение и подтвердите разрешения в запросе браузера.
3. Закрепите значок через кнопку расширений на панели браузера — тогда панель Video Controls Plus откроется одним нажатием.

Приветственная страница откроется внутри расширения. Пройдите её или пропустите. На одном из шагов предлагается **Connect to your account**. Его можно пропустить и подключиться позже.

## Установка в Firefox

Дополнению нужен Firefox 140 или новее. При установке Firefox показывает, какие данные оно собирает.

Firefox также запрашивает необязательные разрешения на данные. События использования передаются только при разрешении на «технические данные и взаимодействия», а содержимое страницы — только после разрешения на «содержимое веб-сайтов», которое дополнение запросит при первом использовании такой функции. Подробнее — в разделе [«Конфиденциальность и разрешения»](../privacy-and-permissions.md).

Подключение к учётной записи в Firefox работает так же, как в Chrome и Edge. Инструкция и список действий, которым оно нужно, — в разделе [«Учётная запись и синхронизация»](../account-and-sync.md).

## Какие разрешения просит браузер

Расширение запрашивает доступ ко всем сайтам, чтобы находить видео на любой открытой странице. Назначение каждого разрешения описано в разделе [«Конфиденциальность и разрешения»](../privacy-and-permissions.md).
