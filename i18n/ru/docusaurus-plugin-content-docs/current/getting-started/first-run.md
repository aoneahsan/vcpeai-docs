Откройте страницу с видео и нажмите `]`. Скорость вырастет на 0.1x — расширение уже работает.

## Попробуйте первые действия

1. Откройте видео на YouTube, Udemy, Vimeo или другом сайте со стандартным плеером.
2. Нажмите `]`, чтобы ускорить видео на 0.1x; повторными нажатиями можно дойти до 4x.
3. Нажмите `[`, чтобы замедлить видео на 0.1x.
4. Нажмите `=`, чтобы вернуться к скорости по умолчанию.
5. Нажмите `Ctrl + Alt + 4`, чтобы сразу перейти к 2x.

Для скорости учётная запись не нужна. Клавиши `,` и `.` перемещают видео по одному кадру. Режим «картинка в картинке» открывается после подключения учётной записи.

## Найдите плавающую панель

Плавающая панель управления находится на странице рядом с видео. Нажмите её, чтобы раскрыть, и перетащите в удобное место.

`Esc` или `Ctrl + Alt + H` скрывают панель. Повторное нажатие возвращает её.

## Найдите панель расширения и настройки

Нажмите значок Video Controls Plus на панели браузера. Откроется панель, где видно текущий сайт и состояние расширения. Здесь можно [приостановить его на одном сайте](./pause-per-site.md).

Настройки открываются в отдельной вкладке.

## Для чего нужна подключённая учётная запись

Скорость, пресеты, покадровое воспроизведение, ссылка на момент, широкий экран, локальные закладки и плавающая панель работают без подключения. После него доступны:

| Действие | Клавиша или управление |
|---|---|
| Повтор A–B | `Ctrl + Alt + A`, затем `Ctrl + Alt + B` |
| Картинка в картинке | `Ctrl + Alt + P` |
| Усиление звука | `Ctrl + Alt + U` |
| Видеофильтры | `Ctrl + Alt + F` |
| Снимок экрана | `Ctrl + Alt + C` |
| Заметка с отметкой времени | **Note** на вкладке Tools плавающей панели |
| Автоматический пропуск | Переключатель в настройках |

Внутри расширения входа нет. Учётная запись находится на vcpeai.aoneahsan.com. Для подключения нажмите **Connect to your account** в панели расширения или на вкладке **Account & Sync** в настройках. Это работает в Chrome, Edge и Firefox. Подробные шаги, новые возможности и данные — в разделе [«Учётная запись и синхронизация»](../account-and-sync.md).

## Если клавиша не работает

Буквенные и цифровые клавиши требуют `Ctrl + Alt`. Отдельно работают только `[`, `]`, `=`, `\`, `'`, `,`, `.` и `Esc`. Все сочетания указаны [в таблице](../keyboard-shortcuts/defaults.md); назначить другую клавишу поможет [эта инструкция](../keyboard-shortcuts/rebinding.md).

Далее: [управление скоростью](../user-guide/speed-control.md).
