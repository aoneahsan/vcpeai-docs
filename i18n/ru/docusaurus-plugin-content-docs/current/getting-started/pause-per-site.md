Откройте панель расширения на нужном сайте и нажмите **Pause on this site**. На нём исчезнут плавающая панель и сочетания клавиш; другие сайты продолжат работать.

## Приостановите сайт

1. Откройте нужный сайт.
2. Нажмите значок Video Controls Plus на панели браузера.
3. Нажмите **Pause on this site**.
4. Выберите срок.

| Вариант | Результат |
|---|---|
| Until I turn it back on | Пауза действует до ручного возобновления |
| For 1 hour | Закончится через 1 час |
| For 4 hours | Закончится через 4 часа |
| For 1 day | Закончится через 1 день |
| For 1 week | Закончится через 1 неделю |

Страница перезагрузится. Пока действует пауза, плавающая панель и сочетания на этом сайте не работают.

## Возобновите работу

1. Откройте приостановленный сайт.
2. Откройте панель расширения. В ней будет **Paused** и оставшееся время.
3. Нажмите **Resume**.

## Ограничения

Список приостановленных сайтов хранится на этом устройстве и не синхронизируется. Пауза на ноутбуке не выключит расширение на другом компьютере.

Кнопка паузы есть только на сайте, где расширение работает. Если панель показывает **Not enabled**, приостанавливать нечего.

## Сочетания

Для паузы сочетания нет. Чтобы скрыть только плавающую панель, нажмите `Esc` или `Ctrl + Alt + H`. Они есть [в списке](../keyboard-shortcuts/defaults.md), а [инструкция по переназначению](../keyboard-shortcuts/rebinding.md) поможет их изменить.
