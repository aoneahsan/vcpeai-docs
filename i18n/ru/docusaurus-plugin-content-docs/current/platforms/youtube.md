На YouTube доступны обычные элементы управления и специальные функции: поиск комментариев, счётчик дизлайков, блокировка каналов, скачивание субтитров и обложек. Большинство включены сразу. Для работы включённых по умолчанию функций учётная запись не нужна; подключение требуется только для вкладки YouTube Features в настройках, где меняются переключатели. См. [«Учётная запись и синхронизация»](../account-and-sync.md).

## Основное управление

Скорость, плавающая панель и клавиши работают как на других сайтах. `]` ускоряет на 0.1x; память скорости хранит значение отдельно для каждого видео.

## Что включено изначально

| Функция | Действие | Исходно |
|---|---|---|
| Dislike Counter | Показывает число дизлайков через Return YouTube Dislike API | Вкл., есть в меню по правому щелчку |
| Comment Search | Ищет среди комментариев к видео | Вкл., есть в меню |
| Channel Blocker | Убирает канал из рекомендаций | Вкл., есть в меню |
| Thumbnail Downloader | Скачивает обложку видео | Вкл. |
| Subtitle Downloader | Скачивает субтитры | Вкл. |
| Shorts Blocker | Скрывает Shorts в ленте | Выкл. |
| Auto Wide | Всегда включает широкий режим YouTube | Выкл. |
| Ad Skip | Нажимает собственную кнопку YouTube Skip Ad, когда она появляется | Выкл. |

Ad Skip не удаляет рекламу. Он действует только после появления кнопки на самом YouTube.

## Где находятся переключатели

1. Откройте настройки.
2. Перейдите на вкладку **YouTube Features**.
3. Если вкладка просит подключиться, подключите учётную запись.

Функции сгруппированы по разделам Comments, Discovery & Blocking, Navigation, Viewing Experience, Player, Productivity, Learning, Analytics, Advanced и Downloads. Все 62 с их ограничениями описаны [в руководстве по функциям YouTube](https://vcpeai.aoneahsan.com/blog/youtube-extras-guide).

| Переключатель | Действие |
|---|---|
| Enable | Включает или выключает функцию |
| Show in right-click menu | Добавляет её в меню по правому щелчку на YouTube |

Специальные функции действуют только на youtube.com.

## Как запустить функцию

Используйте вкладку YouTube плавающей панели или меню по правому щелчку. Надписи панели следуют [языку расширения](../user-guide/display-and-widget.md). В меню появляются только выбранные вами пункты.

## Сочетания

`Ctrl + Alt + X` копирует ссылку на текущий момент видео. Остальные клавиши есть [в списке](../keyboard-shortcuts/defaults.md), а изменить их поможет [инструкция](../keyboard-shortcuts/rebinding.md).
