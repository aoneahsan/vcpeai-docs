На LinkedIn расширение управляет видео и помогает с профилем, вакансиями и публикациями. Инструмент запускается сразу после выбора в плавающей панели или меню по правому щелчку. Включённые по умолчанию инструменты работают без учётной записи. Для изменения переключателей нужна вкладка LinkedIn Features в настройках, а для неё — [подключённая учётная запись](../account-and-sync.md).

## Инструменты

Каждый инструмент сразу открывает панель либо начинает экспорт или скачивание. Все 48 описаны с шагами, примерами и ответами на вопросы на сайте, начиная с [инструментов профиля](https://vcpeai.aoneahsan.com/features/linkedin-profile).

| Инструмент | Действие | Исходно |
|---|---|---|
| Profile Scorer | Анализ полноты профиля | Вкл. |
| Headline Generator | Создание заголовков по ключевым словам | Вкл. |
| Job Tracker | Учёт заявок на вакансии | Вкл. |
| Post Exporter | Экспорт публикаций в CSV или JSON | Вкл. |
| Profile Backup | Резервная копия профиля | Вкл. |
| Message Exporter | Экспорт сообщений в CSV или JSON | Вкл. |
| Feed Filter | Фильтрация ленты | Выкл. |
| Focus Mode | Скрытие отвлекающих элементов LinkedIn | Выкл. |

## Что включено

Инструменты, которые ждут вашего выбора, включены по умолчанию. Те, что изменяют страницу или ленту LinkedIn при загрузке, сначала выключены. К последним относятся Feed Filter и Focus Mode.

## Где находятся переключатели

1. Откройте настройки.
2. Перейдите на вкладку **LinkedIn Features**.
3. Если вкладка просит, подключите учётную запись.

Разделы: Profile, Content Creation, Post & Feed, Connections, Messaging, Jobs, Analytics, Export, Privacy и Productivity. У каждого инструмента есть переключатель включения и показа в меню по правому щелчку. Они работают только на linkedin.com. Переключатели начинают действовать после перезагрузки LinkedIn, но действия меню выполняются сразу.

## Кнопка справки

На каждой панели инструмента есть кнопка с объяснением назначения и способа использования панели.

## Помощь с текстом

Помощь с текстами LinkedIn — функция ИИ с тремя способами запуска. Какие данные передаются и куда, объясняется [здесь](../ai-features.md).
