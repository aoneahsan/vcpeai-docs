Скорость и основные действия работают на Netflix. Дополнительные функции изначально выключены; включайте нужные на вкладке Netflix Features в настройках. Для вкладки нужна учётная запись; см. [инструкцию по подключению](../account-and-sync.md).

## Основное управление

`]` ускоряет на 0.1x, `[` замедляет на 0.1x — с учётной записью или без неё.

## Включите дополнительные функции

1. Откройте настройки и вкладку **Netflix Features**.
2. Если требуется, подключите учётную запись.
3. Включите нужную функцию.
4. Перезагрузите страницу Netflix.

Переключатели действуют после перезагрузки. Действия из меню запускаются сразу: открытие панели, запуск таймера, экспорт и скачивание не ждут перезагрузки. Для каждой функции есть также переключатель пункта в меню по правому щелчку. Они действуют только на netflix.com. Все 50 с ограничениями защиты Netflix описаны [в отдельном руководстве](https://vcpeai.aoneahsan.com/blog/netflix-extras-guide).

| Функция | Действие | Исходно |
|---|---|---|
| Skip Recap | Пропуск «Ранее в сериале…» | Выкл. |
| Dual Subtitles | Два языка субтитров одновременно | Выкл. |
| Subtitle Downloader | Скачивание SRT или VTT | Выкл. |
| Sleep Timer | Пауза через заданное число минут | Выкл. |
| Episode Navigator | Переход между сериями | Выкл. |
| Watch Limits | Дневной лимит просмотра | Выкл. |
| Dialogue Boost | Усиление голоса относительно музыки и эффектов | Выкл. |

Watch Limits учитывает только воспроизведение в видимой вкладке. Фоновая вкладка дневной лимит не расходует.

## Клавиши при скрытом управлении Netflix

Иногда Netflix показывает экран «Устройство не входит в домохозяйство Netflix». Когда расширение убирает этот экран, Netflix может оставить собственное управление плеером скрытым. **Только тогда** включаются следующие клавиши. Небольшое уведомление на плеере сообщает об этом и ведёт к полному списку.

| Клавиша | Действие |
|---|---|
| `Space` | Воспроизведение или пауза |
| `←` / `→` | Назад или вперёд на 10 секунд |
| `Shift + ←` / `Shift + →` | На 1 минуту |
| `Ctrl + ←` / `Ctrl + →` | На 5 минут |
| `Ctrl + 0` | К началу |
| `Ctrl + 1` — `Ctrl + 9` | К отметкам от 10 до 90 % |
| `Ctrl + -` | За минуту до конца |
| `↑` / `↓` | Громче или тише |
| `M` | Включить или выключить звук |
| `F` | Включить или выключить полный экран |
| `V` | Следующая дорожка субтитров, включая выключение |
| `B` | Следующая звуковая дорожка |

Эти клавиши можно изменить в **Settings → Keyboard Shortcuts → Netflix Recovery Controls**. Одно сочетание принадлежит только одному действию; клавиша восстановления не может одновременно быть общей клавишей.

## Ограничения

В других ситуациях это собственные клавиши Netflix. Расширение не исправляет все ошибки Netflix: оно убирает экран домохозяйства и даёт клавиатурное управление в описанном случае.
