Буквы и цифры используются с `Ctrl + Alt`. Отдельно работают только `[`, `]`, `=`, `\`, `'`, `,`, `.` и `Esc`. Так клавиши расширения не мешают клавишам самого плеера.

«Да» в последнем столбце означает, что действие требует [подключённой учётной записи](../account-and-sync.md).

## Скорость

В настройках эти действия находятся в разделе Speed Control.

| Клавиша | Действие | Нужна учётная запись |
|---|---|---|
| `[` | Замедлить на 0.1x | Нет |
| `]` | Ускорить на 0.1x | Нет |
| `=` | Вернуться к скорости по умолчанию | Нет |
| `\` | Показать текущую скорость | Нет |
| `'` | Применить Current Dynamic Speed с вкладки General настроек | Нет |
| `Esc` | Скрыть или показать плавающую панель | Нет |
| `Ctrl + Alt + H` | Скрыть или показать плавающую панель | Нет |

## Необязательные действия без клавиш

Изначально эти действия не назначены. В **Settings → Keyboard Shortcuts** найдите группу, нажмите **Set** и введите сочетание. Если оно уже занято, настройки назовут другое действие и дадут ссылку на него.

| Группа | Действие | Нужна учётная запись |
|---|---|---|
| Comfort | Включить или выключить комфорт для глаз | Нет |
| Comfort | Включить или выключить настройку цветовосприятия | Нет |
| Bookmarks | Включить или выключить Focus Mode | Нет |
| Comfort | Включить или выключить оформление субтитров | Нет |
| Comfort | Включить или выключить направляющую для чтения | Нет |
| Study | Запустить или приостановить учебный таймер | Нет |
| Study | Показать или скрыть расшифровку | Нет |
| Effects | Включить или выключить эффекты | Да |
| Effects | Размыть участок видео | Да |
| Audio tools | Включить или выключить звуковые инструменты | Да |
| Audio tools | Поменять левый и правый каналы | Да |
| Capture | Начать или остановить запись клипа | Да |
| Capture | Создать GIF | Да |
| Capture | Сделать пометки на снимке | Да |
| Automation | Заблокировать автозапуск на сайте | Нет |
| Automation | Начать или остановить постепенное ускорение | Нет |

Каждое действие описано отдельно: [комфорт](../user-guide/comfort-and-accessibility.md), [учёба](../user-guide/study-tools.md), [эффекты](../user-guide/visual-effects.md), [звук](../user-guide/audio-tools.md), [захват](../user-guide/capture-and-export.md), [автоматизация](../user-guide/playback-automation.md).

## Сочетания браузера

Эти четыре действия назначает сам браузер. Изменить их можно на его странице сочетаний расширений, но не внутри Video Controls Plus.

| Предлагаемая клавиша | Действие |
|---|---|
| `Alt + V` | Открыть панель расширения |
| `Ctrl + Shift + V` (`Command + Shift + V` на Mac) | Показать или скрыть плавающую панель |
| `Ctrl + Shift + P` (`Command + Shift + P` на Mac) | Включить или выключить картинку в картинке |
| `Ctrl + Shift + C` (`Command + Shift + C` на Mac) | Сделать снимок |
