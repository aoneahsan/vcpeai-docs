Нажимайте `]` и `[` для изменения скорости шагом 0.1x или двигайте ползунок плавающей панели до 4x. Для этих клавиш не нужны `Ctrl + Alt`, а для управления скоростью — учётная запись.

## Клавиши скорости

| Клавиша | Действие |
|---|---|
| `]` | Быстрее на 0.1x |
| `[` | Медленнее на 0.1x |
| `=` | Вернуться к скорости по умолчанию |
| `\` | Показать текущую скорость |
| `'` | Применить динамическую скорость |
| `Ctrl + Alt + 1` | 0.5x |
| `Ctrl + Alt + 2` | 1x |
| `Ctrl + Alt + 3` | 1.5x |
| `Ctrl + Alt + 4` | 2x |
| `Ctrl + Alt + 5` | 2.5x |
| `Ctrl + Alt + 6` | 3x |
| `Ctrl + Alt + 7` | 3.5x |
| `Ctrl + Alt + 8` | 4x |

## Предел скорости

Доступный диапазон — от 0.1x до 16x. Ползунок и клавиши `[` и `]` останавливаются на 4x. Для большей скорости введите число в поле вкладки Speed плавающей панели или в поля **Custom Speed (0.1x - 16x)** на вкладке General в настройках.

Шаг клавиш всегда равен 0.1x. Настройки минимальной, максимальной скорости и шага в приложении нет.

## Скорость по умолчанию и динамическая скорость

Откройте вкладку General в настройках.

| Параметр | Назначение | Клавиша |
|---|---|---|
| Default Playback Speed | Скорость после сброса и при загрузке нового видео | `=` |
| Current Dynamic Speed | Другое заданное здесь значение, применяемое одной клавишей | `'` |

Клавиша `'` применяет Current Dynamic Speed. Это не значение, сохранённое для конкретного видео.

## Пресеты

Восемь пресетов назначены на `Ctrl + Alt + 1` — `Ctrl + Alt + 8`. Каждый можно изменить, а ненужные удалить на вкладке Keyboard Shortcuts в настройках. Девятый пресет получает `Ctrl + Alt + 9`.

## Память скорости

Расширение по умолчанию запоминает выбранную для видео скорость и применяет её при следующем открытии. Также можно запомнить скорость для всего плейлиста или курса: переключатель на вкладке Advanced изначально выключен.

Если для видео подходят несколько сохранённых значений, **Speed Priority** определяет приоритет:

| Вариант | Какая скорость используется |
|---|---|
| Playlist/Course first | Для плейлиста или курса |
| Video first | Для конкретного видео |
| Global only (ignore saved) | Значение по умолчанию; сохранённые значения игнорируются |

## Соседние клавиши

`,` и `.` передвигают видео на кадр назад или вперёд. Все клавиши перечислены [здесь](../keyboard-shortcuts/defaults.md); [эта инструкция](../keyboard-shortcuts/rebinding.md) поможет изменить назначение.
