Повтор A–B воспроизводит отрезок между двумя выбранными точками. Для него нужна [подключённая учётная запись](../account-and-sync.md); для управления скоростью — нет. Если клавиши повтора не действуют, сначала подключитесь.

## Задайте фрагмент

1. Доведите видео до начала трудного места.
2. Нажмите `Ctrl + Alt + A` — это точка A.
3. Дождитесь конца нужного фрагмента.
4. Нажмите `Ctrl + Alt + B` — это точка B.

Достигнув B, видео вернётся к A и будет повторять отрезок до сброса. Точки можно задать и нажатием на вкладке Loop плавающей панели.

Это помогает переслушать быстрый такт урока гитары, 40-секундное доказательство в лекции или непонятую фразу на другом языке. Отметьте отрезок, уменьшите скорость клавишей `[` и повторяйте его столько, сколько нужно.

## Клавиши повтора

| Клавиша | Действие |
|---|---|
| `Ctrl + Alt + A` | Установить начало (A) |
| `Ctrl + Alt + B` | Установить конец (B) |
| `Ctrl + Alt + L` | Включить или выключить повтор |
| `Ctrl + Alt + Backspace` | Сбросить обе точки |

## Выберите режим

Режим выбирается на вкладке Loop плавающей панели. Названия показываются на выбранном в расширении языке; см. [«Изменение языка»](./display-and-widget.md).

| Режим | Что происходит при достижении B |
|---|---|
| Forever | Отрезок повторяется до выключения |
| Once | Отрезок повторяется один раз |
| Times | Отрезок повторяется заданное число раз — от 1 до 20 |

В режиме Times индикатор показывает ход повторов. Максимум — 20. Для большего числа выберите Forever и выключите повтор клавишами `Ctrl + Alt + L`.

## Соседние клавиши

`,` и `.` передвигают видео на один кадр назад или вперёд, помогая точно поставить A и B. Полный список — [«Сочетания по умолчанию»](../keyboard-shortcuts/defaults.md); изменить их можно по [инструкции](../keyboard-shortcuts/rebinding.md).
