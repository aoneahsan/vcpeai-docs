После [подключения учётной записи](../account-and-sync.md) можно усилить звук выше 100 %, вплоть до 400 %. Нажмите `Ctrl + Alt + U` для повышения и `Ctrl + Alt + Y` для понижения.

## Клавиши звука

| Клавиша | Действие |
|---|---|
| `Ctrl + Alt + U` | Прибавить усиление на 20 % |
| `Ctrl + Alt + Y` | Убавить усиление на 20 % |
| `Ctrl + Alt + N` | Включить или выключить выравнивание |

Эти же действия доступны на вкладке Audio плавающей панели.

## Усильте тихую запись

Запись лекции из дальнего конца аудитории может оставаться тихой даже при 100 % громкости плеера. Усиление поднимает её выше этого предела, от 100 до 400 %.

Одно нажатие меняет уровень на 20 %. На 400 % громкое видео звучит очень громко, поэтому повышайте постепенно.

## Выровняйте громкость

Выравнивание сокращает разницу между самыми громкими и тихими частями. Нажмите `Ctrl + Alt + N`, если голос тихий, а вступительная музыка значительно громче.

## Память громкости

Расширение запоминает громкость и отключение звука отдельно для каждого сайта. Например, YouTube можно оставить тихим, а учебный сайт — громким. Карточка **Remember Volume** находится во вкладке Video Features настроек.

## Другие звуковые инструменты

Вкладка Audio плавающей панели предлагает не только усиление. После подключения учётной записи в **Advanced Audio** доступны:

| Кнопка | Действие |
|---|---|
| Bass | Усиление низких частот |
| Denoise | Уменьшение фонового шума |
| Spatial | Пространственное звучание |
| Vocals | Выделение голоса |
| Compress | Сжатие динамического диапазона |
| Karaoke | Режим караоке |
| Pitch | Пресет высоты тона |
| EQ | Пресеты эквалайзера |

## Скачайте звук

Функция сохраняет звук видео в WebM или WAV, но не в MP3. Переключатель **Audio Download** находится на вкладке Download & Capture настроек. Обработка выполняется на вашем устройстве.
