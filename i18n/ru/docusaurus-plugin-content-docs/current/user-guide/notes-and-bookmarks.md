Для сохранения заметки сначала подключите учётную запись. У каждой заметки остаётся время видео; она появляется на странице **Notes** сайта. На вкладке **Tools** плавающей панели находятся редактор, кнопки экспорта и выбор библиотеки.

## Запишите заметку

1. Откройте вкладку **Tools** плавающей панели.
2. В разделе **Notes & Extraction** нажмите **Note**.
3. Введите текст и подтвердите.

Заметка с текущим временем видео становится в очередь синхронизации с учётной записью. Также можно щёлкнуть видео правой кнопкой и выбрать **Add Note**. Если расширение не подключено, оно попросит подключить учётную запись до открытия редактора.

Заметка, написанная на 12:40 лекции, остаётся привязанной к 12:40. Она личная и не публикуется в комментариях к видео.

Чтобы читать и редактировать заметки, выберите **Notes** в разделе **Your library** на вкладке Tools. Откроется страница заметок вашей учётной записи.

## Экспортируйте заметки

В том же разделе выберите формат. В экспорт входят заметки из учётной записи и те, что ещё ожидают синхронизации в этом браузере.

| Кнопка | Файл |
|---|---|
| Notes MD | Markdown |
| Notes TXT | Обычный текст |
| Notes JSON | JSON |

В файле Markdown каждая заметка стоит на отдельной строке со своей отметкой времени.

## Добавьте закладку

Нажмите **Bookmark** на вкладке Tools, выберите **Add Bookmark** в меню по правому щелчку видео или нажмите `Ctrl + Alt + O`. Без учётной записи закладка остаётся в этом браузере.

После подключения новые закладки сохраняются на текущем моменте и синхронизируются с учётной записью. Чтобы искать, редактировать, удалять или экспортировать их, выберите **Bookmarks** в **Your library** либо откройте вкладку [Bookmarks на странице Notes](https://vcpeai.aoneahsan.com/notes?tab=bookmarks). Закладки, созданные до подключения, остаются в том браузере; позже они не загружаются автоматически. **Enable Cloud Sync** отдельно управляет синхронизацией настроек.

## Скачайте расшифровку

Кнопка **Transcript** в том же разделе скачивает расшифровку текстовым файлом для чтения вне плеера.

## Поделитесь моментом

`Ctrl + Alt + X` копирует ссылку на видео с текущим временем. Это работает на YouTube, Vimeo, Twitch и других сайтах. В ссылке есть только время.

## Сочетания

| Клавиша | Действие |
|---|---|
| `Ctrl + Alt + O` | Добавить закладку на текущем моменте |
| `Ctrl + Alt + X` | Скопировать ссылку с отметкой времени |
| `Ctrl + Alt + C` | Сохранить кадр |

Исходные клавиши — [в списке](../keyboard-shortcuts/defaults.md), изменение — [в инструкции](../keyboard-shortcuts/rebinding.md).
