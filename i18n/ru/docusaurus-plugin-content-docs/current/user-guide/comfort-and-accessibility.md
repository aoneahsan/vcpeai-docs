**Comfort** делает изображение теплее, помогает различать цвета, меняет вид уже существующих субтитров и добавляет направляющую поверх видео. Откройте раздел Comfort на вкладке View плавающей панели. Учётная запись не нужна.

Выбор сохраняется вместе с настройками и попадает в учётную запись только при включённой облачной синхронизации. Инструменты Comfort не передают сведения о просмотре отдельному сервису.

## Где искать настройки

| Место | Что доступно |
|---|---|
| Плавающая панель → View → **Comfort** | Четыре быстрых переключателя и **More comfort settings** |
| Настройки → Video Features → **Comfort & accessibility** | Все параметры и **Reset comfort settings** |
| Настройки → Keyboard Shortcuts → **Comfort** | Четыре действия без назначенных клавиш |

## Комфорт для глаз

Включите **Eye comfort** и настройте **Warmth** от 0 до 100 % для вечернего просмотра. Меняется только видео, не страница. **Also lower brightness** дополнительно приглушает яркость.

**Turn on by itself between set times** включает и выключает режим по расписанию. Введите **From** и **Until**; исходно он включается в 21:00 и выключается в 07:00.

## Различимость цветов

Выберите **Type**: Green-weak, Red-weak, Blue-yellow или No color. Затем выберите **Mode**:

- **Make colors clearer** сдвигает цвета, чтобы их было проще различать.
- **Show how it looks** показывает изображение так, как его видит человек с выбранным типом цветовосприятия.

## Вид субтитров

Эта функция меняет вид субтитров, уже показанных сайтом, на YouTube, Netflix, Prime Video, Udemy, Coursera, Vimeo, Khan Academy, в плеерах Video.js и видео с дорожкой WebVTT. Новые субтитры она не создаёт.

Выберите **Caption look** и **Text size**.

| Вид | Описание |
|---|---|
| Default | Белый текст на тёмной полосе |
| High contrast | Крупный полужирный белый текст на чёрном |
| Dark | Мягкий светлый текст на тёмно-сером |
| Minimal | Небольшой текст на светлой полосе |
| Large print | Крупный полужирный жёлтый текст |
| Colorful | Полужирный зелёный текст на тёмно-фиолетовом |
| Easy reading | Простой шрифт без засечек, увеличенные промежутки и высота строк, тёмный текст на кремовом |

## Направляющая для чтения

Мягкая полоса помогает следить за одной строкой субтитров или текста на экране. В **Shape** выберите Band, Line или Spotlight. **Stay put** удерживает её на одной высоте, **Follow the pointer** ведёт за указателем. **Height on the video** задаёт положение, **Strength** — выраженность.

## Вместе с другими действиями

Comfort работает одновременно с [видеофильтрами](./video-filters.md) и цветами режима кино. Расширение объединяет их в один фильтр, поэтому включение одного не выключает другой.

## Сочетания

Четыре необязательных действия изначально без клавиш: Toggle eye comfort, Toggle color vision, Toggle caption style и Toggle reading guide. Назначьте их [по инструкции](../keyboard-shortcuts/rebinding.md).
