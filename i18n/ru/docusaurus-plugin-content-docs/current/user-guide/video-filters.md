Фильтры меняют яркость, контрастность и насыщенность от 0 до 200 %. Есть также оттенки серого, инверсия и ночной режим. После [подключения учётной записи](../account-and-sync.md) нажмите `Ctrl + Alt + F`, чтобы открыть вкладку Filters плавающей панели.

## Доступные действия

| Действие | Диапазон или эффект | Управление |
|---|---|---|
| Вкладка Filters | Открыть или закрыть | `Ctrl + Alt + F` |
| Яркость | 0–200 % | Ползунок |
| Контрастность | 0–200 % | Ползунок |
| Насыщенность | 0–200 % | Ползунок |
| Оттенки серого | Вкл. или выкл. | `Ctrl + Alt + G` |
| Инверсия | Вкл. или выкл. | `Ctrl + Alt + I` |
| Ночной режим | Вкл. или выкл. | `Ctrl + Alt + T` |

100 % — исходное изображение сайта. Меньшее значение ослабляет эффект, большее усиливает; каждый ползунок останавливается на 200 %. Кнопка **Reset All Filters** возвращает исходный вид.

## Когда применять фильтр

Бледно-серый текст записи экрана на белом фоне легче читать после повышения контрастности. Тёмное видео днём можно осветлить. Для яркой доски лектора вечером используйте `Ctrl + Alt + I` для инверсии или `Ctrl + Alt + T` для ночного режима.

## Сохраните пресет

Настройте три ползунка и сохраните результат на вкладке Filters. Доступно до 20 пресетов. Они входят в настройки и могут включаться в [экспорт](../account-and-sync.md).

## Другие настройки изображения

| Где | Действие | Результат |
|---|---|---|
| Вкладка View, **Transform** | Rotate, mirror, flip | Поворот на 90°, отражение по горизонтали или вертикали |
| Вкладка Tools, **Visual Modes** | Ambient | Подсветка вокруг плеера |
| Вкладка Tools, **Visual Modes** | Cinema | Цветовой пресет кино |
| Вкладка Tools, **Visual Modes** | Letterbox | Полосы над изображением и под ним |

Фильтры меняют отображение видео в браузере. Снимок и загрузка — отдельные действия.
