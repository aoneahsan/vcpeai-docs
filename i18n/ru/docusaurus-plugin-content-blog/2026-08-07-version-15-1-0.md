Для других приложений команды появилась постоянная вкладка в настройках. Рекламный блок больше не занимает верх каждой страницы настроек, поэтому над ними может быть только один баннер.

- **Новое: вкладка More from the developer.** Другие приложения команды собраны в одном месте: логотип, короткое описание и ссылка для каждого. Раньше список был лишь шагом приветственной страницы, и при пропуске настройки вы его не видели. Список встроен в расширение; для его показа ничего не загружается. Открытие продукта не отслеживается.
- **Новое: More apps в панели расширения.** Ссылка внизу панели сразу открывает эту вкладку.
- **Улучшено: настройки стали спокойнее.** Рекламный блок перенесён на новую вкладку. Если над настройками появляется баннер, он скрывается на время напоминания о завершении настройки — два баннера не накладываются.
- **Улучшено: описания в магазинах.** Страницы Chrome, Edge и Firefox теперь объясняют, какие части расширения ведут к другим приложениям команды. В Chrome указано, что реклама — только собственные продукты: сторонней рекламной сети, SDK и отслеживания для неё нет.
