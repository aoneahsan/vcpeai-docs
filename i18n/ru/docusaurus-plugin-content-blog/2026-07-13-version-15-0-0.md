Появились функции ИИ: краткое содержание видео и помощь с текстами для LinkedIn. Управление воспроизведением работает и во встроенных на других сайтах видео. Все дополнительные функции Netflix теперь включаются по желанию.

- **Новое: функции ИИ.** На вкладке AI Features можно получать краткое содержание видео и помощь с текстом для LinkedIn. Доступен небольшой дневной лимит после входа, собственный ключ OpenAI или Anthropic либо локальная модель. Если ИИ недоступен, функция переходит на встроенные генераторы.
- **Новое: управление встроенными видео.** Плавающая панель, сочетания клавиш и действия контекстного меню работают в плеерах YouTube или Vimeo, встроенных в статьи и курсы. Расширение загружается во встроенный фрейм, только если в нём есть видео.
- **Улучшено: функции Netflix включаются отдельно.** По умолчанию они выключены. Нужные функции включаются на вкладке Netflix Features в настройках. Прежние настройки были сброшены один раз, чтобы у всех было одинаковое исходное состояние.
- **Улучшено: точный учёт времени просмотра Netflix.** Время и лимиты считаются, только пока видео воспроизводится в видимой вкладке. Фоновая вкладка больше не расходует дневной лимит.
- **Исправлено: пауза на сайте остаётся на устройстве.** Список сайтов с приостановленным расширением больше не синхронизируется между устройствами.
